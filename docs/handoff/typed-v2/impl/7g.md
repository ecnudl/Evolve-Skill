## Choices

- `REQUIRED` is exactly the scan (a test holds the equality), not the union with step 1m's list: an equality also
  catches stale names, and the ten removed names belonged to typed-v1 code deleted in step 4. All of 1m's DESIGN 3.1 to
  3.3 names that `T/` uses are still there (1m's own test of them passes unchanged).
- `SCRIPTS` is the static closure (an over-approximation, 11 files) rather than the modules seen loaded at a start:
  lazy imports (the sheet qualification's `replay_sheet_v6`) happen after the check. Pinned from this tree: none of the
  11 files changed in this repository's history after 2026-10-21, before main-v10 (f635f67, 2026-11-09); the dl
  snapshot itself is checked only by the bound driver on dl (Left for later). No list file: the 11 pins live in
  `T/machinery.py`, sealed with `provenance.typed_code`.
- `scripts.run_typed` is typed code (`prepare.TYPED_CODE`), not machinery: `TYPED_SCRIPTS` makes check 4 require it
  from this tree, and `compare_scripts` does not compare `scripts/run_typed.py`.
- Check 6 keeps each module's own self-check and adds one table (`TEXT_PINS`) that also pins the module pin tables, so a
  text changed together with its module's `PINS` still fails. `writers.MEMBER_RULE` (the D16 clause of the revision
  summary, pinned nowhere before) is included with the other D16 / D17 sentences (RP14: step 7 pins the result).
- The guard case "a missing private name" adds a name to `REQUIRED` inside the child (`--missing`): a snapshot with the
  listed bytes cannot lack a name, and an altered file is already the check-2 case. Altered files are appended to (a
  comment, a newline), so they stay importable and only the guard can see them.
- The stand-in snapshot holds, besides the 564 + 64 listed files, the 11 pinned scripts files (the main-v10 snapshot
  holds `scripts/`, check 2 now requires them) and what the frozen `v222_cards` reads beside `skillopt/`
  (`tests/fixtures/execskill/v222_cards`, `docs/handoff/v29-20261026/v210-instructions-coevo5-v1.json`), as T13 does.
- Moved on purpose (no assertion changed): the `stand_in` helper of `tests/test_typed2_machinery.py` also copies the
  11 `SCRIPTS` files, because checks 2 and 3 now compare them; every earlier refusal message ("in 1 paths: ...") holds.
