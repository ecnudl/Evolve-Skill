## Choices

1. **What `COPIED_SOURCE_SHA256` hashes.** I followed DESIGN 3.1 ("the sha256 of the copied source lines") rather
   than the formula in spec/card.md (`sha256(inspect.getsource(v225_cards.card_violation))`, the whole function,
   `964871e3...`). The pin is the UTF-8 sha256 of the copied lines as the bound function holds them: lines 169-201,
   33 lines, 2,179 characters. I computed it now, as DESIGN asks ("computed when the module is written"), so this
   step's test checks it.
2. **Added `copied_source()`.** This public helper is not in the DESIGN 3.1 list. It returns the bound function's
   source after its `return 'length'` line, or `''` when that line is missing, so the pin fails closed. With it the
   pin can be recomputed from the module the run actually bound (the snapshot) at real start. Step 7's check 6 is
   then `sha256(cards.copied_source()) == cards.COPIED_SOURCE_SHA256`.
3. **How the copy is marked.** The one line that differs is `from .engineer import absent_findings`, which becomes
   `from skillopt.execskill.engineer import absent_findings`. The relative form would point into the typed package.
   `PATH_LIKE` and `_reference_values` are bound by module-level aliases (`cards.PATH_LIKE is v225_cards.PATH_LIKE`,
   and the same for `_reference_values`), so the copied lines that use them stay verbatim.
4. **`content_violation` refuses missing text.** For a non-string or blank text it raises `ValueError` through
   `require`, outside the copied block. `card_screen` never calls it for such a text, because no text is `length`
   first.
5. **How `retry_text` detects "no text".** No text is `chars == 0`; `content_chars` is 0 exactly when the text is
   not a string or is blank.
6. **What `retry_text` validates.** It requires that the violation is one of the five keys, that `chars` and
   `bullets` are non-negative ints (bool is refused) and that `room` is an int. It refuses a `length` result that
   has no measured cause.
7. **Content keys and the room rule.** A content key always gets the v2.25 sentence, whatever the room; the examples'
   reserve guarantees it fits, as in typed-v1. A `length` failure gets the detailed sentence when
   `len(sentence) <= room`. Otherwise it gets the v2.25 `length` sentence (199 characters).
8. **Number format.** `chars`, `target` and `cut` are written with thousands separators. `bullets`, `max_bullets`
   and `extra` are plain integers (spec 1.2 item 8).
9. **Shape of `pins()`.** It returns sha256 hex for `RETRY_FRAME`, `REASON_TOO_LONG`, `REASON_TOO_MANY_BULLETS`,
   `REASON_NO_TEXT` and `REASON_JOIN`, plus:
   - `RETRY_SHORT`: a sha256 per key.
   - `LIMITS_RECORD`: a copy.
   - `COPIED_SOURCE_SHA256`.

   The result can be serialised to JSON. This test does not pin literal sha256 values for the retry texts; it
   asserts their exact strings, and step 7 pins the hashes.
10. **The fresh-interpreter test is not written.** spec/card.md's
    `test_card_path_under_bound_machinery_in_a_fresh_interpreter` is left out because DESIGN 5 makes
    `tests/test_typed2_machinery.py` plus `tests/typed2_bound_driver.py` the one bound harness (step 7), and that
    harness "screens a card".
11. **Later consumers: only the frozen ones are tested here.** For a stored card of 4,501 characters, on all five
    benches with `configuration=MACHINERY` (main-v10), the test asserts that the bound `v225_cards.compose` returns
    the system card unchanged for a package without card procedures, and that the bound `solver._system` carries it
    whole. The typed consumers (`library`, the describer, `mount.system_card`, the revise `card_request`) are not
    tested in this file, because other steps are editing those modules now (see "Left for later steps").
12. **What the drift corpus contains.**
    - All the cases named in spec/card.md 4, plus the three shown eight-gram cases of
      `tests/test_execskill_v225_cards.py:77-81` and a clean 2,999-character card in both contexts.
    - Every text is screened bare and with one final newline.
    - The writer-context items and examples are inline copies, so the file does not import `T/writers.py`, which
      other steps are editing.
