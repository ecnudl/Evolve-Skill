## 1 两条架构

- **A（phase1，特征感知生成器）**：生成题按训练真题的特征分布出题，扩展算式语法覆盖真题里的统计运算，
  作为学习步的**额外训练材料**（诊断题 D）与远迁移测量（迁移题 T）。不再当门。
- **X（条款池）**：`final = bzero + 通过条款级门的 edits`。候选拆成相对父 Skill 的逐条 edit，每条 edit
  单独加到 bzero 上，在**训练真题里它所针对的 trigger 子集**上测量，按下面的决策规则收入条款池。

两者共用 `skillopt/skill_features`（零调用 tagger：运算族、答案形式、舍入要求、上下文形状）。

## 4 生成器 v3（架构 A）

- 版本 `generated-officeqa-tasks-v3-feature-aware`，新文件，v1/v2 不改。
- **扩展算式语法**：在 v1 的有理数四则 + abs/min/max 之外，加 `sqrt ln exp pow` 与序列函数
  `mean median sum stdev_pop stdev_samp geomean`（以及 `corr`）；最多 24 个数字；`decimal` 60 位精度求值；
  舍入在要求位数上不得接近平局（|小数部分 − 0.5| ≥ 1e-9）；"答案依赖每个数字"的扰动检验沿用 v1。
- **多部分答案**：`expressions` 至多 3 个、每个各自位数，答案写成 `[a, b]`。
- **题型对齐**：L 侧每道源题先打标签，写题模型被要求写**同一题型**（同一运算族、同一答案形式、同一舍入习惯）
  但关于不同数字的新题；H 侧（只给页面）按 L32 档案的题型分布抽样指定题型（不泄露 H 的题面）。
- **保真度检查（零调用，生成后）**：生成题档案对 L32 的 TV 距离：主运算 ≤ 0.25、答案形式 ≤ 0.20、
  舍入 ≤ 0.25（旧生成题分别是 0.51 / 0.25 / 0.47）。不过 → 记 no-go，不进学习步。
- **难度检查（校准，付费，GLM-5.3 × 3 次）**：父 Skill（bzero）在 D、T 上的通过率与在 G 上的通过率之差
  ≤ 10 个百分点（10/15 v2：生成 0.78–0.79 vs 真题约 0.60）；D 中"父 Skill 至少错一次"的题 ≥ 20。

## 6 条款级门（架构 X）——事先登记的决策规则

- **拆分**：父 Skill 与候选按块（顶层 bullet / 标题 / 段落，连同块前的原始分隔符）对齐，每个非 equal 操作是
  一条 edit（改写过的块按相似度或旧文本保留比例配成 replace；插入的标题与紧随其后、中间无空行的块合成一条）；
  edit 的标签 = 新文本的标签减去被替换文本的标签（为空则取新文本标签；仍为空 = 通用 edit，trigger 子集 = G）。
  **删除型 edit 没有新文本，一律按通用 edit 判**。单独加上后文本与父 Skill 相同的 edit（只改空白）不送测。
- **测量**：每条 edit 单独加到 bzero（leave-one-in），在 G 48 道 × **2 次**上评测（deepseek-v4-flash）；
  bzero 本身在 G 上至少 4 次（复用 10/16 两次探针的 4 次，同一求解提示与评分器）。逐题用平均通过率 p。
  每个探针必须：测的 Skill 文本哈希与 edit 文本一致；题面与登记的 G 逐题一致；求解配置（模型、后端、
  max_tokens、思考设置、版本）与噪声登记时一致；每格运行数完整；所有用到的探针 config 两两不同；
  初筛/复核探针的启动时间晚于噪声登记时间。
- **噪声模型**（10/16 12:30 修订，在任何 edit 测量之前）：σ(n) = sqrt(v · n)，v = 逐题差值 d_i = p_A(i) − p_B(i)
  的**二阶矩 mean(d²)**（不减均值：两组之间的漂移也计入噪声，比方差更保守），A、B 为 bzero 在 G 上的两次独立
  探针（各 2 次运行）。
- **缺测**：门槛 σ 按登记的子集大小算（不按已知题数）；edit 与父 Skill 都有已知结果的题少于 G 的 90% → 该 edit
  记为 pending，不通过；已知不足 90% 的初筛/复核一律不放行。
- **初筛**：Δ_trig = Σ_{i∈S}(p_e − p_0) ≥ max(1, σ(|S|))；Δ_rest = Σ_{i∉S}(p_e − p_0) ≥ −1；
  通用 edit 要求 Δ_total ≥ max(1.5, σ(48))。
- **复核**：初筛通过的 edit 再用新的 2 次运行（另一个探针）重测；Δ_trig > 0 且 Δ_rest ≥ −1（通用：Δ_total > 0）
  才收入条款池。
- **整份候选（A-whole）**：把整份候选当一条通用 edit 用同一规则判；通过者里取**复核轮** Δ_total 最大者，无则 = bzero。
- **组合**：池内 edit 按父 Skill 位置应用；两条 edit 改同一父块时保留**复核轮** Δ_trig/|S| 较大者并记录冲突。

## 9 实现时的补充与收紧（10/16 11:40–12:10，均在任何门、学习、最终评测结果之前；来自 Codex 审查）

- **条款门（§6）**：判定全用精确有理数（v 封存为 "p/q"；Δ ≥ max(下限, √(v·n)) 判为 Δ ≥ 下限且 Δ² ≥ v·n）；覆盖率按计数判；
  登记的运行次数（噪声每半 2 次、初筛/复核各 2 次、父基线每题合计 ≥ 4 次）封存在噪声登记里并强制执行；每个探针逐题核对
  评分输入（题面 + 评分器读取的私有字段：OfficeQA 只读参考答案，故面板与试点题文件之间只差出处键的同一道题视为相同）。
- **初筛/复核探针的父基线**：除噪声两半的 4 次外，同时把初筛（及复核）探针里 bzero 自己的 2 次也计入父基线（同时间、
  同路由条件的锚；规则写的是"至少 4 次"）。
- **组合（§6 最后一条）**：多个门的结果一起合成时（`pool_all` ＝ 旧候选门 ＋ 新候选门），各 edit 按复核轮 Δ_trig/|S| 排序；
  与更强 edit 冲突者跳过（原规则），**新文本（忽略空白）与更强 edit 相同者也跳过**，两者都记入回执。
- **生成器 v3（§4）**：算式按精确有理数求值，只有无理函数（sqrt、ln、exp、分数次幂、标准差、geomean、corr）在 60 位与 120 位
  各算一次且须在 1e-25 相对范围内一致，中间值 |v| < 1e40；多部分题须以固定句 "Answer in the format [x, y]." 结尾
  （评分器保留逗号后的空格）；题目类别取生成题自身题面的运算族。档案必须由学习侧真题重算一致（不只核 id）。
- **go/no-go（§4）**：保真度按"池里实际保留的题"算（D 只含单部分的学习侧题；T 全部）；难度的 G 参照用一个**新的、只测
  G 48 题**的 GLM-5.3 low 探针（父 Skill × 3 次，10/16 11:50 起跑；旧的 10/15 探针同时测过 val，不再用作参照），且校准探针与
  参照探针的求解设置（模型、档位、思考、max_tokens、温度、基准）必须一致。难度读作"池通过率 − G 通过率 ≤ 0.10"（单侧）。
