# coevo5 第二批代码审查（唯一一轮，Codex gpt-6-astra，推理 ultra，只读）原文

日期：2026-10-17。审查提示见同目录的说明；以下为审查输出原文，未改动。

VERDICT: NOT ACCEPTABLE

1. **BLOCKER — [chain.py:185](../../skillopt/coevo5/chain.py#L185): Termination permits unsealing while learning continues.** Calling `terminate()` during stage 1 immediately publishes `chain-terminated.json`, which permits `evaluation.unseal()`. The running chain checks termination only at startup and continues through stages 2–5. An in-memory reproduction executed all five stages after termination. Violates §10 and §13.4. **Smallest fix:** synchronize termination with the runner; publish the terminal marker only after the chain has stopped issuing work.

2. **BLOCKER — [chain.py:128](../../skillopt/coevo5/chain.py#L128): A sealing failure is accepted as successful evaluation.** Evaluation writes `unit.json` before its containment context performs the final output flush. If that flush fails, the child returns `EXIT_PAUSED`; the parent nevertheless accepts the existing record and continues learning. Restart also skips that unit. Violates §20.2 and §13.4. **Smallest fix:** publish successful completion only after containment succeeds, honor failed child exits, and preserve a recovery requirement across restarts.

3. **MAJOR — [leakage.py:73](../../skillopt/coevo5/leakage.py#L73): Supplied SearchQA/OfficeQA context escapes the mechanical leakage check.** The analyst sees snippets/documents, but `surface()` compares only `public["question"]`. A unique eight-word sentence copied from context into a research question passes and reaches the researcher. This conflicts with §7’s isolation requirement and §9 under the ordinary meaning of the task surface. **Ambiguity:** §9 says “题面（含选项、任务说明）” without explicitly defining whether supplied context is included; §22 records no exclusion. **Smallest fix:** include context in the comparison surface, or explicitly resolve that definition before launch.

4. **MAJOR — [leakage.py:45](../../skillopt/coevo5/leakage.py#L45): Alternative numeric spellings bypass answer leakage detection.** For OfficeQA reference `0.125`, text containing `.125` passes because the regex extracts `125`; `1.25e-1` also passes. The equivalent `0.125` is correctly rejected. Such answer-bearing research questions reach the researcher before adjudication. Violates §9 and §4 step 5b. **Smallest fix:** recognize complete numeric tokens, including leading-dot decimals and scientific notation, and compare exact values.

5. **MAJOR — [manifest.py:28](../../skillopt/coevo5/manifest.py#L28), [manifest.py:66](../../skillopt/coevo5/manifest.py#L66): Frozen inputs need not be bound to the run.** An empty or incomplete `code` map passes verification, allowing an omitted implementation file to change without changing the manifest hash. Separately, the archive is loaded by path and checked against its own mutable `index.json`; replacing a document and its index hash passes on restart under the same run identity. Violates §0, §7 and §20.2. **Smallest fix:** require coverage of the mandatory code files and bind the archive index/document hashes to the manifest.

6. **MAJOR — [step.py:137](../../skillopt/coevo5/step.py#L137): C3 overlooks missing mandatory answer formats.** Suppose a rule produces three truncated SearchQA regression answers with unavailable output while the parent passes all 60. `answer_tag_present(None)` returns `None`; testing `is False` counts zero violations. The score loss of three remains within tolerance five, so C3 passes despite exceeding its two-extra-violations limit. Violates §5.5 C3 and §22. **Smallest fix:** after the existing unknown handling, count unavailable output or any non-True mandatory format result as a violation.

7. **MAJOR — [forward.py:417](../../skillopt/coevo5/forward.py#L417): Failed questions receive additional consistency checks when repeated.** Deduplication checks only accepted items. If a question fails its first consistency check and reappears, another check can accept it. Seven other valid questions can therefore become an eight-question panel and enable similar placement. Violates §8’s first-occurrence rule and §22’s requirement that duplicates consume no checking calls. **Smallest fix:** record encountered identities before consistency checking, regardless of the outcome.

8. **MAJOR — [forward.py:347](../../skillopt/coevo5/forward.py#L347), [forward.py:363](../../skillopt/coevo5/forward.py#L363): Independent OfficeQA formulas bypass source validation.** Given table cells `1300` and `1234.50`, generation formula `1300-1234.50`, and reference `65.50`, the independent response `{"formula":"65.5"}` passes although that literal appears in no table cell. Violates §22’s requirement that every formula number come verbatim from a cell. **Smallest fix:** apply the same table-literal validation to the independent formula before comparing its result.

9. **MAJOR — [roles.py:78](../../skillopt/coevo5/roles.py#L78), [research.py:677](../../skillopt/coevo5/research.py#L677): Outer resends exceed method-role ceilings.** `Roles.ask()` uses a recorder permitting three sends, while research counts only logical `ask()` invocations. Six research calls can issue eighteen requests; the supposedly unretried rewrite can issue three. These sends are charged, so this is a call-ceiling violation, not a ledger bypass. Violates §4 step 5b, §7 and §8. **Smallest fix:** enforce method ceilings at the send boundary and disallow outer rewrite resends. **Ambiguity:** if “调用” intentionally means logical invocations, §22 needs to record that exception; it currently does not.

10. **MAJOR — [step.py:182](../../skillopt/coevo5/step.py#L182): Rubric revision uses completion labels as official scores.** A delivered SpreadsheetBench program producing an invalid workbook has completion `fail` but no official score. `answers()` supplies `official="fail"`, and the retained program makes it judgeable. Eight such cases plus eight official passes create a revision-selection panel that lacks eight actual official failures. Disagreement sampling and balanced accuracy also use these substituted labels. Violates §6 and §22. **Smallest fix:** preserve separate completion and official fields; use actual official results for revision and completion results for diagnoses/triggers.

11. **MAJOR — [chain.py:136](../../skillopt/coevo5/chain.py#L136): Stage 0 starts model calls before SpreadsheetBench qualification succeeds.** All five evaluation children start together. Only the SpreadsheetBench child performs test-side qualification; the other four can issue calls before it discovers zero qualified items. Violates §2.1 and §10, which require stopping before **any** stage-0 calls in that case. **Smallest fix:** complete qualification inside a sealed evaluation process and establish a shared success barrier before releasing stage-0 solver calls.

12. **MAJOR — [chain.py:164](../../skillopt/coevo5/chain.py#L164): An authorized budget increase prevents recovery.** After a budget stop, the owner raises the relevant cap through `Budget.raise_cap()` and records recovery. Restart unconditionally declares the original caps; `Budget.declare()` rejects the raised value as “A declared cap differs.” Raising the overall cap similarly obstructs later chain starts. Violates §13.4’s authorized continuation path. **Smallest fix:** preserve existing caps increased through recorded deviations and declare only missing scopes.

13. **MAJOR — [scripts/run_coevo5.py:45](../../scripts/run_coevo5.py#L45), [chain.py:129](../../skillopt/coevo5/chain.py#L129): Early evaluation-child failures leave no recovery barrier.** A child can fail during manifest/client/endpoint initialization before an attempt directory exists. The parent reports a pause, but persists no failed attempt. Restart launches the unit without any `recovery.json`; this was reproduced with failed-before-attempt children followed by successful children. Violates §13.4. **Smallest fix:** durably register the attempt before fallible child initialization and record startup failures against it.

14. **MAJOR — [chain.py:168](../../skillopt/coevo5/chain.py#L168), [chain.py:176](../../skillopt/coevo5/chain.py#L176): A manifest-verification interruption does not terminate the chain.** If a pinned file changes between stages, `verify()` raises outside a unit and leaves no terminal state. Restoring the file and restarting resumes the existing history. §13.4 explicitly requires termination for interruptions outside registered units, giving manifest mismatch as its example. **Smallest fix:** persist a fatal chain state for this failure and refuse continuation in that run.

15. **MAJOR — [chain.py:155](../../skillopt/coevo5/chain.py#L155): Terminal markers bypass run-identity validation.** Pointing a different manifest at a directory containing an earlier `chain-complete.json` or `chain-terminated.json` immediately returns that status. The subsequent `chain.json` identity check never executes, so the new run can be silently skipped. Violates §20.2’s run binding. **Smallest fix:** validate the chain and terminal-marker identities before returning either terminal status.

16. **MINOR — [examiner.py:110](../../skillopt/coevo5/examiner.py#L110), [examiner.py:159](../../skillopt/coevo5/examiner.py#L159): Analyst input bounds are exceeded.** ALFWorld trajectory actions are unbounded here: an allowed 1,000-character action plus a clipped observation exceeds §22’s 300-character-per-step limit. `_clip()` also appends six characters after consuming the entire allowance, turning a 2,000-character question bound into 2,006. **Smallest fix:** cap the complete displayed trajectory step and include truncation markers within every limit.

17. **MINOR — [units.py:142](../../skillopt/coevo5/units.py#L142): Method-role configuration errors receive the wrong pause category.** A non-dictionary receipt causes `Roles.ask()` to raise `ConfigurationError`, which inherits `RuntimeError`. `run_unit()` recognizes only `ValueError` as configuration, recording this as `exception`. It pauses, but violates §22’s required classification. **Smallest fix:** recognize `ConfigurationError`, preferably preserving the existing registered stop-kind mapping.
