### 1.2 全局一个、每个 bench 一个、每簇一个、每个 Skill 一个？

- 零调用：40 份学到的 Skill 严格按数据集聚成 3 簇；跨数据集规则重合 0.00，同数据集内也只有 0.02；从指令出发学到的
  Skill 保留指令 40–75% 的规则，从空出发的 0。→ "先聚类再按簇写 rubric"在现有数据上就是"按 bench 写 rubric"；
