## 0. Summary of the v4 analyst (what an implementer builds)

1. **One call per diagnosis code** (P5, B9). `analyst.payloads(...)` builds one input per code that has >= 1 check-half failed
   item (else `untestable_code`), >= `EVIDENCE[0]` = 2 proposal-half failed items (else `too_few_examples`), within the first
   `ANALYST_MAX_CODES` = 8 codes by frequency (else `beyond_code_cap`). Codes are ordered by proposal-half failed-ITEM count
   (B8: one code per item), largest first, then name. Each call asks for at most `ANALYST_RULES_PER_CODE` = 2 rules.
2. **Balanced per-code payload** (P6, B9, B8): every failed item of the code up to the per-code cap (`ANALYST_EXAMPLES[bench]`,
   else `ANALYST_MAX_EXAMPLES` = 40), one example per item with the wrong answers of all its failed runs, the answers of its passed
   runs when it has both (the contrast), and the reference (today's policy: the analyst sees it); up to
   `ANALYST_PASSED_EXAMPLES` = 8 seeded proposal-half items whose every run passed; the counts (proposal-half failures with the
   code, check-half failures with the code, check-half items, MIN_TRIGGER); the similarity map and the limits. Under
   `ROLE_INPUT_BYTES` the passed examples are left out first, then failed examples (`examples_omitted`,
   `passed_examples_omitted`).
3. **Conditional rows** (P1): a row has `when` (<= 200), `do` (<= 300), optional `otherwise` (<= 100); the code renders
   `"When <when>: <do>."` + `" Otherwise: <otherwise>."`; whitespace runs are collapsed server-side (B5); the rendered text must
   be <= `MAX_RULE_CHARS` = 600. `text`, `codes`, `transfer` in the reply are ignored (P1, B1, B2).
4. **Codes from evidence** (B1): `codes := sorted({code of each cited item})`; evidence = 2-8 distinct task ids of the failed
   items shown IN THIS CALL (a passed item is never evidence). `placement` in {"local","similar"}, "local" when absent (B2).
5. **Two-pass validation** (B5): the validator raises every problem of the first reply as ONE message; the wrapper (G4)
   re-asks once with it; on the second reply the rows still invalid are voided alone (`row_status` =
   `fields_missing | when_invalid | do_invalid | otherwise_invalid | rendered_overlength | placement_invalid |
   evidence_invalid | row_invalid`, `problem` = the message); the reply is never voided for a row. `covered`/`adds`/`rationale`
   are clipped, never a reason to void; bad questions are dropped and counted. A reply whose envelope is still malformed
   after the re-ask is that CODE's method failure; the other codes stand.
6. **Per-step selection** (P5, B2), in `step.prepare`: void rows recorded; dedup over valid rows (as today); `analyst.capped`
   keeps the `MAX_RULES` = 5 rows with the most evidence (the rest `over_cap`); `analyst.demoted` turns similar rows beyond
   `MAX_SIMILAR_RULES` = 2 per step -- and every similar row at a stage without a checkable similar target -- into local rows
   (`demoted_similar`, never voided).
7. **Trigger from the judge** (P1, G2 provides the judge): for every admissible rule, `applicability.judge` is asked for every
   check-half item whether `when` holds; `trigger := applicable items`; `< MIN_TRIGGER` => `insufficient_support`;
   `when_matched`, `when_precision`, `when_recall`, `not_applicable` recorded (informational).
8. **Prompt** (P2, B4, C1, B2, B9): worked example about an imaginary colour-sorting task (part of the fixed prompt, so in the
   request hash); the leakage rules (no digits except years, no quoted passage/option text, invented examples only;
   task-structure rules allowed, answer-distribution rules refused); the testability constraint (>= 4 held-out items judged
   by `when`); what a similar rule must pass and the per-step allowance; every limit.

## 1. Interfaces this plan assumes from other groups (named; both sides must match)

### 1.1 G4 (calls.py/roles.py: B5 re-ask, B17, P4) -- the role-call wrapper
- `roles.Roles.ask(role, system, user, *, label, check=None, reask=True) -> value | None`. When `check(value)` raises
  `Invalid` (or `ValueError`/`TypeError`/`KeyError`) on the first delivered reply and `reask` is true, the wrapper sends ONE
  more request with the same system prompt and the user payload extended by two keys:
  `"previous_reply": <the first reply's text, clipped>` and
  `"validation_feedback": "Your previous reply failed validation: <str(error)>. Reply with the corrected JSON only."`.
  `check` is called again on the second reply (so G1's validator sees pass 1 then pass 2); a second failure returns `None`.
  G1's analyst calls `roles.ask(..., reask=True)`; if G4 names the keyword differently or makes the behaviour the default,
  change that one keyword in `analyst.propose` (§2.2) and the two test lines marked `# G4` (§2.4, §2.5).
- The role-call record (`roles.calls[-1]`) carries `"reasked": True|False`. `analyst.propose` reports
  `attempts = 1 + bool(roles.calls[-1].get("reasked"))`. If G4 records it differently, adjust that one expression.
- The wrapper must pass the FULL `str(error)` into the feedback (G1's messages are up to ~300 characters per row, joined
  with "; "); clipping only the archived `reason` (today `str(error)[:80]`) is fine.
- G1 does not rely on `roles.fields` tolerating extra keys (it validates rows with its own helpers), so B5's "extra keys are
  tolerated" needs no G4 change for the analyst.

class RowProblem(Invalid):
    """A rule row's validation problem: ``status`` (the row's ``row_status`` when it is voided) and, as the message, what
    is sent back to the analyst (v4 B5)."""

    def __init__(self, status, message):
        super().__init__(message)
        self.status = status


def normalized(value):
    return " ".join(value.lower().split())


def _order(values, seed, tag):
    key = lambda v: hashlib.sha256(json.dumps([seed, tag, v]).encode()).hexdigest()  # noqa: E731
    return sorted(values, key=key)


def _collapsed(value):
    """Whitespace runs (line breaks included) to one space, surrounding whitespace removed: v4 B5 keeps the rule
    format's whitespace constraints (§3) server-side instead of asking the model for them."""
    return " ".join(value.split())


def render_text(when, do, otherwise=None):
    """v4 P1: the rule text of its parts -- "When <when>: <do>." and, when ``otherwise`` is given, " Otherwise:
    <otherwise>." -- each part collapsed and stripped of trailing ".", ":" or ";" so the template's punctuation is the
    only one."""
    part = lambda value: _collapsed(value).rstrip(".:; ")  # noqa: E731
    text = "When %s: %s." % (part(when), part(do))
    return text if otherwise is None else text + " Otherwise: %s." % part(otherwise)


# ------------------------------------------------------------------------------------------------ the rows
def _part(row, name, limit, n, *, optional=False):
    """One text part of row ``n`` (``when``, ``do``, ``otherwise``): collapsed, trailing sentence punctuation removed;
    None when an optional part is absent or blank. Raises ``RowProblem("<name>_invalid", message)``."""
    value = row.get(name)
    if value is None and optional:
        return None
    if type(value) is not str:
        raise RowProblem(name + "_invalid", "rule %d: \"%s\" must be a string%s"
                         % (n, name, " or omitted" if optional else ""))
    value = _collapsed(value).rstrip(".:; ")
    if not value:
        if optional:
            return None
        raise RowProblem(name + "_invalid", "rule %d: \"%s\" must not be blank" % (n, name))
    if len(value) > limit:
        raise RowProblem(name + "_invalid", "rule %d: \"%s\" has %d characters, at most %d are allowed"
                         % (n, name, len(value), limit))
    return value


def _clipped(row, name, limit):
    """An archival string field clipped to its limit; "" when absent or not a string (v4 B5: never a reason to void)."""
    value = row.get(name)
    return value[:limit] if type(value) is str else ""


def _questions(row):
    """(the usable research questions, the entries dropped): the first MAX_RESEARCH_QUESTIONS nonblank strings within
    MAX_QUESTION_CHARS of the row's ``questions`` (v4 B5: never a reason to void)."""
    raw = row.get("questions")
    raw = raw if type(raw) is list else []
    kept = [q for q in raw if type(q) is str and q.strip() and len(q) <= MAX_QUESTION_CHARS][:MAX_RESEARCH_QUESTIONS]
    return kept, len(raw) - len(kept)


def _evidence(row, shown, n):
    """(the row's evidence, the codes it derives): EVIDENCE[0]..EVIDENCE[1] distinct task ids of the failed items shown
    in this call, ``shown`` = {task_id: code} (v4 B1). Raises ``RowProblem("evidence_invalid", message)``."""
    evidence = row.get("evidence")
    if type(evidence) is not list or not EVIDENCE[0] <= len(evidence) <= EVIDENCE[1]:
        raise RowProblem("evidence_invalid", "rule %d: \"evidence\" must list %d to %d distinct task_id values of the "
                         "shown failed examples (got %s)" % (n, EVIDENCE[0], EVIDENCE[1],
                                                             len(evidence) if type(evidence) is list else "no list"))
    if any(type(e) is not str for e in evidence) or len(set(evidence)) != len(evidence):
        raise RowProblem("evidence_invalid", "rule %d: \"evidence\" entries must be distinct strings" % n)
    unknown = [e for e in evidence if e not in shown]
    if unknown:
        raise RowProblem("evidence_invalid", "rule %d: evidence cites %s, which is not a task_id of the shown failed "
                         "examples (\"examples\"; a passed example is never evidence)"
                         % (n, ", ".join(json.dumps(u) for u in unknown[:3])))
    return list(evidence), sorted({shown[e] for e in evidence})


def _row(benchmark, shown, row, n):
    """One rule row of a reply, validated on its own (v3 §4; v4 P1, B1, B2, B5): the record of a valid row. Raises
    ``RowProblem`` with the message sent back to the analyst."""
    if type(row) is not dict:
        raise RowProblem("fields_missing", "rule %d: must be a JSON object" % n)
    missing = [key for key in ("when", "do", "evidence") if key not in row]
    if missing:
        raise RowProblem("fields_missing", "rule %d: missing field(s) %s" % (n, ", ".join(missing)))
    when = _part(row, "when", MAX_WHEN_CHARS, n)
    do = _part(row, "do", MAX_DO_CHARS, n)
    otherwise = _part(row, "otherwise", MAX_OTHERWISE_CHARS, n, optional=True)
    text = render_text(when, do, otherwise)
    if len(text) > MAX_RULE_CHARS:
        raise RowProblem("rendered_overlength", "rule %d: the rendered rule \"When <when>: <do>. Otherwise: "
                         "<otherwise>.\" has %d characters, at most %d are allowed; shorten when, do or otherwise"
                         % (n, len(text), MAX_RULE_CHARS))
    try:
        Rule("check", text, benchmark)  # the rule format of §3: the rendering keeps it, the check stays the arbiter
    except ValueError as error:
        raise RowProblem("row_invalid", "rule %d: %s" % (n, str(error)[:120])) from None
    placement = row.get("placement")
    placement = "local" if placement is None else placement  # v4 B2: "local" when absent
    if placement not in PLACEMENTS:
        raise RowProblem("placement_invalid", "rule %d: \"placement\" must be \"local\" or \"similar\"" % n)
    evidence, codes = _evidence(row, shown, n)
    questions, dropped = _questions(row)
    return {"when": when, "do": do, "otherwise": otherwise, "text": text, "placement": placement,
            "placement_proposed": placement, "demoted_similar": False, "codes": codes, "evidence": evidence,
            "row_status": "ok", "problem": None, "covered": _clipped(row, "covered", MAX_COVERED_CHARS),
            "adds": _clipped(row, "adds", MAX_ADDS_CHARS),
            "rationale": _clipped(row, "rationale", MAX_RATIONALE_CHARS),
            "questions": questions, "questions_dropped": dropped}


def _void_row(row, problem):
    """v3 §4 / v4 B5: the record of a row that failed its validation on the second pass: never tested; its parts kept
    (clipped) when they are text."""
    def kept(name, limit):
        value = row.get(name) if type(row) is dict else None
        return value[:2 * limit] if type(value) is str else None
    when, do = kept("when", MAX_WHEN_CHARS), kept("do", MAX_DO_CHARS)
    otherwise = kept("otherwise", MAX_OTHERWISE_CHARS) or None
    placement = row.get("placement") if type(row) is dict else None
    return {"when": when, "do": do, "otherwise": otherwise,
            "text": render_text(when, do, otherwise) if when and do else None, "placement": None,
            "placement_proposed": placement if type(placement) is str else None, "demoted_similar": False,
            "codes": [], "evidence": [], "row_status": problem.status, "problem": str(problem)[:300], "covered": "",
            "adds": "", "rationale": "", "questions": [], "questions_dropped": 0}


def _check(benchmark, shown):
    """The validator of one per-code reply (v4 B5), called by the wrapper on each delivered reply: the first pass
    raises every problem of the envelope and of the rows as one message (the wrapper's one re-ask); the second pass
    voids the rows still invalid (``_void_row``) and keeps the rest. ``shown``: {task_id: code} of the failed items
    shown in this call (``payloads``). Returns {"rules": [row records], "problems": [messages], "rows_dropped": rows
    beyond ANALYST_RULES_PER_CODE left out on the second pass}."""
    passes = []

    def check(value):
        passes.append(True)
        strict = len(passes) == 1
        if type(value) is not dict or type(value.get("rules")) is not list:
            raise Invalid("the reply must be one JSON object {\"rules\": [...]}")
        rows, problems = value["rules"], []
        if len(rows) > ANALYST_RULES_PER_CODE:
            problems.append("at most %d rules for this failure code (got %d)" % (ANALYST_RULES_PER_CODE, len(rows)))
        out = []
        for n, row in enumerate(rows[:ANALYST_RULES_PER_CODE], 1):
            try:
                out.append(_row(benchmark, shown, row, n))
            except RowProblem as problem:
                problems.append(str(problem))
                out.append(_void_row(row, problem))
            except (ValueError, TypeError) as error:  # a wrong type is the row's own fault
                problem = RowProblem("row_invalid", "rule %d: %s" % (n, str(error)[:120] or type(error).__name__))
                problems.append(str(problem))
                out.append(_void_row(row, problem))
        if problems and strict:
            raise Invalid("; ".join(problems))
        return {"rules": out, "problems": problems, "rows_dropped": max(0, len(rows) - ANALYST_RULES_PER_CODE)}
    return check


# ---------------------------------------------------------------------------------------------- the inputs
def _example(benchmark, item, runs, code):
    """v4 P6/B8: one failed proposal-half item -- its task (from its first failed run, with that run's trace on
    ALFWorld), the wrong answers of its failed runs, the answers of its passed runs (the contrast, when it has both)
    and the reference (today's policy: the analyst may see it)."""
    failed = [r for r in runs if r["completion"] == "fail"]
    passed = [r for r in runs if r["completion"] == "pass"]
    first = failed[0]
    return {"task_id": item, "code": code,
            "task": task_view(benchmark, first["public"], trace=first.get("trace"),
                              context_chars=ANALYST_CONTEXT_CHARS.get(benchmark)),
            "answers": [answer_text(benchmark, r["output"]) for r in failed],
            "passed_answers": [answer_text(benchmark, r["output"]) for r in passed],
            "reference": reference(benchmark, first)}


def _passed_example(benchmark, item, runs):
    """v4 P6: one proposal-half item whose every run passed, with its answers (the common 6,000-character context)."""
    first = runs[0]
    return {"task_id": item, "task": task_view(benchmark, first["public"], trace=first.get("trace")),
            "answers": [answer_text(benchmark, r["output"]) for r in runs], "reference": reference(benchmark, first)}


def _fit(value):
    """v3 §6, v4 P6: the message within ROLE_INPUT_BYTES -- the last passed examples are left out first, then the last
    failed examples (``roles.fit``); the payload says how many of each. A message whose fixed fields alone exceed the
    bound is never sent (ValueError from ``fit``: the unit pauses)."""
    value["passed_examples_omitted"] = 0
    while value["passed_examples"] and message_bytes(value) > ROLE_INPUT_BYTES:
        value["passed_examples"].pop()
        value["passed_examples_omitted"] += 1
    return fit(value, "examples", ROLE_INPUT_BYTES)


def payloads(benchmark, *, parent_text, answers, item_codes, split, meanings, cards, seed, tag):
    """v4 P5, P6, B9: the analyst's inputs, one per code asked, in order -- {"calls": [{"code", "payload", "shown":
    {task_id: code} of the failed items shown}], "skipped": {code: "untestable_code" | "too_few_examples" |
    "beyond_code_cap"}, "order": every code with a proposal-half failed item, by count (largest first) then name}.
    ``answers``: the proposal half's answers, every run (``step.answers``); ``item_codes``: {item: its diagnosis code}
    for every training item with a failed run, both halves (v4 B8, ``examiner.item_codes``); ``split``: {item: half}
    (``step.halves``); ``cards``: the public task card of every bench."""
    backward, forward = similar_targets(benchmark)
    runs = {}
    for answer in sorted(answers, key=lambda a: (a["item"], a["run"])):
        runs.setdefault(answer["item"], []).append(answer)
    failed = sorted(i for i, found in runs.items() if any(r["completion"] == "fail" for r in found))
    passed = sorted(i for i, found in runs.items() if all(r["completion"] == "pass" for r in found))
    require(all(i in item_codes for i in failed), "Every failed proposal-half item has a diagnosis code (v4 B8)")
    by_code = {}
    for item in failed:
        by_code.setdefault(item_codes[item], []).append(item)
    check_items = [i for i, half in split.items() if half == "check"]
    check_failed = {}
    for item, code in item_codes.items():
        if split.get(item) == "check":
            check_failed[code] = check_failed.get(code, 0) + 1
    order = sorted(by_code, key=lambda c: (-len(by_code[c]), c))
    cap = ANALYST_EXAMPLES.get(benchmark, ANALYST_MAX_EXAMPLES)
    calls, skipped = [], {}
    for code in order:
        if check_failed.get(code, 0) == 0:
            skipped[code] = "untestable_code"
        elif len(by_code[code]) < EVIDENCE[0]:
            skipped[code] = "too_few_examples"
        elif len(calls) >= ANALYST_MAX_CODES:
            skipped[code] = "beyond_code_cap"
        else:
            shown = _order(by_code[code], seed, "%s:%s" % (tag, code))[:cap]
            drawn = _order(passed, seed, "%s:passed:%s" % (tag, code))[:ANALYST_PASSED_EXAMPLES]
            value = _fit({
                "section": TITLES[benchmark], "applies_when": APPLIES_WHEN[benchmark], "task_card": cards[benchmark],
                "current_skill": parent_text, "code": {"code": code, "meaning": meanings.get(code, "")},
                "counts": {"proposal_failures": len(by_code[code]), "check_failures": check_failed[code],
                           "check_items": len(check_items), "min_trigger": MIN_TRIGGER, "proposal_items": len(runs),
                           "proposal_failures_by_code": {c: len(v) for c, v in sorted(by_code.items())}},
                "examples": [_example(benchmark, i, runs[i], code) for i in shown],

                            "checkable": [TITLES[b] for b in backward + forward]},
                "limits": {"rules": ANALYST_RULES_PER_CODE, "rules_per_step": MAX_RULES,
                           "similar_rules_per_step": MAX_SIMILAR_RULES if backward + forward else 0,
                           "questions_per_rule": MAX_RESEARCH_QUESTIONS, "when_characters": MAX_WHEN_CHARS,
                           "do_characters": MAX_DO_CHARS, "otherwise_characters": MAX_OTHERWISE_CHARS,
                           "rule_characters": MAX_RULE_CHARS, "evidence": list(EVIDENCE),
                           "covered_characters": MAX_COVERED_CHARS, "adds_characters": MAX_ADDS_CHARS,
                           "rationale_characters": MAX_RATIONALE_CHARS, "question_characters": MAX_QUESTION_CHARS}})
            calls.append({"code": code, "payload": value,
                          "shown": {e["task_id"]: e["code"] for e in value["examples"]}})
    return {"calls": calls, "skipped": skipped, "order": order}


# ----------------------------------------------------------------------------------------------- the calls
def propose(roles, benchmark, calls, *, stage, label, reask=True):
    """{"status": "proposed" | "method_failure" | "nothing_to_ask", "calls": [per code asked: {"code", "status":
    "proposed" | "invalid", "attempts", "rows", "valid_rows", "rows_dropped", "problems", "shown", "passed_shown",
    "examples_omitted", "passed_examples_omitted"}], "proposals": [row records with "id", "code_call", "row"]}: one
    call per entry of ``calls`` (``payloads``), in order (v4 P5). v4 B5: a call is the first send and, on a validation
    problem, the wrapper's one re-ask with the message (``attempts``: 1 or 2 -- ``ANALYST_ATTEMPTS``); a reply still
    invalid after it is that code's method failure, the other codes stand. Proposal ids are positions over the calls'
    rows in call order (``s<stage>-r<n>``), fixed before any filtering; ``code_call`` is the code a row was asked for
    and ``row`` its position in that reply."""
    records, proposals = [], []
    for call in calls:
        payload = call["payload"]
        reply = roles.ask("analyst", ANALYST_SYSTEM, payload, label="%s/%s" % (label, call["code"]),
                          check=_check(benchmark, call["shown"]), reask=reask)  # G4: the re-ask keyword (v4 B5)
        record = {"code": call["code"], "status": "proposed" if reply is not None else "invalid",
                  "attempts": 1 + bool(roles.calls[-1].get("reasked")),  # G4: the re-ask flag of the call record
                  "rows": 0, "valid_rows": 0, "rows_dropped": 0, "problems": [], "shown": sorted(call["shown"]),
                  "passed_shown": len(payload["passed_examples"]),
                  "examples_omitted": payload["examples_omitted"],
                  "passed_examples_omitted": payload["passed_examples_omitted"]}
        if reply is not None:
            record.update(rows=len(reply["rules"]), valid_rows=sum(r["row_status"] == "ok" for r in reply["rules"]),
                          rows_dropped=reply["rows_dropped"], problems=reply["problems"])
            for n, row in enumerate(reply["rules"], 1):
                proposals.append({"id": "s%d-r%d" % (stage, len(proposals) + 1), "code_call": call["code"],
                                  "row": n, **row})
        records.append(record)
    status = ("nothing_to_ask" if not calls else "proposed" if any(r["status"] == "proposed" for r in records)
              else "method_failure")
    return {"status": status, "calls": records, "proposals": proposals}


# ------------------------------------------------------------------------------------------- the selection
def deduplicated(proposals, parent_texts):
    """(kept, dropped ids): a proposal whose normalized text equals a parent rule or a lower-numbered kept proposal is
    dropped (§4 step 5, and again after the research rewrite)."""
    seen, kept, dropped = {normalized(t) for t in parent_texts}, [], []
    for proposal in proposals:
        key = normalized(proposal["text"])
        if key in seen:
            dropped.append(proposal["id"])
            continue
        seen.add(key)
        kept.append(proposal)
    return kept, dropped


def capped(proposals):
    """v4 P5: (the MAX_RULES proposals with the most evidence, in their original order; the ids of the rest, ``over_cap``)
    over the valid, deduplicated rows of a step; ties keep the earlier row (a stable sort by evidence count)."""
    ranked = sorted(proposals, key=lambda p: -len(p["evidence"]))
    keep = {p["id"] for p in ranked[:MAX_RULES]}
    return [p for p in proposals if p["id"] in keep], [p["id"] for p in proposals if p["id"] not in keep]


def demoted(proposals, allowance):
    """v4 B2: (the proposals with at most ``allowance`` similar placements -- the first in order keep it, later similar
    rows become local with ``demoted_similar``; the ids demoted). ``allowance``: MAX_SIMILAR_RULES at a stage with a
    checkable similar target, else 0 (every similar row is demoted). Nothing is voided."""
    out, ids, similar = [], [], 0
    for proposal in proposals:
        if proposal["placement"] == "similar":
            similar += 1
            if similar > allowance:
                proposal = {**proposal, "placement": "local", "demoted_similar": True}
                ids.append(proposal["id"])
        out.append(proposal)
    return out, ids

## 5. Open questions (decisions the main session should confirm; each has a default in the code)

1. **"other" as a code cluster.** The code keeps asking about `other` like any code (v3 allowed targeting `other`); a rule
   for "none of the codes fits" is unlikely to be coherent. Default: ask. Flip: add `other` to a skip set in
   `analyst.payloads` (one line).
2. **Two G1 additions to P5/B9's skip list.** `too_few_examples` (< 2 failed items: no row could cite the required two) and
   `beyond_code_cap` (`ANALYST_MAX_CODES = 8`, needed for a finite per-step GLM cap, §6). Both recorded; defaults on.
3. **Order of cap and demotion.** Default: dedup -> cap (5 by evidence) -> demotion (2 similar among the kept). The
   alternative (demote first) would let a demoted row push a similar row out of the cap. Both are one-line swaps in
   `step.prepare`.
4. **Research rewrite and self-test revision vs `when`.** `research.rewrite` (REWRITE_SYSTEM) and the self-test revision
   (step.SELFTEST_SYSTEM/_revisions) return a free text, so after them `text` may no longer be "When <when>: <do>." while
   the judge's trigger set was derived from the analyst's `when` (and, in prepare, before the self-test). Recommended (not in
   G1's items; the owners of research.py/step.selftest decide): tell both prompts to keep the "When <condition>:" opening
   verbatim and change only the action, and refuse (as `rewrite_failed` / an invalid revision entry) a text that does not
   start with `"When " + when + ":"`. G1's record keeps `when` unchanged through both.
5. **Judge only admissible rules.** `applicability.judge` is called only for rules that passed `_admissible` (status None),
   so dropped rules have `trigger = []`, `when_matched = None`. Cost reason (§6). Flip: call it for every kept rule.
6. **`questions` leniency.** Bad or excess questions are dropped and counted rather than re-asked (they feed research, not
   the Skill). Flip: treat them as row problems in `_row`.
7. **G4's re-ask payload keys** (`previous_reply`, `validation_feedback`) and the record flag `reasked` are G1's assumption;
   three test lines and one expression depend on the names (§1.1).

## 6. GLM volume of the analyst per step (for the caps owner, spec §0)

- v3: at most 2 sends x (220,000-byte input ~ 86k prompt tokens [v1's 209,041 bytes = 85,789 tokens] + 16,384 output) =
  about 0.2M tokens per step.
- v4: at most `ANALYST_MAX_CODES` (8) calls x 2 sends (B5) x (86k + 16k) = about **1.6M tokens per step** worst case; a
  per-code payload is smaller than v3's single payload in practice (one code's items only, cap 40/16/20 per code), so a
  realistic step is 4-6 codes x ~1.3 sends x ~40k = 0.2-0.3M. The re-ask payload also carries `previous_reply` (<= 16k).
- Suggested cap delta: + 1.5M tokens per stage on each GLM learning cap (`LEARNING_CAP["E"]`, `["I"]`, `["ds"]`) and the
  chain caps accordingly; the applicability judge's volume (G2: <= 5 admissible rules x check-half items (<= 100) x 3 votes
  x ~3k tokens = ~4.5M per step worst case on SearchQA) is separate and larger.
