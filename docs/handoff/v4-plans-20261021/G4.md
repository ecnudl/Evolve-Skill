## 1. B5: re-ask with the validator's message; extra keys tolerated; archival truncation

### 1.1 What changes (semantics)

- `Roles.ask` (every validated role call) makes at most ONE re-ask after a refused reply: the same system prompt, the
  original payload plus `"notice": "Your previous reply failed validation: <validator message>. Reply with the
  corrected JSON only."` and `"previous_reply": <the refused reply, clipped to REASK_REPLY_CHARS = 6000 characters>`.
  The re-ask is a new request (own hash); its sends are marked `"followup": "validation"`; the call record lists it
  under `"followups"`. A second refusal voids the call with `"reason": "invalid:<message>"` exactly as today.
  Row-level voiding (B1: only the invalid ROW is voided after the re-ask) is the analyst group's: it happens inside
  the analyst's `check`, which raises only when no row is usable; the wrapper re-asks on that raise.
- `fields(value, required, optional)` requires the `required` keys and IGNORES other keys (B5: "extra keys tolerated
  everywhere"); callers that copy a fixed key set (examiner `_edit`, analyst rows) already drop extras.
- New `clipped(value, limit, name=)` for archival-only texts (reasons, rationales, notes): clipped with " [...]",
  never a reason to void. New `reasoned(key, allowed)` validator (section 3) uses it for the reason.
- Every validator message says what was wrong, because the model reads it (`text`, `items`, `fields`, `parse`,
  examiner `_judgment`, `_edit`, `_edits`).
- Roles that keep a registered single call pass `followups=False`: the pre-launch rubric writer (its two identical
  attempts of registration section 22, verified by `prelaunch.verify_texts` send by send), the researcher's three
  calls per round (the 8-call ceiling of section 7 counts requests) and the rewriter (`REWRITE_CALLS = 1`, "never
  retried"). Those edits are in texts.py and research.py (cross-group, section 8).
- `Rule()` constraints the model is not told (whitespace, '#'-leading line, length): skill.py is the P1 group's;
  the wrapper forwards whatever `ValueError` message `Rule()` raises into the re-ask notice, so once skill.py strips
  whitespace server-side and `Rule`'s `require` messages name the remaining constraints, the model sees them.

"""Method-role calls (registration §4, §6-§9, §13.5; v4 B5, B17, P4).

Every method role -- analyst, rubric judge, diagnosis, rubric reviser, researcher, rewriter, forward-item writer and
checker, leakage adjudicator, applicability judge, the pre-launch instruction and rubric writers -- is GLM-5.3
(reasoning low, temperature 0; v4 P4: a voting role's samples at ``ROLE_VOTE_TEMPERATURE``) behind the call wrapper
of its unit attempt (``calls.Endpoint``: reservation, settlement, identical resends of a call that delivered nothing).
A role's reply must be one JSON object -- the whole reply, or the whole reply inside one ```json fence -- that the
role's validator accepts; anything else is an invalid reply: it is recorded and the role's registered fallback applies
(§4). A stop of the run -- a budget stop, a broken reservation assumption, a ledger failure, a receipt that is not a
mapping -- is raised and pauses the unit; it is never mistaken for an invalid reply.

v4 B17 and B5 (``Roles.ask``, ``followups``): a reply cut off at the token limit is sent again once with a notice
(``TRUNCATED_NOTICE``); a reply the validator refuses is asked again once with the validator's message and the refused
reply (``REASK_NOTICE``; the reply clipped to ``REASK_REPLY_CHARS``). A follow-up is a new request -- the original
payload with a ``notice`` (and ``previous_reply``) -- with its own hash, marked on its sends and listed in the call's
``followups``; a second truncation or a second refusal voids the call with its reason. At most one follow-up of each
kind, so a call sends at most three requests (each with the wrapper's identical resends of a request that delivered
nothing); a re-ask may exceed a caller's input bound (``ROLE_INPUT_BYTES``) by the clipped reply and the notice only.
A validator refuses only what the prompt states (B5): an object is read for the keys the role must give and other keys
are ignored (``fields``); an archival-only text over its limit is clipped, never refused (``clipped``); every message
names what was wrong, since the model reads it. The pre-launch writers (their registered attempts, §22, verified by
``prelaunch.verify_texts``), the researcher (the call ceiling of §7) and the rewriter (one call, never retried) pass
``followups=False``.

v4 P4 (``vote``, ``Roles.vote``, ``reasoned``): a reason-then-label role -- the diagnosis, the leakage adjudicator, the
applicability judge, the forward checker -- is sampled ``ROLE_VOTES`` times at ``ROLE_VOTE_TEMPERATURE``, each sample a
call of its own (``<label>/v1``, ...) with B5's re-ask; a label that more than half of the samples carry decides, else
the role's registered tie label; the tally and every sample's reason go to the caller's record.
"""
from __future__ import annotations

import json
import re
from collections import Counter

from skillopt.continual_eval.core import require

from .calls import _request_hash
from .outcomes import ConfigurationError
from .protocol import REASK_REPLY_CHARS, ROLE_REASON_CHARS, ROLE_VOTE_TEMPERATURE, ROLE_VOTES

FENCE = re.compile(r"```(?:json)?[ \t]*\n(.*)\n[ \t]*```", re.S)
NAME = re.compile(r"[a-z][a-z0-9_]{0,39}")
CLIP = " [...]"
TRUNCATED_NOTICE = "Your previous reply was cut off at the token limit; answer more concisely."
REASK_NOTICE = "Your previous reply failed validation: %s. Reply with the corrected JSON only."
RESERVED = ("notice", "previous_reply")  # a follow-up's keys in the payload (B5/B17); no caller sends them
PROBLEM_CHARS = 300  # of a validator's message as the model reads it; the record keeps 80 characters, as before


class Invalid(ValueError):
    """A reply that is not what the role must return; its message says what was wrong (v4 B5: the model reads it)."""


def parse(text):
    """The JSON object a role replied: the whole reply, or the whole reply inside one fence."""
    if type(text) is not str:
        raise Invalid("the reply has no text")
    body = text.strip()
    fenced = FENCE.fullmatch(body)
    if fenced is not None:
        body = fenced.group(1).strip()
    try:
        value = json.loads(body)
    except ValueError:
        raise Invalid("the reply is not JSON; reply with one JSON object only") from None
    if type(value) is not dict:
        raise Invalid("the reply is not a JSON object")
    return value


def fields(value, required, optional=()):
    """``value`` is an object with every ``required`` key; v4 B5: other keys are tolerated and ignored (``optional``
    documents the keys a caller reads besides the required ones). The message names the missing keys."""
    if type(value) is not dict:
        raise Invalid("not a JSON object")
    missing = [key for key in required if key not in value]
    if missing:
        raise Invalid("missing field(s): " + ", ".join(missing))
    return value


def text(value, *, limit, empty=False, name="text"):
    """A text the protocol reads: a string, nonblank unless ``empty``, of at most ``limit`` characters; the message
    names the field (``name``)."""
    if type(value) is not str:
        raise Invalid("%s must be a string" % name)
    if not empty and not value.strip():
        raise Invalid("%s must not be empty" % name)
    if len(value) > limit:
        raise Invalid("%s has %d characters, at most %d are allowed" % (name, len(value), limit))
    return value


def clipped(value, limit, *, name="text"):
    """v4 B5: an archival-only text (a rationale, a reason, a note): a string, kept whole up to ``limit`` characters
    and clipped with a mark beyond -- its length is never a reason to void a reply."""
    if type(value) is not str:
        raise Invalid("%s must be a string" % name)
    return value if len(value) <= limit else value[:limit - len(CLIP)] + CLIP


def reasoned(key, allowed, *, limit=None):
    """v4 P4: the validator of a reason-then-label reply {"reason": <text>, <key>: one of ``allowed``} -- both keys
    required, other keys tolerated (B5), the reason clipped to ``limit`` (``ROLE_REASON_CHARS``) characters for the
    archive. Returns {"reason", key}."""
    allowed, limit = set(allowed), ROLE_REASON_CHARS if limit is None else limit

    def check(value):
        fields(value, ["reason", key])
        label = value[key]
        if type(label) is not str or label not in allowed:
            raise Invalid("%s must be one of: %s" % (key, ", ".join(sorted(allowed))))
        return {"reason": clipped(value["reason"], limit, name="reason"), key: label}
    return check


def message_bytes(user):
    """The UTF-8 size of ``user`` as ``Roles.ask`` sends it."""
    return len(json.dumps(user, ensure_ascii=False, sort_keys=True).encode())


def fit(user, key, budget):
    """v3 §6: leave out the last entries of ``user[key]`` (a list, in its shown order) until the message has at most
    ``budget`` bytes; ``user[key + "_omitted"]`` says how many were left out. Deterministic; returns ``user``. A message
    whose other fields alone exceed the budget is never sent: ValueError (the unit pauses)."""
    entries = list(user[key])
    user[key + "_omitted"] = 0
    while entries and message_bytes(user) > budget:
        entries.pop()
        user[key], user[key + "_omitted"] = list(entries), user[key + "_omitted"] + 1
    if message_bytes(user) > budget:
        raise ValueError("A role input exceeds its bound with no example left")
    return user


def items(value, *, limit, low=0, name="list"):
    """A list of ``low`` to ``limit`` entries; the message names the field (``name``)."""
    if type(value) is not list:
        raise Invalid("%s must be a list" % name)
    if not low <= len(value) <= limit:
        raise Invalid("%s has %d entries, %d to %d are allowed" % (name, len(value), low, limit))
    return value


def problem(error):
    """What a validator refused, as the re-ask notice and the record say it: a validator's own message (``Invalid``,
    or a ``ValueError`` of a protocol check such as ``skill.Rule``), else the error's type with its message."""
    if isinstance(error, ValueError):
        found = str(error) or type(error).__name__
    else:
        found = type(error).__name__ + (": " + str(error) if str(error) else "")
    return found[:PROBLEM_CHARS]


def majority(labels, *, votes=None):
    """v4 P4: the label more than half of ``votes`` samples carry (``labels``: one per sample, None for an invalid
    one), else None."""
    votes = ROLE_VOTES if votes is None else votes
    tally = Counter(label for label in labels if label is not None)
    if not tally:
        return None
    label, count = tally.most_common(1)[0]
    return label if 2 * count > votes else None


def vote(call, parse, label_of, tie, *, votes=None):
    """v4 P4, the generic helper: ``call(n)`` makes sample ``n`` (1-based) and returns its reply, or None when the
    call delivered nothing usable; ``parse(reply)`` returns the validated reply or raises ``Invalid`` (``ValueError``);
    ``label_of(parsed)`` returns its label, a string; ``tie`` is the label when no majority exists. Returns (label,
    record): {"label", "majority": whether a majority decided, "tally": {label: samples}, "invalid": samples without
    a label, "votes": [{"label", "reason", "valid"} per sample, in order]} -- every sample's reason is archived
    whatever the outcome. A stop of the run raised by a call propagates."""
    votes = ROLE_VOTES if votes is None else votes
    require(type(votes) is int and votes > 0 and callable(call) and callable(parse) and callable(label_of)
            and type(tie) is str, "Invalid vote")
    samples = []
    for n in range(1, votes + 1):
        reply, found = call(n), {"label": None, "reason": None, "valid": False}
        parsed = None
        if reply is not None:
            try:
                parsed = parse(reply)
            except (Invalid, ValueError, TypeError, KeyError):
                parsed = None
        if parsed is not None:
            label = label_of(parsed)
            require(type(label) is str, "A vote's label is a string")
            found = {"label": label, "reason": parsed.get("reason") if isinstance(parsed, dict) else None,
                     "valid": True}
        samples.append(found)
    decided = majority([s["label"] for s in samples], votes=votes)
    tally = Counter(s["label"] for s in samples if s["valid"])
    label = tie if decided is None else decided
    return label, {"label": label, "majority": decided is not None, "tally": dict(sorted(tally.items())),
                   "invalid": sum(not s["valid"] for s in samples), "votes": samples}


def _made(record, kind):
    return any(followup["kind"] == kind for followup in record["followups"])


def _reply_text(receipt, limit):
    """The refused reply as the re-ask shows it, clipped to ``limit`` characters."""
    value = receipt.get("response")
    return clipped(value if isinstance(value, str) else "", limit)


class Roles:
    """The method roles of one unit attempt. ``endpoint``: the attempt's GLM-5.3 endpoint for method roles. ``calls``:
    the record of every role call (kept in the unit's record): role, label, request hash, sends with their receipts
    (a follow-up's marked ``followup``), the follow-ups made (v4 B5/B17), and whether the reply was valid (else why
    not)."""

    def __init__(self, endpoint):
        self.endpoint, self.calls = endpoint, []

    def ask(self, role, system, user, *, label, check=None, temperature=None, followups=True):
        """The validated reply of one call, or None when it is invalid. ``user``: a JSON object (a dict), sent as
        compact JSON; ``check(value)`` returns the accepted value or raises ``Invalid`` (or ``ValueError``);
        ``temperature``: a voting role's sampling temperature (None: the client's own, 0). v4 B17/B5 (``followups``):
        one resend after a truncated reply, one re-ask after a refused reply (the module docstring); False keeps a
        registered single call."""
        require(NAME.fullmatch(role) is not None and type(system) is str and system.strip() and type(user) is dict
                and not any(key in user for key in RESERVED), "Invalid role call")
        message = json.dumps(user, ensure_ascii=False, sort_keys=True)
        recorder = self.endpoint.recorder(label=label)
        record = {"role": role, "label": label, "request_sha256": _request_hash(system, message),
                  "sends": recorder.sends, "valid": False, "reason": None, "followups": []}
        self.calls.append(record)
        kind = None  # what the request about to be sent is: the first one (None) or a follow-up's kind
        while True:
            start = len(recorder.sends)
            receipt = recorder(system, message, temperature=temperature)  # a stop of the run is raised from here
            if kind is not None:
                for send in recorder.sends[start:]:
                    send["followup"] = kind
            if recorder.invalid:
                raise ConfigurationError("invalid_model_receipt")
            if receipt.get("ok") is not True or receipt.get("finish_reason") != "stop":
                reason = "no_reply:" + str(receipt.get("error_type") or receipt.get("finish_reason"))[:40]
                if receipt.get("finish_reason") != "length" or not followups or _made(record, "truncation"):
                    record["reason"] = reason
                    return None
                kind, extra = "truncation", {"notice": TRUNCATED_NOTICE}
            else:
                try:
                    value = parse(receipt.get("response"))
                    value = check(value) if check is not None else value
                except (Invalid, ValueError, TypeError, KeyError) as error:
                    found = problem(error)
                    reason = "invalid:" + found[:80]
                    if not followups or _made(record, "validation"):
                        record["reason"] = reason
                        return None
                    kind, extra = "validation", {"notice": REASK_NOTICE % found,
                                                 "previous_reply": _reply_text(receipt, REASK_REPLY_CHARS)}
                else:
                    record["valid"] = True
                    return value
            message = json.dumps({**user, **extra}, ensure_ascii=False, sort_keys=True)
            record["followups"].append({"kind": kind, "after": reason,
                                        "request_sha256": _request_hash(system, message)})

    def vote(self, role, system, user, *, label, check, label_of, tie, votes=None):
        """v4 P4 for one role call: ``ROLE_VOTES`` samples of (``system``, ``user``) at ``ROLE_VOTE_TEMPERATURE``,
        each an ``ask`` of its own (labels ``<label>/v1``, ...; ``check`` validates each sample, with B5's re-ask),
        decided by ``vote``. Returns (label, record)."""
        return vote(lambda n: self.ask(role, system, user, label="%s/v%d" % (label, n), check=check,
                                       temperature=ROLE_VOTE_TEMPERATURE),
                    lambda value: value, label_of, tie, votes=votes)

    def plain(self, role, system, user, *, label):
        """The text of one call whose reply is plain text (the pre-launch instruction writer, whose user message is
        the plain text of the existing generator), or None when no complete reply arrived. No follow-up: the writer's
        registered single call (§22)."""
        require(NAME.fullmatch(role) is not None and type(user) is str and user.strip(), "Invalid role call")
        recorder = self.endpoint.recorder(label=label)
        record = {"role": role, "label": label, "request_sha256": _request_hash(system, user), "sends": None,
                  "valid": False, "reason": None}
        self.calls.append(record)
        try:
            receipt = recorder(system, user)
        finally:
            record["sends"] = recorder.sends
        if recorder.invalid:
            raise ConfigurationError("invalid_model_receipt")
        if receipt.get("ok") is not True or receipt.get("finish_reason") != "stop" or type(receipt.get("response")) \
                is not str:
            record["reason"] = "no_reply:" + str(receipt.get("error_type") or receipt.get("finish_reason"))[:40]
            return None
        record["valid"] = True
        return receipt["response"]

    def count(self, prefix):
        """Calls whose label starts with ``prefix`` (the per-request ceilings of §7 and §8; v4: a vote's samples
        count one each)."""
        return sum(1 for record in self.calls if record["label"].startswith(prefix))
```

## 2. B17: a role reply truncated at ROLE_MAX_TOKENS is sent again once

- `roles.reasoned(key, allowed, *, limit=None) -> check`: validates `{"reason": str, key: one of allowed}` (other

- `roles.vote(call, parse, label_of, tie, *, votes=None) -> (label, record)`: `call(n)` (n = 1..ROLE_VOTES) returns

    """{answer key: {"code", "by"(, "votes")}} for every failed answer (one per failed run) of both halves; v4 B8:
    ``by_item`` gives the per-item code every later step reads."""

                                                  label="%s/%s" % (label, a["key"])), failures, workers=workers)
    return {a["key"]: r for a, r in zip(failures, results)}


def by_item(diagnoses, failures):
    """v4 B8: one code per failed ITEM from the diagnoses of its failed runs: the most frequent code over the item's
    failed runs; when several codes are equally frequent, the code of the lowest run index. {item: {"code", "by":
    "majority" | "lowest_run", "tally": {code: runs}, "runs": [{"key", "run", "code"} in run order]}} for every item
    of ``failures`` (the failed answers of both halves, one per failed run, as ``step.answers`` reads them)."""
    runs = {}
    for answer in sorted(failures, key=lambda a: (a["item"], a["run"])):
        runs.setdefault(answer["item"], []).append({"key": answer["key"], "run": answer["run"],
                                                   "code": diagnoses[answer["key"]]["code"]})
    out = {}
    for item, found in runs.items():
        tally = Counter(r["code"] for r in found)
        top = max(tally.values())
        leaders = [code for code, n in tally.items() if n == top]
        code, by = (leaders[0], "majority") if len(leaders) == 1 else (found[0]["code"], "lowest_run")
        out[item] = {"code": code, "by": by, "tally": dict(sorted(tally.items())), "runs": found}
    return out


def item_failures(failures, diagnoses):
    """v4 B8 for the analyst (P6): the failed items of ``failures`` in item order, each with its code (``by_item``) and
    its failed runs' answers in run order -- one example per item, never the same item twice."""

    runs = {}

        runs.setdefault(answer["item"], []).append(answer)
    return [{"item": item, "code": codes[item]["code"], "by": codes[item]["by"], "runs": found}
            for item, found in sorted(runs.items())]
