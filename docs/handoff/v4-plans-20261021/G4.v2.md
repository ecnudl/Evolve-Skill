## 1. B5: re-ask with the validator's message; extra keys tolerated; archival truncation

### 1.1 What changes (semantics)

- `Roles.ask` (every validated role call) makes at most ONE re-ask after a refused reply (`reask=True`, the default):
  the same system prompt, the original payload plus `"notice": "Your previous reply failed validation: <validator
  message>. Reply with the corrected JSON only."` and `"previous_reply": <the refused reply, clipped to
  REASK_REPLY_CHARS = 6000 characters>`. The re-ask is a new request (own hash); its sends are marked `"followup":
  "validation"`; the call record lists it under `"followups"`. A second refusal voids the call with `"reason":
  "invalid:<message, 80 characters>"` exactly as today. The notice carries up to `PROBLEM_CHARS = 2000` characters of
  the message (the analyst's per-row messages, about 300 characters each, joined). Row-level voiding (B1: only the
  invalid ROW is voided after the re-ask) is G1's: it happens inside the analyst's `check`, which raises only when no
  row is usable; the wrapper re-asks on that raise.
- B17 (`resend=True`, the default): one resend after a reply cut off at `ROLE_MAX_TOKENS` (section 2). A follow-up is
  built from the last follow-up's content: a resend after a re-ask keeps the validator's message and the refused reply
  and adds the truncation notice; a re-ask after a resend carries the validator's message only (the resend's reply was
  complete).
- Only the message of an `Invalid` (the validators') or of a `ValueError` (a protocol check such as `skill.Rule`'s
  `require`, whose constraints B5 wants the model to read) reaches the notice and the record; any other error a
  validator raises (`TypeError`, `KeyError`: a reply of an unexpected shape) is told to the model as the fixed text "a
  value of the wrong type or a missing entry" and recorded by its type name, exactly as v3 recorded it.
- `fields(value, required, optional)` requires the `required` keys, IGNORES other keys (B5: "extra keys tolerated
  everywhere") and returns the projection on `required` and `optional` -- identical to v3's return value for every
  reply v3 accepted, so a tolerated extra key never reaches a record or another role's input through it (research.py
  `_conclusion` returns it; the quote copy at research.py line 489 is narrowed to page and text, section 1.7).
- New `clipped(value, limit, name=)` for archival-only texts (reasons, rationales, notes, the reviser's `basis`):
  clipped with " [...]", never a reason to void. New `reasoned(key, allowed)` validator (section 3) uses it for the
  reason.
- Every validator message says what was wrong, because the model reads it (`text`, `items`, `fields`, `parse`,
  examiner `_judgment`, `_edit`, `_edits`).
- `Roles.record(label)` returns the record of the call with that label (race-free under `run_parallel`, unlike
  `roles.calls[-1]`); a caller counts its own follow-ups there (G1's `attempts`).
- Calls with a registered retry rule of their own keep it and pass `reask=False, resend=False` (section 1.7): the
  pre-launch rubric writer (two identical attempts, registration section 22, verified send by send by
  `prelaunch.verify_texts`), the self-test revision (two identical attempts, `SELFTEST_ATTEMPTS`, v3 section 7: the
  loop already sends again after a refused or truncated reply), the researcher's three calls per round (the request
  ceiling of section 7 counts requests) and the rewriter (`REWRITE_CALLS = 1`, "never retried"). This is a named,
  registered exemption, not a silent narrowing: each is one keyword at its call site.
- `Rule()` constraints the model is not told (whitespace, '#'-leading line, length): skill.py is the P1 group's;
  the wrapper forwards the `ValueError` message `Rule()` raises into the re-ask notice, so once skill.py strips
  whitespace server-side and `Rule`'s `require` messages name the remaining constraints, the model sees them.

```python
"""Method-role calls (registration §4, §6-§9, §13.5; v4 B5, B17, P4).

Every method role -- analyst, rubric judge, diagnosis, rubric reviser, researcher, rewriter, forward-item writer and
checker, leakage adjudicator, applicability judge, the pre-launch instruction and rubric writers -- is GLM-5.3
(reasoning low, temperature 0; v4 P4: a voting role's samples at ``ROLE_VOTE_TEMPERATURE``) behind the call wrapper
of its unit attempt (``calls.Endpoint``: reservation, settlement, identical resends of a call that delivered nothing).
A role's reply must be one JSON object -- the whole reply, or the whole reply inside one ```json fence -- that the
role's validator accepts; anything else is an invalid reply: it is recorded and the role's registered fallback applies
(§4). A stop of the run -- a budget stop, a broken reservation assumption, a ledger failure, a receipt that is not a
mapping -- is raised and pauses the unit; it is never mistaken for an invalid reply.

v4 B17 and B5 (``Roles.ask``, ``resend``, ``reask``): a reply cut off at the token limit is sent again once with a
notice (``TRUNCATED_NOTICE``); a reply the validator refuses is asked again once with the validator's message and the
refused reply (``REASK_NOTICE``; the reply clipped to ``REASK_REPLY_CHARS``, the message to ``PROBLEM_CHARS``). A
follow-up is a new request -- the original payload with a ``notice`` (and ``previous_reply``) -- with its own hash,
marked on its sends and listed in the call's ``followups``; a resend after a re-ask keeps the re-ask's content and adds
the truncation notice. A second truncation or a second refusal voids the call with its reason. At most one follow-up of
each kind, so a call sends at most three requests (each with the wrapper's identical resends of a request that
delivered nothing); a follow-up may exceed a caller's input bound (``ROLE_INPUT_BYTES``) by the clipped reply and the
notice only. A validator refuses only what the prompt states (B5): an object is read for the keys the role must give,
other keys are ignored and never returned (``fields``); an archival-only text over its limit is clipped, never refused
(``clipped``); every message names what was wrong, since the model reads it -- only a validator's own message
(``Invalid``) or a protocol check's (``ValueError``), never another error's text. The calls with a registered retry
rule of their own -- the pre-launch rubric writer (§22, verified by ``prelaunch.verify_texts``), the self-test revision
(v3 §7), the researcher (the call ceiling of §7) and the rewriter (one call, never retried) -- pass ``reask=False,
resend=False``.

v4 P4 (``vote``, ``Roles.vote``, ``reasoned``): a reason-then-label role -- the diagnosis, the leakage adjudicator, the
applicability judge, the forward checker -- is sampled ``ROLE_VOTES`` times at ``ROLE_VOTE_TEMPERATURE``, each sample a
call of its own (``<label>/v1``, ...) with B5's re-ask; a label that more than half of the samples carry decides, else
the role's registered tie label; the tally and every sample's reason go to the caller's record.
"""
from __future__ import annotations

import json
import re
from collections import Counter

from skillopt.continual_eval.core import require

from .calls import _request_hash
from .outcomes import ConfigurationError
from .protocol import REASK_REPLY_CHARS, ROLE_REASON_CHARS, ROLE_VOTE_TEMPERATURE, ROLE_VOTES

FENCE = re.compile(r"```(?:json)?[ \t]*\n(.*)\n[ \t]*```", re.S)
NAME = re.compile(r"[a-z][a-z0-9_]{0,39}")
CLIP = " [...]"
TRUNCATED_NOTICE = "Your previous reply was cut off at the token limit; answer more concisely."
REASK_NOTICE = "Your previous reply failed validation: %s. Reply with the corrected JSON only."
RESERVED = ("notice", "previous_reply")  # a follow-up's keys in the payload (B5/B17); no caller sends them
PROBLEM_CHARS = 2000  # of a validator's message as the model reads it (a row-wise check joins its rows' messages)
REASON_CHARS = 80  # of the same message in the call record, as before
WRONG_VALUE = "a value of the wrong type or a missing entry"  # what the model reads of any other error (B5)


class Invalid(ValueError):
    """A reply that is not what the role must return; its message says what was wrong (v4 B5: the model reads it)."""


def parse(text):
    """The JSON object a role replied: the whole reply, or the whole reply inside one fence."""
    if type(text) is not str:
        raise Invalid("the reply has no text")
    body = text.strip()
    fenced = FENCE.fullmatch(body)
    if fenced is not None:
        body = fenced.group(1).strip()
    try:
        value = json.loads(body)
    except ValueError:
        raise Invalid("the reply is not JSON; reply with one JSON object only") from None
    if type(value) is not dict:
        raise Invalid("the reply is not a JSON object")
    return value


def fields(value, required, optional=()):
    """``value`` is an object with every ``required`` key; v4 B5: other keys are tolerated and ignored. Returns the
    projection of ``value`` on ``required`` and ``optional`` (the keys a caller may read) -- for every reply v3 accepted
    the same object v3 returned, so an extra key never reaches a record or another role's input through it. The
    message names the missing keys."""
    if type(value) is not dict:
        raise Invalid("not a JSON object")
    missing = [key for key in required if key not in value]
    if missing:
        raise Invalid("missing field(s): " + ", ".join(missing))
    return {key: value[key] for key in (*required, *optional) if key in value}


def text(value, *, limit, empty=False, name="text"):
    """A text the protocol reads: a string, nonblank unless ``empty``, of at most ``limit`` characters; the message
    names the field (``name``)."""
    if type(value) is not str:
        raise Invalid("%s must be a string" % name)
    if not empty and not value.strip():
        raise Invalid("%s must not be empty" % name)
    if len(value) > limit:
        raise Invalid("%s has %d characters, at most %d are allowed" % (name, len(value), limit))
    return value


def clipped(value, limit, *, name="text"):
    """v4 B5: an archival-only text (a rationale, a reason, a note, a basis): a string, kept whole up to ``limit``
    characters and clipped with a mark beyond -- its length is never a reason to void a reply."""
    if type(value) is not str:
        raise Invalid("%s must be a string" % name)
    return value if len(value) <= limit else value[:limit - len(CLIP)] + CLIP


def reasoned(key, allowed, *, limit=None):
    """v4 P4: the validator of a reason-then-label reply {"reason": <text>, <key>: one of ``allowed``} -- both keys
    required, other keys tolerated (B5), the reason clipped to ``limit`` (``ROLE_REASON_CHARS``) characters for the
    archive. Returns {"reason", key}."""
    allowed, limit = set(allowed), ROLE_REASON_CHARS if limit is None else limit

    def check(value):
        fields(value, ["reason", key])
        label = value[key]
        if type(label) is not str or label not in allowed:
            raise Invalid("%s must be one of: %s" % (key, ", ".join(sorted(allowed))))
        return {"reason": clipped(value["reason"], limit, name="reason"), key: label}
    return check


def message_bytes(user):
    """The UTF-8 size of ``user`` as ``Roles.ask`` sends it."""
    return len(json.dumps(user, ensure_ascii=False, sort_keys=True).encode())


def fit(user, key, budget):
    """v3 §6: leave out the last entries of ``user[key]`` (a list, in its shown order) until the message has at most
    ``budget`` bytes; ``user[key + "_omitted"]`` says how many were left out. Deterministic; returns ``user``. A message
    whose other fields alone exceed the budget is never sent: ValueError (the unit pauses)."""
    entries = list(user[key])
    user[key + "_omitted"] = 0
    while entries and message_bytes(user) > budget:
        entries.pop()
        user[key], user[key + "_omitted"] = list(entries), user[key + "_omitted"] + 1
    if message_bytes(user) > budget:
        raise ValueError("A role input exceeds its bound with no example left")
    return user


def items(value, *, limit, low=0, name="list"):
    """A list of ``low`` to ``limit`` entries; the message names the field (``name``)."""
    if type(value) is not list:
        raise Invalid("%s must be a list" % name)
    if not low <= len(value) <= limit:
        raise Invalid("%s has %d entries, %d to %d are allowed" % (name, len(value), low, limit))
    return value


def problem(error):
    """What a validator refused, as the re-ask notice says it (at most ``PROBLEM_CHARS`` characters): the message of an
    ``Invalid`` (a validator's own) or of a ``ValueError`` (a protocol check such as ``skill.Rule``'s ``require``); any
    other error (a reply of an unexpected shape: ``TypeError``, ``KeyError``) as the fixed ``WRONG_VALUE`` -- no other
    error's text reaches a role's input."""
    if isinstance(error, ValueError):
        return (str(error) or type(error).__name__)[:PROBLEM_CHARS]
    return WRONG_VALUE


def _recorded(error):
    """The record's reason for a refused reply: the message (80 characters) of an ``Invalid`` or ``ValueError``, else
    the error's type name, as v3 recorded it."""
    found = problem(error) if isinstance(error, ValueError) else type(error).__name__
    return "invalid:" + found[:REASON_CHARS]


def majority(labels, *, votes=None):
    """v4 P4: the label more than half of ``votes`` samples carry (``labels``: one per sample, None for an invalid
    one), else None."""
    votes = ROLE_VOTES if votes is None else votes
    tally = Counter(label for label in labels if label is not None)
    if not tally:
        return None
    label, count = tally.most_common(1)[0]
    return label if 2 * count > votes else None


def vote(call, parse, label_of, tie, *, votes=None):
    """v4 P4, the generic helper: ``call(n)`` makes sample ``n`` (1-based) and returns its reply, or None when the
    call delivered nothing usable; ``parse(reply)`` returns the validated reply or raises ``Invalid`` (``ValueError``);
    ``label_of(parsed)`` returns its label, a string; ``tie`` is the label when no majority exists. Returns (label,
    record): {"label", "majority": whether a majority decided, "tally": {label: samples}, "invalid": samples without
    a label, "votes": [{"label", "reason", "valid"} per sample, in order]} -- every sample's reason is archived
    whatever the outcome. A stop of the run raised by a call propagates."""
    votes = ROLE_VOTES if votes is None else votes
    require(type(votes) is int and votes > 0 and callable(call) and callable(parse) and callable(label_of)
            and type(tie) is str, "Invalid vote")
    samples = []
    for n in range(1, votes + 1):
        reply, found = call(n), {"label": None, "reason": None, "valid": False}
        parsed = None
        if reply is not None:
            try:
                parsed = parse(reply)
            except (Invalid, ValueError, TypeError, KeyError):
                parsed = None
        if parsed is not None:
            label = label_of(parsed)
            require(type(label) is str, "A vote's label is a string")
            found = {"label": label, "reason": parsed.get("reason") if isinstance(parsed, dict) else None,
                     "valid": True}
        samples.append(found)
    decided = majority([s["label"] for s in samples], votes=votes)
    tally = Counter(s["label"] for s in samples if s["valid"])
    label = tie if decided is None else decided
    return label, {"label": label, "majority": decided is not None, "tally": dict(sorted(tally.items())),
                   "invalid": sum(not s["valid"] for s in samples), "votes": samples}


def _made(record, kind):
    return any(followup["kind"] == kind for followup in record["followups"])


def _reply_text(receipt, limit):
    """The refused reply as the re-ask shows it, clipped to ``limit`` characters."""
    value = receipt.get("response")
    return clipped(value if isinstance(value, str) else "", limit)


def _followup(user, made):
    """The payload of a follow-up: the original ``user`` with the notice(s) of ``made`` -- the validator's message (and
    the refused reply) once a re-ask was made, then the truncation notice when the last reply was cut off."""
    notice = " ".join(made[key] for key in ("refused", "truncated") if key in made)
    return {**user, "notice": notice, **({"previous_reply": made["previous_reply"]} if "previous_reply" in made else {})}


class Roles:
    """The method roles of one unit attempt. ``endpoint``: the attempt's GLM-5.3 endpoint for method roles. ``calls``:
    the record of every role call (kept in the unit's record): role, label, request hash, sends with their receipts
    (a follow-up's marked ``followup``), the follow-ups made (v4 B5/B17), and whether the reply was valid (else why
    not)."""

    def __init__(self, endpoint):
        self.endpoint, self.calls = endpoint, []

    def ask(self, role, system, user, *, label, check=None, temperature=None, reask=True, resend=True):
        """The validated reply of one call, or None when it is invalid. ``user``: a JSON object (a dict), sent as
        compact JSON; ``check(value)`` returns the accepted value or raises ``Invalid`` (or ``ValueError``);
        ``temperature``: a voting role's sampling temperature (None: the client's own, 0). v4 B17 (``resend``): one
        resend after a truncated reply; v4 B5 (``reask``): one re-ask after a refused reply (the module docstring);
        False keeps a registered retry rule of the caller's own."""
        require(NAME.fullmatch(role) is not None and type(system) is str and system.strip() and type(user) is dict
                and not any(key in user for key in RESERVED), "Invalid role call")
        message = json.dumps(user, ensure_ascii=False, sort_keys=True)
        recorder = self.endpoint.recorder(label=label)
        record = {"role": role, "label": label, "request_sha256": _request_hash(system, message),
                  "sends": recorder.sends, "valid": False, "reason": None, "followups": []}
        self.calls.append(record)
        kind, made = None, {}  # what the request about to be sent is (None: the first), and the follow-ups' content
        while True:
            start = len(recorder.sends)
            receipt = recorder(system, message, temperature=temperature)  # a stop of the run is raised from here
            if kind is not None:
                for send in recorder.sends[start:]:
                    send["followup"] = kind
            if recorder.invalid:
                raise ConfigurationError("invalid_model_receipt")
            if receipt.get("ok") is not True or receipt.get("finish_reason") != "stop":
                reason = "no_reply:" + str(receipt.get("error_type") or receipt.get("finish_reason"))[:40]
                if receipt.get("finish_reason") != "length" or not resend or _made(record, "truncation"):
                    record["reason"] = reason
                    return None
                kind, made["truncated"] = "truncation", TRUNCATED_NOTICE
            else:
                try:
                    value = parse(receipt.get("response"))
                    value = check(value) if check is not None else value
                except (Invalid, ValueError, TypeError, KeyError) as error:
                    reason = _recorded(error)
                    if not reask or _made(record, "validation"):
                        record["reason"] = reason
                        return None
                    made.pop("truncated", None)  # the refused reply was complete
                    kind = "validation"
                    made.update(refused=REASK_NOTICE % problem(error),
                                previous_reply=_reply_text(receipt, REASK_REPLY_CHARS))
                else:
                    record["valid"] = True
                    return value
            message = json.dumps(_followup(user, made), ensure_ascii=False, sort_keys=True)
            record["followups"].append({"kind": kind, "after": reason,
                                        "request_sha256": _request_hash(system, message)})

    def vote(self, role, system, user, *, label, check, label_of, tie, votes=None):
        """v4 P4 for one role call: ``ROLE_VOTES`` samples of (``system``, ``user``) at ``ROLE_VOTE_TEMPERATURE``,
        each an ``ask`` of its own (labels ``<label>/v1``, ...; ``check`` validates each sample, with B5's re-ask and
        B17's resend), decided by ``vote``. Returns (label, record) -- a tuple (section 8 of the v4 plan)."""
        return vote(lambda n: self.ask(role, system, user, label="%s/v%d" % (label, n), check=check,
                                       temperature=ROLE_VOTE_TEMPERATURE),
                    lambda value: value, label_of, tie, votes=votes)

    def record(self, label):
        """v4 B5: the record of the call labelled ``label`` (the last one, should a label repeat) -- how a caller reads
        its own call's follow-ups, race-free under parallel calls (``calls[-1]`` may be another thread's)."""
        found = [record for record in list(self.calls) if record["label"] == label]
        require(bool(found), "No role call has the label %s" % label)
        return found[-1]

    def plain(self, role, system, user, *, label):
        """The text of one call whose reply is plain text (the pre-launch instruction writer, whose user message is
        the plain text of the existing generator), or None when no complete reply arrived. No follow-up: the writer's
        registered single call (§22)."""
        require(NAME.fullmatch(role) is not None and type(user) is str and user.strip(), "Invalid role call")
        recorder = self.endpoint.recorder(label=label)
        record = {"role": role, "label": label, "request_sha256": _request_hash(system, user), "sends": None,
                  "valid": False, "reason": None}
        self.calls.append(record)
        try:
            receipt = recorder(system, user)
        finally:
            record["sends"] = recorder.sends
        if recorder.invalid:
            raise ConfigurationError("invalid_model_receipt")
        if receipt.get("ok") is not True or receipt.get("finish_reason") != "stop" or type(receipt.get("response")) \
                is not str:
            record["reason"] = "no_reply:" + str(receipt.get("error_type") or receipt.get("finish_reason"))[:40]
            return None
        record["valid"] = True
        return receipt["response"]

    def count(self, prefix):
        """Calls whose label starts with ``prefix`` (the per-request ceilings of §7 and §8; v4: a vote's samples
        count one each; a call's follow-ups are inside its one record)."""
        return sum(1 for record in self.calls if record["label"].startswith(prefix))
```

def by_item(diagnoses, failures):
    """v4 B8: one code per failed ITEM from the diagnoses of its failed runs: the most frequent code over the item's
    failed runs; among equally frequent codes, the one whose first failed run has the lowest run index. {item: {"code",
    "by": "majority" | "lowest_run", "tally": {code: runs}, "runs": [{"key", "run", "code"} in run order]}} for every
    item of ``failures`` (the failed answers of both halves, one per failed run, as ``step.answers`` reads them)."""
    runs = {}
    for answer in sorted(failures, key=lambda a: (a["item"], a["run"])):
        runs.setdefault(answer["item"], []).append({"key": answer["key"], "run": answer["run"],
                                                   "code": diagnoses[answer["key"]]["code"]})
    out = {}
    for item, found in runs.items():
        tally, first = Counter(r["code"] for r in found), {}
        for r in found:
            first.setdefault(r["code"], r["run"])
        leaders = [code for code, n in tally.items() if n == max(tally.values())]
        out[item] = {"code": min(leaders, key=first.get), "by": "majority" if len(leaders) == 1 else "lowest_run",
                     "tally": dict(sorted(tally.items())), "runs": found}
    return out


def item_codes(*, diagnoses, failures):
    """v4 B8, the per-item code every later step reads (the analyst's examples and evidence check, a rule's codes,
    the applicability judge's precision and recall): {item: its code} (``by_item``) for every item of ``failures`` --
    failed answers of either half, one per failed run. Keyword-only: one call form for every caller."""
    return {item: value["code"] for item, value in by_item(diagnoses, failures).items()}


def item_failures(failures, diagnoses):

# -------------------------------------------------------------------------------------------- the caps (v4 §0)
def test_v4_role_caps_are_the_registered_arithmetic():
    """v4 §0: a deepseek chain's step cap is the step's high-cost role volume rounded up to the million; E's and I's
    caps grew by the same increase over v3; the chain caps are the sums; the pre-launch cap covers the smoke's two
    stages at the same cost. Structural: it reads every group's final constants (G1's ANALYST_MAX_CODES, G6's
    RESEARCH_MAX_CALLS), so a constant that moves a cap fails here until the literals are recomputed."""
    from skillopt.coevo5 import prelaunch, protocol, smoke

    m = protocol.M
    v3 = {"E": {"searchqa": 60, "officeqa": 55, "livemath": 65, "spreadsheetbench": 45, "alfworld": 135},
          "I": {"searchqa": 90, "officeqa": 70, "livemath": 85, "spreadsheetbench": 65, "alfworld": 225},
          "ds": {"searchqa": 10, "officeqa": 6, "livemath": 6, "spreadsheetbench": 4, "alfworld": 3}}

    def up(tokens):
        return -(-tokens // m) * m

    assert (protocol.role_tokens("short"), protocol.role_tokens("long")) == (8000, 106670)
    assert protocol.role_tokens("view", "officeqa") == 20311 and protocol.role_tokens("view", "searchqa") == 8000
    for bench in protocol.ORDER:
        ds = up(protocol.role_volume(bench))
        assert protocol.LEARNING_CAP["ds"][bench] == ds > v3["ds"][bench] * m
        for kind in ("E", "I"):
            assert protocol.LEARNING_CAP[kind][bench] == (v3[kind][bench] - v3["ds"][bench]) * m + ds
    assert protocol.CHAIN_CAP["E-ds"] == protocol.CHAIN_CAP["I-ds"] == sum(protocol.LEARNING_CAP["ds"].values())
    for chain_name, kind in (("E-glm", "E"), ("I-glm", "I")):
        assert protocol.CHAIN_CAP[chain_name] == (protocol.STAGE0_EVALUATION_CAP[kind]
                                                  + sum(protocol.LEARNING_CAP[kind].values())
                                                  + len(protocol.ORDER) * protocol.EVALUATION_CAP[kind])
    drawn = sum(protocol.role_volume(bench, draw) for bench, draw in smoke.DRAW.items())
    assert prelaunch.PRELAUNCH_CAP == up(prelaunch.TEXTS_CAP + drawn + m)
    assert sum(protocol.CHAIN_CAP.values()) > protocol.OVERALL_CEILING == 1160 * m  # the ceiling binds
    assert protocol.ROLE_VOTES == 3 and protocol.ROLE_VOTE_TEMPERATURE == 0.7 and protocol.REASK_REPLY_CHARS == 6000
