From A9, 2026-10-22. Plan §2.6, §2.7, §6; registration §3.3, §3.4, §6.1-§6.5, §7.2.

How the CLI or unit driver uses A9's modules (zero model calls until `dispatch`):

1. Register A (and LiveMath's J7 probe, purpose `accept_probe`) in the registry first. Then call
   `sealed = acceptance.prepare(root, chain=, bench=, step=, unit=, candidate=, parent=, views=, blocks=, workers=,
   trajectories=, rooms=, generate=, dup=, probe=, freshness=, mde=)`. This writes `<root>/sealed.json` once.
   - `views`: {item: `solver.routing_view(bench, public)`} in slice order.
   - `blocks`: {item: block}; ALFWorld blocks are whole rooms.
   - `workers(package, item)`: router.plan's factory, also used for donor items.
   - `generate`: the examiner's frozen generator on the A* public views, returning [{"id", "source_item"}], at most
     `protocol.G_ACC[bench]`.
2. Call `acceptance.dispatch(sealed, registry, run, items={task_id: registered item record})`. A too-small A*
   releases every item (`routed_not_dispatched`) and returns []. Otherwise A* and the probe items are dispatched, and
   `run(block, jobs)` is called per block in the schedule's order (ticket A9-2).
   - Build each cell from `acceptance.cell_arm(sealed, job, cell=cell_id)`, which returns (package key in
     `sealed["packages"]`, arm kind, `solver.solve` keywords). Call `acceptance.check_packages(sealed, packages)`
     before the first cell.
   - Cell records need `arm`, `task_id`, `run`, `set`, `judge`, `faults`, `logical_calls`, `worst_delivery`,
     `sends`, `dispatch_ts` and `finish_ts`; A8's `cells.py` writes all of them.
3. Call `decision = acceptance.decide(cells, sealed)`, then `acceptance.write(root, decision)`, which writes
   `<root>/decision/decision.json` once, then `registry.decide(...)` for A* and the probe. On a redo,
   `donors.verify(sealed["corpus"], trajectories)` must pass. `acceptance.reproduce(cells, sealed, decision)`
   recomputes the decision from the records.
4. For validity (§7.2), take one `validity.round_pair(cells, sealed)` per round of a generator (None without G_acc),
   plus `validity.dup_control(cells, sealed)`. `validity.status(rounds, dup)` is not_evaluable below 8 rounds.
