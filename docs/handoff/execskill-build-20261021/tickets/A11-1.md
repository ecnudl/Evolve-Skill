## 1. `execskill.qualify.qualify`: keep the frozen signature and record shape (A12)

`generators/sheet.py` does NOT import `execskill.qualify`. It does not exist in the tree yet. Instead it calls an
injected `Engine.qualify` exactly like the frozen `coevo5/qualify.py:85`:

    record = engine.qualify([task], folder / "qualification", engine.runtime, side="train",
                            native=engine.native, workers=1)

It then reads two fields: `record["qualified"]`, a list of task ids (frozen :119-125), and
`record["scorings_per_item"]` (frozen :127). The `task` it passes is
`{"task_id": "gen:<generator>:<n>", "public": {...source public, "input_files": [new input]},
"private": {"test_files": [new reference], "answer_position": ...}}`. This is the shape the frozen
`reference_prediction` (:38-43) and `backends.score` read.

Request: `execskill.qualify.qualify` keeps this signature and these two fields. Its only change is the version stamp,
`fivebench-execskill-v1-sheet-qualification` instead of the v3 stamp at frozen :124 (Codex F15). If the record shape
changes, `sheet.apply` (lines 173-177) needs the same change. Tell A11 or the main agent.

## 2. Wiring in a run (orchestrator owner, `scripts/run_execskill.py`)

- SpreadsheetBench: build `generators.sheet.Engine(recalc=..., qualify=execskill.qualify.qualify,
  runtime=<the frozen SpreadsheetBench runtime, which must carry "recalculation">, native=<the native slot pool,
  with hold()>)`. Here `recalc(path) -> receipt` is the frozen v7 recalculation of one workbook
  (`sheet_recalc_v7.Recalculator(image).run`). It returns at least `status` and `output_base64`, plus
  `output_sha256` when available. Pass a fresh `out_dir` per generation run.
- LiveMath: make one `generators.livemath.SandboxChecker(sandbox.client.Worker(...))` per generation run. It starts
  kind `"generator"` with the fixed `CHECKER` bundle, and the caller closes the worker. The checker imports sympy, so
  it only works in the pinned image. On a host without sympy, every instance drops as `reference_fn_failed`.
  `test_execskill_generators.py::test_gen2_the_real_checker_passes_the_policy_and_runs_through_the_sandbox` checks
  this.
- `generators.generate(...)` now refuses to run a LiveMath family without `checker`, and a SpreadsheetBench family
  without `source_items`, `engine` and `out_dir`.
