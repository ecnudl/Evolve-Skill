## 1. `smoke_run` reads a key that `smoke.run_stage` never returns (KeyError on every stage)

`scripts/run_execskill.py` `smoke_run` (lines 388-394 when C7c read it) does
`_print({"stage": args.stage, "passed": result["passed"]})`. `smoke.run_stage` returns either

- the stage record, where the verdict is at `result["result"]["passed"]` (no top-level `passed`), or
- the stopped report of a unit that paused (the cap, connectivity, the first reply not confirmed, the S4 drill):
  `{"stage", "complete": False, "stopped", "reason", "unit"}`, and S4 adds `"paused": [attempt paths]`.
  This report has no `passed` at all, and nothing is recorded. The S4 drill ALWAYS returns it on the first S4 call.

Suggested body (the exit code for the stopped case is the CLI's choice; `chain.EXIT_PAUSED` would fit):

```python
    found = smoke.run_stage(args.spec, args.manifest, args.stage, fake=args.fake, env_path=args.env_path,
                            roles_repo=args.roles_repo)
    if found.get("complete") is False:  # a unit paused: kept, not judged (S4: the drill's paused attempts)
        _print({key: found.get(key) for key in ("stage", "stopped", "reason", "unit", "paused")})
        return chain.EXIT_PAUSED
    _print({"stage": args.stage, "passed": found["result"]["passed"]})
    return 0 if found["result"]["passed"] else 3
```
