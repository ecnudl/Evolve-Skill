# Ticket C6-1 → registrar / owner of `generators/sheet.py` and `generators/livemath.py`, main agent: no production SpreadsheetBench engine or LiveMath checker for `step.Services`

From C6, 2026-10-22. Ticket A13-1 / C2-1 §1 (`manifest.services_of`).

`step.Services` has two fields that `manifest.services_of` leaves at None, because the tree has no production object
for them:
- `engine`: a `generators.sheet.Engine(recalc, qualify, runtime, native)`. `qualify` exists (`qualify.qualify`), but
  there is no `recalc(path) -> receipt` (frozen v7 receipt shape: `status`, `output_base64`). The only producers of
  that shape are inside the frozen scorer stack (`continual_eval/sheet_recalc.py`, `native_worker.py`), and none of them
  takes a single workbook path.
- `checker`: LiveMath's fixed checker (`generators.livemath.apply(..., checker=)`).

Effect: `generators.generate` requires `engine` and `out_dir` on SpreadsheetBench (generators/__init__.py:65). When
the examiner of a SpreadsheetBench step writes specs, the generate unit therefore pauses with kind "configuration".
The pilot's step 1 is SpreadsheetBench (`protocol.ORDER`), so this blocks the pilot, but not the smoke: the smoke's
S4 mini-step is SearchQA, which has no generator family.

Request: provide `recalc(path)` as fixed registrar code. It should run under the native slot pool
(`setting.slots[slots.NATIVE]`) with the frozen runtime `setting.runtime["spreadsheetbench"]`. Provide also the
LiveMath checker. Then `services_of` binds `engine=sheet.Engine(recalc=..., qualify=functools.partial(qualify.qualify,
evidence=m["evidence"]), runtime=setting.runtime["spreadsheetbench"], native=setting.slots[slots.NATIVE])` and
`checker=...`. That is a two-line change in `manifest.services_of` (C6's file, or the integrator's).
