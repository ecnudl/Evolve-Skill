## 2. `skillopt/execskill/runcli.py` `report` (51-53): a paused scan is an exit code, not a traceback

`readout.report` calls `evaluation.unseal` per chain, so a canary hit (or an attempt awaiting the owner) reaches
`report` as `cells.Pause`. Today it propagates as a traceback (its message is kind, a count and a folder, never text,
but the exit code is 1 like a crash). Suggested:

```python
from .cells import Pause  # as evaluation.py:90 and step.py:92 import it


def report(args):
    try:
        found = readout.report(manifest.load(args.manifest), out=args.out)
    except Pause as pause:  # the run-root canary scan before the first unseal (registrar decision C3-1 (b))
        _print({"paused": pause.kind, "reason": pause.reason, "at": pause.cell})
        return chain.EXIT_AWAITING if pause.kind == "awaiting_owner_decision" else chain.EXIT_PAUSED
    _print(found)
    return chain.EXIT_COMPLETE
```

(the same mapping as `run_unit_spec`, evaluation.py:1015, and `step.run_unit_spec`, step.py:993).
