## What is in place (PR-C12)

- `solver.solve(..., shortcut="no_workbook")` (`solver.NO_WORKBOOK`): the request view without `workbook_preview`
  (no preview and no other sheet content reaches the model); the program is still pre-checked and executed on the
  real input files; the shell record carries `shortcut`. Refused (ValueError) off SpreadsheetBench and for a package
  with a procedure for SpreadsheetBench (only the card arm probes).
- `cells.run_cell`: a cell dict with a `shortcut` key hands it to the shell (`cells._shell`, so the re-execution
  replay gets it too); the record keeps the request in `cell` and states at its top level the mode the shell's own
  record reports (`shortcut`, None if the shell ran without it).
- `examiner.shortcut_variant(item)` now works on SpreadsheetBench: public fields unchanged (the real input file
  stays), `set` "shortcut", `probe` "no_workbook", `variant_of`. New `examiner.probe_mode(variant)`: the cell's mode,
  "no_workbook" on SpreadsheetBench, None on OfficeQA/LiveMath (their variants stay public-field blanks).
- `examiner.shortcut` (and so `examiner.gates`) raises ValueError("Every shortcut-probe cell ran in its bench's probe
  mode ...") when a probe cell did not run in its bench's mode: a SpreadsheetBench probe cell that saw the workbook is
  refused loudly, never counted.

## Needed in `step.py` (yours)

1. `_probe_shortcut` (step.py:492-500 as of 13:05): drop `st.bench == "spreadsheetbench" or` from the early return,
   and the docstring sentence "SpreadsheetBench has no workbook-free view yet (ticket C1-2): None, the gate is not run
   and the set is not admitted."
2. Give each probe cell its mode. Suggested patch (the shape `tests/test_execskill_shortcut_sb.py::probe_job` drives):

   ```python
   variants = [examiner.shortcut_variant(item) for item in probe]
   jobs = [("C", card, v["id"], run, {**_task(v), "shortcut": examiner.probe_mode(v)})
           for v in variants for run in (0, 1)]
   ```

   and in `_cells` (step.py:314-325 as of 13:05), when building the cell dict:

   ```python
   cell = {"id": cell_id(unit, arm, item, run), "unit": unit, "arm": arm, "benchmark": task["benchmark"],
           "task_id": item, "run": run, **({"shortcut": task["shortcut"]} if task.get("shortcut") else {})}
   ```

   (`_cells` already passes only `public`/`private` on as the task, so nothing else changes; QA probes get no key.)

Without (2), SpreadsheetBench probe cells would see the workbook, and `examiner.gates` raises instead of admitting a
set. Without (1), the gate stays `not_run` for SpreadsheetBench, as today (no set admitted, no crash).
