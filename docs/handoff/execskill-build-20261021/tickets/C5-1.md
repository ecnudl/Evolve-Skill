## What `sandbox/client.py` now offers
- `client.unit_tag(chain, unit) -> str`: `"<chain lower-cased>-<first 12 hex of sha256(unit)>"`, e.g. `g-1a2b3c4d5e6f`.
  The chain must be 1-8 letters or digits.
- `Worker(..., tag=None)`: with `tag=unit_tag(chain, unit)`, the worker's containers are named
  `execskill-sbx-<chain>-<unit12>-<uuid4 hex>`. Without a tag, they keep the registered `execskill-sbx-<uuid4 hex>`.
- `client.drain_unit(chain, unit, *, docker=None)`: raises `CleanupUnconfirmed` if any container of that unit is
  still listed. It never looks at other units' or the other chain's containers.
- `client.drain_check(prefix=PREFIX)`: unchanged. With the bare prefix it is the machine-wide check. Call it only where
  no route-B unit runs (for example, both chains idle).
