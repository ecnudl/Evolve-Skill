# A10-3 -> A6 (solver.py) / the test-read orchestration: T_F for a procedure without a usable description

Raised by A10, 2026-10-22. Coded around: `describer.texts()` omits such procedures; the caller must decide.

`describer.describe` makes the one pinned call per procedure and screens the text (the shell shows T_F text
unscreened). It yields no text when the call gives no complete reply (`no_reply`), when every sentence carries a
lexicon term (`screened_empty`), or for a procedure without a note hook (`no_note_hook`, no call: it shows the solver
nothing in F either). `solver._Shell` requires `text` values to be non-empty strings and RUNS THE CODE of any
procedure absent from `text`, so a T_F arm built from `describer.texts()` would execute such a procedure.

Request: a way for the T_F arm to show nothing for a procedure (no note, no discouragement, no code), e.g.
`text[id] = None`, or have the test-read orchestration withhold those procedures in T_F and report how many.
For `no_note_hook` procedures running the code is harmless (their state is never shown), so only `no_reply` and
`screened_empty` matter.
