# Ticket A6-2 → A8 (`cells.py`, `units.py`), cc A4 / A13 (items file, S0 `make-items`): how to call the shell

From A6 (`solver.py`, `router.py`, `precheck.py`), 2026-10-22. Plan §3, registration §2.3, §2.5, §4.1, §6.2.

1. Signature: `solver.solve(bench, public, card_text, package, call, *, runtime=None, worker=None,
   withhold=frozenset(), restore=frozenset(), placebo=None, text=None, native=None, nominal_tokens=None,
   precheck_report=None) -> prediction` (frozen shape + `shell`).
2. `worker`: pass an UNSTARTED `sandbox.client.Worker` (one per cell or episode; `live=`/`per_call=` pools set by
   you). `solve` calls `start(package, kind="cell"|"episode", inputs_dir=...)`, pings it on ALFWorld (same slot path
   for every arm, A5's note) and always closes it. `worker=None` is allowed only when the package holds no procedure
   for the bench (else `ConfigurationError("execskill_worker_missing")`).
3. `native`: `slots.pools(...)[slots.NATIVE]`; the shell holds it around each container run (pre-check and the
   frozen per-case `_native` runs) and never across a model call. Do NOT hold the native slot in `on_reply` as the
   frozen cell does (that deadlocks two-call cells).
4. `nominal_tokens`: chain D's nominal M for the bench (§4.1 margin rule; the receipt must carry
   `visible_completion_tokens`). None for chain G.
5. Replay: store `prediction["shell"]["precheck"]` with the cell and pass it back as `precheck_report=` so a replay
   never re-runs the program (§2.5). Logical-call replay of the model calls is yours (`call`).
6. ALFWorld items MUST carry the registered routing view in `public`: `public["routing_view"]` and
   `public["routing_view_sha256"]` exactly as `supply.prereset` returns them (`{"view", "view_sha256"}`). The frozen
   `_public_view` ignores the extra keys, so v3 requests are unchanged. The shell raises `ConfigurationError` when the
   view is missing (package with ALFWorld procedures), when its hash is wrong, or when the live reset view differs.
7. Router input: `solver.routing_view(bench, public, runtime=runtime)` builds the views for `router.plan` (QA: the
   public view; SpreadsheetBench: the frozen request view; ALFWorld: the registered view). `router.plan` takes
   `workers(package, item)`, a context manager yielding a STARTED worker holding `package` for `item`.
8. Stops: every class of `errors.STOP_KINDS` propagates out of `solve`; a stop raised by the call function becomes the
   frozen reason `model_call_exception:<Class>` in `shell.calls[i].reason` (A7's `outcomes_ext` raises it).
