# Ticket PR-C61-1 → integrator I1 (owner of `manifest.py` and its tests): bind the production SpreadsheetBench engines in `services_of`

From PR-C61, 2026-10-22 12:5x. Ticket C6-1; registrar decisions 2026-10-22, addendum 13:0x (pilot-readiness row,
"C6-1 production engines in Services"); registration §7.2 "SpreadsheetBench 族", §4.4 P4; plan §4-§5 (lock order).

`skillopt/execskill/engines.py` (new, PR-C61) provides
`engines.sheet_engines(runtime, *, native, evidence) -> generators.sheet.Engine`: `recalc` = the frozen v7
`Recalculator.run` of the engine `sheet_numeric_adapter.qualified_engine(runtime)` revalidates (once, at the first
recalculation; 0.5 s on dl), under one `spreadsheet-native` slot per container run; `qualify` =
`functools.partial(qualify.qualify, evidence=evidence)`; `runtime` (a copy); `native`. Building it revalidates
nothing, so the manifest tests' `runtime = {b: {} ...}` still build.

## LiveMath checker

C7d's checker adapter is not in `generators/livemath.py` yet (file unchanged since 02:42; only `SandboxChecker(worker)`,
which starts a container in its constructor). When it lands, `services_of` binds it in the same return statement
(`checker=...`). It must not start a container while the Services are built (`services_of` runs in every step-unit
child and in `chain.run_manifest`, also for QA steps) and its container must carry the running unit's tag, as
`workers` does (ticket C5-1), so the unit's drain sees it.

## Also note

- `step.Services.engine` is consumed only by `step._build` → `examiner.build` → `generators.generate`; nothing else
  changes. The engines are zero-call; `make-manifest` and S0 already revalidate the same runtime
  (`qualify.engine_runtime`, ticket C7b1-3), so a stale runtime is caught before launch; at run time it pauses the
  generate unit as "configuration" at the first recalculation.
- Ticket PR-C61-2: with the engines bound, SpreadsheetBench generation still cannot keep an item (two defects in
  `generators/sheet.py`, verified on dl with zero calls). Wiring this ticket alone turns step 1's generate unit from a
  configuration pause at "no engine" into a configuration pause at the first engine qualification.
- The code map (`pin_code`) and `tests/test_execskill_smoke_rehearsal.py` see two new files
  (`skillopt/execskill/engines.py`, `tests/test_execskill_engines.py`).
