verified verbatim against the item's public text are not screened.

## What changed in `notes`
- `notes.screen(fields, *, bench, public_text=None)`. `public_text` None (the default) screens every text, as before.
  With the item's public text, a table cell or a binding's quote that occurs in it verbatim is skipped; facts,
  candidates, warnings, binding names and values are always screened.
- `screen` returns the kept fields as `notes.Screened` (a dict that remembers the public text). `notes.render` screens
  a `Screened` again against that same text, a plain dict against nothing (every text). So no `render` call site
  changes; a caller that copies the kept fields into a plain dict before rendering gets the strict check (a refusal
  for exempted content), the safe direction.
