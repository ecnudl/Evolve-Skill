# Ticket P2-A2-1 → owner of `readout.py` (PR-F2's file; integrator I1 to route): the §6.2 "answer-format share" reads 0.0 on SpreadsheetBench and ALFWorld by construction

From P2-A2, 2026-10-22 14:1x, while implementing ticket PR-F2-1 (`acceptance.series`, which reuses
`readout._windows` as the registrar decided: "reusing readout.py's fixer-2 definitions"). Registration §6.2 ("按组、按
15 分钟报告简短回答比例、答案格式比例、回答长度"), §8.3. Descriptive only: no J1-J7 reading and no decision changes.

## What is wrong

`readout._windows` (`readout.py:468`) computes the per-window answer-format column as

    "answer_tag_share": _share(members, lambda v: v["format"].get("tag_present")),

`judge._format` (`judge.py:206-234`) sets `tag_present` on the QA benches and LiveMath only. A SpreadsheetBench cell's
format is `{program_delivered, cases, cases_available, violation}` and an ALFWorld cell's `{steps, admissible_steps,
violation}`, so `.get("tag_present")` is None for every cell and the share is **0.0 in every window of every arm** --
indistinguishable from "no cell delivered an answer in the registered format". The pilot runs SpreadsheetBench first in
both chains (owner's pilot order), so the first acceptance decision records (`decision.json` -> `series`, ticket
PR-F2-1) and every SpreadsheetBench/ALFWorld test-read table (`arm_table` -> `windows`) would carry this false zero.

## Proposed patch (exact; `skillopt/execskill/readout.py`)

Option A (minimal, keeps the column's meaning): None where the bench has no answer tag.

```diff
@@ def _windows(rows, start):
         out.append({"window": window, "cells": len(members),
-                    "answer_tag_share": _share(members, lambda v: v["format"].get("tag_present")),
+                    "answer_tag_share": (_share(members, lambda v: v["format"].get("tag_present"))
+                                         if any("tag_present" in v["format"] for v in members) else None),
                     "mean_completion_tokens": sum(tokens) / len(tokens) if tokens else None,
```

and in the `_windows` docstring: "their answer-tag share (None on a bench without an answer tag: SpreadsheetBench,
ALFWorld)".

Option B (registrar's choice, additionally): a bench-neutral §6.2 answer-format share beside it, J4's own format
reading (QA a usable tag, LiveMath one letter, SpreadsheetBench a delivered program, ALFWorld an admissible share
>= 0.9; unknown cells, `violation` None, left out):

```diff
+                    "format_share": _share([v for v in members if v["format"].get("violation") is not None],
+                                           lambda v: v["format"]["violation"] is False),
```

Tests to add with it (readout's owner): a SpreadsheetBench row set gives `answer_tag_share` None (option A) and, with
option B, `format_share` 1.0 when every cell delivered a program. `tests/test_execskill_acceptance.py` (P2-A2's PR-F2-1
tests) sets `tag_present` explicitly, so it passes under either option unchanged; `acceptance.series` needs no change
(it passes `judge.format` through).
