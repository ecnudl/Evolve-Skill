# Ticket C7d-3 → owner of `scripts/run_execskill.py` (I1): `smoke-run --fake` names a credential by default

From C7d, 2026-10-22. Minor; it affects every stage, not only S3.

`smoke-run` defines `--env-path` with the default `protocol.ELUCID_ENV` and passes it to `smoke.run_stage` even
when `--fake` is given. The fake branches of `smoke._backends` and `smoke_roles.backends` require `env_path is None
and roles_repo is None` ("A rehearsal names no credential"). So `smoke-run --fake` without an explicit empty
`--env-path` is refused for every stage. The CLI test stubs `run_stage`, so it does not catch this.

Request: in `smoke_run`, when `args.fake` is set, pass `env_path=None, roles_repo=None`, or refuse explicit
credentials together with `--fake`. The tests call `run_stage(..., fake=True)` directly and are unaffected.
