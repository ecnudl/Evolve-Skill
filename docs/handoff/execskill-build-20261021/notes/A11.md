## Deviations from the plan (with reasons)

1. **Research requests are methods of `Researcher`.** `family_material`, `parameter_choice` and `selection_hint` are
   methods, not free functions, because the object holds the 24-request ceiling and the pre-dispatch leakage screen
   for one step and bench.
2. **Two new purposes.** `function` uses the archive only, and the quote must name the function. `parameter` requires
   every value to be written in its verbatim quote. Both sit beside the frozen three, with their own
   `CONCLUDE_SYSTEM` prompts. The frozen prompts are unchanged.
3. **The topic hint uses the frozen payload key `rule`.** This avoids changing the frozen request payload.
4. **Family code is split across modules.** The family base is in `generators/families.py`. The registry and
   `generate` are in `generators/__init__.py`. Each bench's `apply` takes what its truth needs: a checker for
   LiveMath, an engine for SpreadsheetBench. There is no uniform `apply(spec)`.
5. **LiveMath truth comes from an injected checker.** In a run this is the sandbox checker. The tests use an in-process
   exact `FakeChecker` (Fraction arithmetic), because the host has no sympy. The real path is only tested up to its
   host fault: on the host every instance drops as `reference_fn_failed`. A real sympy solve was never run (it needs
   the pinned image).
6. **SpreadsheetBench recalculation and qualification are injected through `sheet.Engine`.** `execskill.qualify` does
   not exist yet (ticket A11-1). Also, a generated item carries only the source's first case (`input_files[0]`,
   `test_files[0]`).
7. **The ALFWorld filter is a fixed schema.** The spec is
   `{task_kinds, min_receptacles, min_openable, target, finding}` over the zero-call routing view. The examiner does
   not write selection code. A spec must cite a qualified `selection` finding.
8. **More drop reasons than the plan names.** Added: `material_mismatch`, `options`, `meta_option`,
   `function_not_researched`, `forbidden_function`, `literal_answer`, `edit_target_invalid`, `recalc_failed`,
   `engine_qualification_failed` and `finding_exhausted`.
9. **Known limitation: OfficeQA totals can go stale.** A perturbation rewrites only the chosen cells. A dependent
   cell, such as a Total column, keeps its old value, so the table can become internally inconsistent. Questions name
   their cells explicitly.
