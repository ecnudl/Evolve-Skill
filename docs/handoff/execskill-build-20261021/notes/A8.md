## Deviations from the plan (with reasons)

1. `run_cell(context, cell, task, arm, *, store)` takes an `Arm` (kind, package, withhold, restore, placebo, text)
   instead of separate package/arm arguments, so a replay re-runs exactly the same twin/placebo/text options.
   `_replay(context, cell, task, arm, previous, log)` also takes the stored record for its pre-check report.
2. `faults` is a list of `{procedure, hook, kind, exc_type, message, step}` (acceptance.py reads the procedure of
   each fault); the plan's `{kind: n}` count is the extra key `fault_kinds`.
3. Extra record keys: `arm`, `task_id`, `run`, `set`, `block` at the top level (the acceptance.py contract),
   `dispatch_ts`/`finish_ts` as epoch seconds (§6.2 balance); `logical_calls` entries also carry `solve`,
   `request_sha256` and `exception` (a stored exception is re-raised on replay).
4. P3 (§4.4): a replay whose request hash differs, or that makes an extra or a missing call, becomes
   `_prediction_unknown(REPLAY_MISMATCH, replay={served, stored})`, is scored host-side (unknown) and classifies
   as `unknown_fault`. The internal `ReplayMismatch` exception never leaves the shell (the frozen `_response` turns
   it into `model_call_exception:ReplayMismatch`); it is not a stop. A SpreadsheetBench replay that diverges at
   the repair call may run the program containers once more before it is discarded (the shell's fallback).
5. `table_of` returns the frozen 5-tuple, with `unknown_fault` entered as `unknown_artifact`: wrong on L, right
   on H, never infrastructure, so the frozen `unknown_share(..., infrastructure_only=True)` agrees with `guard`.
   `tokens()` gives the table for `stats_ext.item_scores` (A7-2 §5).
6. `balance(cells)` returns `{"ok", "spread_s", "duration_s", "medians"}` instead of a bare bool, so the round
   report can show why it failed; shared cells (§8.1) are left out.
7. `run_round(..., blocks=)` partitions and orders blocks (each block in its own seeded order, `cell["block"]`);
   the time gap between blocks is the caller's. A callable arm gives the cell's Arm (per-cell placebo seed).
8. `run_unit` enforces the redo limit: an attempt beyond 1 + MAX_REDOS raises `Pause("redo_limit")`; a paused
   attempt without the owner's `recovery.json` raises `Pause("awaiting_owner_decision")`. Stop kinds come from
   `errors.stop_kind` (PackageInvalid -> package, not configuration); another ValueError -> configuration, any
   other exception -> exception.
9. `units.CHAINS` holds only `solver` and `start: empty`; `solver_endpoint` covers the step kinds of
   `budgets.solver_scopes`; test, smoke and probe endpoints belong to other rows.
10. Trajectories: an enable line is written only for a cell whose final shell has a route; a stopped cell has no
    trajectory. `whitelisted` refuses hidden ALFWorld keys (`expert_plan`, `gamefile`, `game_file`, `extra`) in the
    record and inside each call's request. The SpreadsheetBench masked view shows the first reply only (the repair
    and the pre-check run status are hidden); QA views mask every answer carrier (tags, an unclosed last tag, JSON
    answer values, SearchQA's last line when there is no carrier). The examiner view adds `passed`.
11. Landmark view (§7.1, Codex F10): an infrastructure-censored episode is `Excluded("censored:infrastructure")`
    when T > 10 and `Excluded("ended_by_step_10:infrastructure")` otherwise; episodes ending by step 10 are
    `Excluded("ended_by_step_10:won" | ":done")`, so they can be reported by outcome.
