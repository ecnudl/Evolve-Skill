## What each new piece does

- **`probe` (S1, §10)**
  - Runs on its own ledger root `<probe root>/ledger` with `budgets.probe_caps()` (0.5M) and scopes
    `(overall, smoke:probe)`. It refuses a probe root inside the smoke root.
  - Rows a (M 64), b (M 16, 64 and 256, ten long-output requests each) and c (M 16,384) are sequential, with ledger
    bound B_probe = 32,768.
  - Row d is 8 concurrent calls with M = B = 64.
  - Row e is one call through `ControlClient` with bound B_probe.
  - Each probe is ONE `Endpoint.send` (no `Recorder` resend), so S1-e's mismatch stays a single control receipt.
  - The first call (a) must be an ok reply echoing the registered model before anything else is sent. Otherwise the
    attempt stops (`first_call_not_confirmed`). S1 is then not judged, and the attempt record stays.
  - A ledger stop (`BudgetStop`, `AssumptionBroken`, `LedgerFailure`) also stops the attempt. Example: a completion
    above a probe bound, which halts only the probe ledger.
  - The total is capped at `S1_MAX_CALLS` = 60 over all attempts. A complete attempt records stage S1 once.
  - Kept: per send, row, n, M, B, body, ok, error type, subtype, echoed model, finish reason, usage, reasoning
    tokens, seconds and request bytes. Never kept: a reply text or a credential. The CLI prints counts, classes,
    rows, branch and longest.
  - Row f: the gateway every client was built with (`protocol.GATEWAY`, which `ElucidClient` validates),
    `trust_env` read from every client's `httpx.Client`, and whether the first call was confirmed.
- **`sandbox-selftest` (S0, §2.6)**
  - Copies `worker.py`, `policy.json` and `escape_probe.py` read-only into a fresh runner directory.
  - Starts the registered cell argv with `/runner/escape_probe.py` in place of the worker. The container is removed
    by its exact name (`sandbox.cleanup`) in every case.
  - Judges the report on eight rows: network, read_only, identity, env_keys (exactly the 13 keys, and the 5
    registered values), no_secrets, limits (pids, memory), worker_child and python_flags (`no_user_site`).
  - One ping of an empty-package worker gives VSZ/RSS and the start latency. The p99 public-view size comes from
    the given item files.
  - The sealed record goes into the smoke spec through `smoke-make --selftest`. That is the "measurements written
    into the smoke manifest before S1" of plan §10 step 3.
- **`exclude-tests` (tickets fixer-4, fixer-8)**
  - The consent check comes first; the test asserts that no panel was opened before it. Then one
    `TestAccess("smoke/s0/test-exclusion")`.
  - Runs `exclusion.exclude_tests` and `exclusion.alfworld_test_identity`, plus the canaries from the same two test
    sets (C3-1).
  - Writes the three records once under `<root>/shared/exclusion/`. Prints counts and hashes only. The test checks
    that no question, path or test id appears in the output or in any record file.
- **`make-manifest`**
  - Verifies the three records: both runs of one consent, the SearchQA digest intact, ALFWorld disjoint, the
    canaries sealed. Then binds `{path, record_sha256}` of each into `data.exclusion`.
  - Writes the canaries record once as `<manifest root>/shared/test-canaries.json`. It checks the file with
    `evaluation.load_canaries`, all before `manifest.make`.
  - This makes the CLI the creator of the run root's canaries (fixer-4). Without the persisted unit there is no
    manifest.
- **`import-texts` (§2.2)**
  - The frozen `coevo5.prelaunch.verify_texts` verifies the source in place (zero calls; an import's own source is
    verified again).
  - The version must be exactly `fivebench-coevolution-v3-texts-import`.
  - The five `instructions` are the route-B cards. Each must match the registered length and sha256 prefix of
    §2.2 (`CARD_IDENTITY`).
  - Written as `texts-import` in a new directory.
- **`import-sheet-qualification`**: `qualify.load` (the v3 record only through `IMPORTABLE`), then the training side
  is required, then `qualify.reverify(pinned=--sha256)`, then a `sheet-qualification-import` record holding counts
  only.
- **`make-items`**
  - ALFWorld: `supply.alfworld_items` → `supply_record`. A dry run prints counts and writes nothing. Otherwise
    `write_supply`, then the registered cut (`slices(order, registered_sizes)`: 12/60/150/200 = 422 games) is
    pre-reset with `supply.alfworld_reset` and written once as `alfworld-views`.
  - SearchQA: the frozen builder's loader (`datasets.load_dataset(name, revision=)`) → `supply.searchqa_tail`. A dry
    run prints counts only.
- **`replay`**
  - For each procedure, `replay.zero_crash` over a completed unit's trajectories, in sandbox workers
    (`sandbox.with_worker`).
  - SpreadsheetBench trajectories are refused: their hooks need the public input directories, which only the
    engineer's checks bind.
- **`classed_sends`**
  - Turns a cell's recorded sends into receipt-class entries when the cell is dispatched. A repeat of the previous
    request after an undelivered receipt is a frozen-path resend.
  - Receipts are reduced to ok, error type and subtype.
  - `receipt_classes` refuses a stamp that disagrees with its own verdict.
- **`FaultSwitch` (S4)**
  - Refuses a unit outside the verified smoke spec's root.
  - The `fail_at`-th sandbox call through its workers raises `SandboxUnavailable` (P4), before docker is touched.

## Deviations from the plan, with reasons

1. **A new file, `escape_probe.py`.** The probe is mounted into the container at `/runner`, so it must be a file.
   B2 asked that it become fixed registrar code for `sandbox-selftest`. It lives in the package, so the manifest's
   code map pins it.
2. **`smoke.make` requires `selftest`.** The registered limits and the S0 measurements must be in the smoke spec
   before S1 (plan §10 step 3), and the spec is write-once. Existing tests now pass a synthetic self-test.
3. **S1 implementation-time choices**, none registered:
   - rows a and e use M = 64 (`S1D_TOKENS`);
   - the prompts are fixed in `smoke.py`;
   - a stopped attempt is kept but not judged, so a connectivity failure does not burn the write-once S1 stage.
   - S1 is judged only on a complete attempt.
4. **The S0 `supply` row is computed by the CLI**: the operator's value AND the persisted, verified exclusion
   unit (fixer-8 item 4). The A13 test that recorded a passing S0 now runs `exclude-tests` first.
5. **Canaries cover SearchQA and ALFWorld only**, the two test sets the consented exclusion unit opens. They are
   made in `exclude-tests` and written into the run root by `make-manifest`. Ticket C3-1 covers the other three
   benches and the selection rule.
6. **The sandbox self-test measures no native peak RSS.** That needs a SpreadsheetBench program run in the native
   image. The manifest's `measured.native_peak_rss_kib` (plan §5 memory rule) still comes from the operator's pins.
7. **`import-texts` checks the registered sha256 prefixes** assuming sha256 of the UTF-8 card text. If [CM 2.10b]
   used another convention, S0 stops with "not the registered one". That is the safe direction, and the operator
   should confirm at S0.
