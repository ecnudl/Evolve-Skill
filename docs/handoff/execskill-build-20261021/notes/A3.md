## Public API

@dataclass(frozen=True)
class Procedure(id, origin, description, hooks, source, evidence, header="", max_note_chars=0,
                requests_second_call=False, state_bytes=0, excluded_benches=(), replay_tests=(),
                lineage={"parent": None, "revises": None, "engineer_call": None}, accepted_at=None)
    .is_fixture; .to_json() -> sealed record; .sha256 (its record_sha256); Procedure.from_json(record)
@dataclass(frozen=True)
class Edit(kind, old, new, benches=())        # kind in EDIT_KINDS = new, revision, deletion, narrowing
    .id; .to_json() -> {"kind", "id", "old", "new", "benches"}  (procedure hashes)
@dataclass(frozen=True)
class Package(procedures, step, evidence, parent_sha256=None, retired=(), narrowed={}, describer={})
    .order; .get(id); .excluded(id) -> benches; .for_bench(bench) -> procedures in package order
    .to_json() -> sealed record; .sha256
empty(*, step, evidence) -> Package                       # the root: no procedures, no parent
edits(parent, candidate) -> [Edit]                        # new/revision in candidate order, deletions, narrowings
validate(package, parent=None) -> None                    # invariants; with parent: hash link + <= MAX_CHANGES edits
with_(package, *, step, add=(), revise=(), remove=(), narrow=None, evidence=None) -> Package
with_describer(package, {id: {"text_sha256", "prompt_sha256"}}) -> Package   # the frozen package of a step (§5.7)
withhold(package, ids) -> Package                         # withholding twin
restore(package, parent, ids) -> Package                  # restoration twin (deleted or narrowed ids)
save(root, package) -> sha   # write-once <root>/procedures/<sha>.json, <root>/packages/<sha>.json
load(path) -> Package        # <root>/packages/<sha>.json, every hash re-verified
# FIXTURE, HOOK_PARAMETERS, NOTE_HOOKS, SECOND_CALL_HOOKS, EDIT_KINDS, MAX_STATE_BYTES

# policy.py  (standard library only)
check(source, *, bench=None) -> sorted [Violation]    # bench None: all three C4 static bans; a bench: only its own
Violation(rule, detail, line=0).to_json()             # rule in RULES
POLICY (dict, version "fivebench-execskill-v1-policy"); policy_sha256() -> digest(POLICY)
write_policy_json(path=POLICY_PATH) -> sha            # canonical bytes; same bytes: no-op; different: ValueError
meta_option_hits(text) -> [term]                      # C4 LiveMath (META_TERMS = phrases + 4-word shingles)
literal_hits(text) -> [(rule, hit)]                   # bulletin_literal / receptacle_literal

# notes.py
screen(fields, *, bench) -> (kept, dropped)           # dropped: {"field", "reason", "detail"}, one fault each
check_bindings(bindings, public_text) -> (kept, dropped)   # name / duplicate_name / value / not_verbatim
render(fields, *, bench, header) -> str               # "" when nothing is kept; refuses unscreened fields
assemble([(procedure_id, text, max_note_chars)], *, bench) -> (text, skipped)  # over_declared_cap / over_total_cap
lexicon_hits(text, *, bench) -> [term]; header_hits(header, *, benches) -> [(bench, term)]
lexicon_record() -> dict; lexicon_sha256() -> str    # for the manifest, before S2
# FIELD_ORDER, FIELD_TYPES, SEPARATOR ("\n\n"), PATTERNS

# compute.py
parse_tags(reply) -> [str]                            # the first 8 non-empty <calc> bodies of <= 300 chars
evaluate(formula, bindings=None, *, deadline=None) -> {"value": str}
                                       | {"value": "not evaluated", "error": "computation_failed:<reason>"}
evaluate_tags(tags, bindings=None, *, watchdog_seconds=5.0) -> [{"expr", "value"[, "error"]}]  # one cell
exact(formula, bindings=None, *, deadline=None) -> Fraction   # raises ComputeError(reason)
number(text) -> Fraction; render(Fraction) -> str; literals(formula); rounded(value, decimals)
# ComputeError(ValueError).reason in REASONS; FUNCTIONS = abs, round, min, max, sum; CELL_WATCHDOG_SECONDS = 5.0

canonical(reply, admissible) -> (action, how)  # how in HOWS = tag_exact, tag_level1, whole_exact, whole_level1,

## Deviations from the plan (with reasons)
1. **Records are sealed by A1's `protocol.record`.** They carry `version` =
   `fivebench-execskill-v1-procedure|package`, `evidence` and `record_sha256` (plan §2's general rule), not plan
   §2.1's `"sha256"` key. `Procedure.sha256` and `Package.sha256` return the record hash.
2. **`validate(package, parent=None)`.** The plan has `validate(package)`. Counting the "<= 3 edits per step" rule
   needs the parent, so with a parent `validate` also checks the hash link and the edit count. `with_` always
   validates against its parent.
3. **`with_` requires `step=` (keyword).** A package record carries its step label, and a default would mislabel
   the candidate. A3 added these helpers, which the plan does not list:
   - `empty(*, step, evidence)`, the root;
   - `with_describer`, the §5.7 frozen package: describer hashes, a new record hash;
   - `Package.for_bench`, `excluded`, `get` and `order`, the router's input.
4. **Ids.** Learned ids are `p-<origin>-<step>-<n>` (1-3 digits each). Engineering fixtures are `fx-<name>`. They
   must have `evidence = engineering_fixture`, and a package holding one must too (AGENTS.md: a fixture is never
   a learned Skill).
5. **`MAX_STATE_BYTES = 65,536` is an implementation cap** on declared ALFWorld state; the registration fixes none.
   The hook parameter counts are fixed in `HOOK_PARAMETERS`: `applies(view)`, `before_call(view, state)`,
   `bindings(view)`, `sheet_feedback(view, run_report, state)`, `alf_before_step(view, state)`,
   `alf_after_step(event, state)`.
6. **`restore` position.** The plan does not specify one. A3 re-inserts a deleted procedure after its nearest
   preceding parent procedure still in the candidate, or after that procedure's revision, which stands in its
   place. New procedures stay last.
7. **`policy.check(source, *, bench=None)`.** The default is all three static bans, because a procedure's scope
   is every bench it does not exclude (REG §5.7). With a bench, only that bench's ban applies; package validation
   uses the default. `policy.py` uses only the standard library, so the sandbox can load it standalone. It
   therefore copies, by value, `BENCHES`, the byte/constant caps and `STRONGER_OPTION`; tests assert they equal
   `protocol` and `coevo5.protocol:222`.
8. **`sandbox/policy.json` is configuration, not a record.** It is canonical `POLICY` JSON with `version` but no
   `evidence` field.
9. **Policy residuals are left to the container (REG §2.6) and to C6** (two fresh processes, identical results):
   - reaching `numpy.random` through another name, for example `m = np; m.random`;
   - library constructors that parse strings, other than `sympify`/`S`/`parse_expr`.
10. **compute.**
    - Depth is bracket nesting <= 20, not AST depth, so flat sums are fine. The frozen 100-node cap is kept and
      reported as `size`.
    - The function set is the registration's abs/round/min/max/sum; the frozen kernel's extra functions are
      dropped.
    - `round` rounds half away from zero, to 0-12 places.
    - |exponent| <= 12, with an exact lower-bound pre-check `|e|*(bits-1)+1 > 4096`. The frozen
      `bits*|e| > 4096` would refuse values that fit, for example `(2**341)**12`.
    - Every bound value and every intermediate is checked against 4,096 bits before use.
    - Display: an integer, an exact decimal (<= 30 places), or `p/q (approximately d)` to 12 places.
    - The per-cell watchdog is 5 s.
    - A binding value must parse with `compute.number`: a sign (also U+2212), thousands commas, decimals.
      Anything else means the name is unbound (`name`).
11. **notes.**
    - The lexicon rule is applied exactly as A1 registered it (see ticket A3-1).
    - On LiveMath, the C4 meta-option terms are also screened (reason `meta_option`).
    - A3 added `check_bindings`, `assemble` and `lexicon_record`/`lexicon_sha256`.
    - The line formats are A3's own choice: `- item`, `| a | b |` and `- name = value (quoted: "quote")`. The
      registration fixes only the headers.
12. **T-CANON-4 emulates route B inside the frozen loop.** It feeds `<action>canonical</action>` through the
    frozen `_solve_alfworld` loop with a monkeypatched `_new_alfworld`. The solver-level check belongs to A6
    (T-SOLVER-1).

## Not covered by this row
REG §5.4 C4 also bans "code answering by option position/letter pattern". `policy.py` cannot detect that
statically: it bans only the literal fragments and "stronger result/statement". Detecting it is left to the C4
checker's owner.
