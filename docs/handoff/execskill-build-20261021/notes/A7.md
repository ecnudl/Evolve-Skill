`stats_ext`. Constants: `NORMAL`, `SIDES=("L","H")`.

```python
item_scores(cells, arm, items, *, side)              # {item: Fraction}; L: unknown* wrong, H: right
infrastructure_share(cells, arm, items)             # token "unknown" only (not unknown_fault / unknown_artifact)
paired_t(d, *, strata=None, clusters=None, weights=None) -> {"mean", "se", "df", "t", "p"}   # PRIMARY, one-sided
t_upper(t, df)
signflip(d, *, strata=None, clusters=None, weights=None, n=SIGNFLIP_FLIPS, seed=SEED)   # sensitivity only
wilcoxon(d)                                                                               # sensitivity only
bootstrap_ci(d, *, strata=None, clusters=None, weights=None, resamples=BOOTSTRAP_RESAMPLES, seed=SEED, level=0.95)
Decision(reject, p, alpha, contrasts)                # frozen dataclass
iut(d1, d2, *, alpha=ALPHA, design1=None, design2=None) -> Decision   # design = paired_t's keyword arguments
holm(pvals)                                          # adjusted p, input order
spearman_perm(xs, ys, *, n=VALIDITY_PERMUTATIONS, seed=SEED) -> (rho | None, p)
power_table(se, *, effects=(3, 5, 10), rho=0.5, placebo=0.0, cover=1.0, deff=1.0, deff_y=1.0, alpha=ALPHA)
mde(se, *, power=0.8, **model)
```

`paired_t` uses one WLS form for all three designs:

- Plain items: blocks = 1, weights = 1.
- Block-stratified items: df = items − blocks.
- ALFWorld: games-weighted t on room means, clusters = rooms, weights = games, df = rooms − blocks.

In each case s² = Σw(x − m_b)² / (U − B) and se = s / √W. Values must lie in [−1, 1], weights must be positive, and
each block must be made of whole rooms. With se = 0, p is 0 or 1 and t is None.

## Scorer v2 as implemented (REG §4.4, Codex F7)

A usable official carrier is used exclusively:

- QA: the last non-empty `<answer>` whose content is not itself a JSON object. On LiveMath it must also pass the
  frozen single-letter rule.
- SpreadsheetBench: the program from the frozen `extract_python`.
- ALFWorld: the action.

JSON is read only when the official carrier is unusable, and only on the QA benches. `json_answer` reads the LAST
top-level object that has an `"answer"` key and never falls back to an earlier one. Its value must be a non-blank
string or number (numbers are kept as written; NaN is rejected), and it must survive the tag round trip.

v2 = "pass" when the final verdict is a scored fail and the JSON answer passes the frozen comparison (`backends.score`
on `<answer>X</answer>`). Otherwise v2 = final. For SpreadsheetBench and ALFWorld, v2 = final.

Both invariants, v2 ≥ final and v2 ≥ official, are asserted with explicit errors. The lenient score is
`coevo5.scoring.lenient`, applied to the wrapped JSON answer when the carrier is json. The outputs hold no reply or
reference text; T-JUDGE-4 checks this.

## Deviations from the plan, with reasons

1. **`judge()` takes keyword-only `score`, `verdict` and `deciding`.** The cell runner already holds the official
   score and the final verdict, and scoring SpreadsheetBench needs the sandbox, so the judge does not recompute them.
   Without them it computes the host-only parts itself. A delivered SpreadsheetBench program requires a runner score.
2. **The judge output has `version` and `scorer` but no `evidence`.** It is a field inside the sealed cell record,
   and that record carries the evidence.
3. **Route-B code must read tokens with `outcomes_ext.token(verdict)`.** A subclass of `Verdict` would not survive
   `finalize` and `_combine`. See ticket A7-2.
4. **`_all_stops` also raises any stop class named by a `model_call_exception:<Name>` reason.** The reason can come
   from the prediction, its cases, the score, or a shell call's `reason`. Otherwise a `ConfigurationError` or
   `SandboxUnavailable` raised inside a call would become a row-11 unknown, which contradicts P4 and the
   one-exception-set rule. The shell key is requested in ticket A7-1.
5. **`worst_delivery` adds the values `no_call` and `noncompletion:<err>`.** Filtered and empty replies are neither
   undelivered nor truncated.
6. **`iut` takes `design1` and `design2`.** The two contrasts can have different designs, for example ALFWorld rooms.
7. **`power_table` and `mde` were added.** They are named in the task text, not in the plan row. They reproduce calc
   T2 and never decide anything.
8. **`select_answer` covers all five benches**, so T-JUDGE-5 tests the carrier precedence on each one.
9. **ALFWorld J4's admissible share is read from `shell.alfworld_steps[i].how`.** Every value except `unchanged`
   counts as admissible, and the threshold is `protocol.ALFWORLD_ADMISSIBLE_MIN` = 9/10. `invalid_action_format` is
   always a violation. The shell key is requested in ticket A7-1.
10. **Only top-level JSON objects are read, and the last one with `"answer"` decides.** A nested object is part of
    its parent. This keeps the rule independent of the reference and deterministic. Deep nesting is caught
    (`RecursionError`).
11. **T-STATS-3's null uses continuous uniform(−1, 1)** (n = 10 and n = 30, 4000 seeded repetitions; the shares of
    p ≤ .05, .25 and .5 are checked within a tolerance), alongside the exact calc-T9 sizes. A discrete null with mass
    at a mean of 0 gives p = .5 exactly, so its p-values are not uniform.
12. **The whole-batch floor (J1) and the guards J3-J7 are not in `stats_ext`.** They belong to `acceptance.py`.
    `stats_ext` keeps only the statistical part.

  `alfworld_steps[i].how`. The §4.1 chain-D margin truncation rule has no owner. Proposal: the solver's `_response`

  - Call `judge.judge(..., score=, verdict=, deciding=)`.
  - Build round tables from v2 tokens with `stats_ext.item_scores`.
