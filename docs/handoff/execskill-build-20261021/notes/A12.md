## Public API

### `qualify` (record kinds `sheet-qualification`, `sheet-qualification-score`)

- `qualify(tasks, root, runtime, *, side, native, workers, evidence) -> record`
- `record_digest(value) -> str`: `record_sha256`, or `record_hash` for the v3 record.
- `load(path, *, importable=IMPORTABLE) -> record`
- `reverify(value, *, pinned, tasks=None)`
- `summary(value) -> counts`

### `evaluation`

Consent and test panel:
- `consent(shared)`: exactly `CONSENT_FIELDS`, `multi_arm_arms == TEST_ARMS`.
- `test_tasks(shared, pinned, bench, unit, *, run, runtime, native, workers, evidence, panel=data.test_panel)`
- `test_plan(tasks, final, *, bench, unit, runtime, workers) -> {"routes", "zero", "twins", "not_withheld",
  "sha256"}`

Persistence and canaries:
- `sealed_cell(full)`: the hash-only projection.
- `class EvaluationStore(attempt, *, evidence)`: `claim`, `artifact`, `scorer_dir`, `save`, `finish`.
- `canary(text) -> {"chars", "sha256_16"}`, `load_canaries(root)`, `canary_scan(attempt_dir, canaries) -> (files,
  hits)`.

The read and the unseal:
- `configuration(context, bench)`, `monitor(unit_roots)`.
- `evaluate(unit_root, *, run, shared, pinned, chain, bench, arms, context, workers, route_workers, canaries,
  panel=data.test_panel) -> record "evaluation"` (also written as `unit.json`).
- `continuation(root)`, `read_label(chain_roots)`.
- `unseal(root, chain_root, chain, unit_roots, *, run, evidence, clock=_now) -> {"label", "later_reads", "units":
  {bench: {(arm, task_id, run): {...}}}}`. It also writes the write-once `<chain_root>/unsealed.json`.

### `readout`

Tables and estimates:
- `table(cells)`, `side(arm)`, `differences(tab, first, second, items)`
- `estimate(d, *, strata=None, bootstrap=False, sensitivity=False)`
- `enable_rate(cells, procedure=None)`, `tau(cells, procedure)`

The readouts:
- `q1_home(units, learned)`
- `similar(learned)`, `dissimilar(learned)`, `q2_similar(units, learned, procedures)`
- `q3_noninferiority(units, learned)`
- `code_vs_text(units, learned)`
- `labels(units, procedures)`, `format_withholding(units, procedures)`
- `readout(units, *, learned, procedures, label, evidence) -> record "readout"` (`evidence_kind` "generalization").

### `chain`

Constants: `EXIT_COMPLETE` 0, `EXIT_PAUSED` 3, `EXIT_AWAITING` 5, `RUNNER_LOCK`, `HEAVY_LOCK`, `CAP_CHECK`,
`TEST_READ`, and the exception `Terminated`.

Functions:
- `chain_root(setting, chain)`, `unit_root(setting, chain, bench)`
- `heavy(setting, bench)`: a context manager. SpreadsheetBench takes the lock exclusively, ALFWorld shared, QA none.
- `cap_check(setting, chain, k, measured)`
- `launch_child(setting, spec)`
- `read_budget(setting, chain)`
- `evaluate(setting, chain, package, *, launch=launch_child) -> {bench: unit root}`
- `run(setting, chain, *, learn, launch=launch_child) -> {"status": "complete" | "paused" | "terminated", ...}`
- `terminate(setting, chain, *, decision)`

## Deviations, with reasons

1. **`qualify` is a copy, not an import.** The frozen `qualify` stamps v3's version (:124), so route B copies the
   record closure. It also adds a keyword, `evidence`: every record carries one. The generators bind it with
   `functools.partial` (ticket A11-1's signature is otherwise unchanged).
2. **`evaluation.evaluate` signature.** It differs from the plan's: the plan is computed inside (`test_plan`), and
   `route_workers`, `canaries` and `panel` were added. The arms are `{"F","C","P_F","T_F"}` -> an `Arm` or a callable
   `(cell, task) -> Arm`, so the caller builds P_F's donor content and T_F's text (ticket A10-3). This is an adapter:
   the arm builders are not part of A12.
3. **`EvaluationStore.artifact`** returns `{"sha256", **summary}` because `cells.run_cell` reads `scored["status"]`.
   The summary lives only in the transient full record; the sealed record keeps hashes and tokens only.
4. **Canaries** are registered as a length plus a 16-hex sha256 prefix, never text. The scan hashes windows of every
   artifact's raw text and decoded JSON strings.
5. **`unseal` takes the run root** (to find `owner-continuation.json` and `formal-addendum.json`). It writes a
   write-once `unsealed.json`. The addendum record is `{sha256: 64 hex, written_at: UTC "YYYY-MM-DDTHH:MM:SSZ"}`;
   its format is not registered.
6. **OfficeQA's two test blocks** (§8.1) are dispatched one after the other in one unit, each in its own seeded
   order, and every cell names its block. No gap between the blocks is enforced: §8.1 registers none for the test
   read. The owner should confirm.
7. **Readout cost.** The sign-flip and Wilcoxon sensitivity run for Q1 only, and the bootstrap for Q1, Q2 and
   code-vs-text only, to keep the tests fast. The t quantile is found by bisection over `stats_ext.t_upper` (no scipy
   on the host). Q3 pools the bench differences with Satterthwaite degrees of freedom.
8. **`chain.run` takes `learn` injected** (`step.run_step` in a run). It has no stage-0 read and no per-step
   evaluation: §8.1 makes one test read at the end of the pilot. F = C writes `test-read.json` "not_read".
9. **`chain.read_budget`** checks both `<c>:solver` and `<c>:test` against 1.3 × the S-E6-corrected estimate, which
   comes from `setting.extra["test_read_estimate"]`. The registration names the solver budget; the test scope is
   checked too, so the read cannot start under its own cap.
10. **`chain._verified`** terminates on a ConfigurationError as well as a ValueError, so `manifest.verify_unit` can be
    bound directly (ticket A13-1 item 3).
11. **`chain._child`** starts children with `python -B` and `env=prelaunch.launch_env()` (A13-1 item 5). Frozen
    :162 has neither.
12. **Markers are this protocol's records**: `chain`, `chain-complete`, `chain-terminated`, `test-read`, `cap-check`,
    `unit-status`, all through `protocol.record`, not `seal`.
13. **`chain.cap_check` judges the caller's measured projection** of every chain-G scope. The zero-call arithmetic is
    the step's.
14. **`chain.heavy` is used only around the read children here.** Step units must take it in `step.py`.
