## Deviations

1. `pool_views` reads only the v3 `data.paths.train` with sha256 checks, not `coevo5.data.pool`, because `data.pool` opens val.
2. The escape row runs its own probe container instead of reusing `sandbox_selftest`'s report, because the fixer-9 rows need the new `worker` section.
3. In equivalence, the SpreadsheetBench transport replies with an unfenced line. The frozen extraction takes that line as the program, and the native runner rejects it with SyntaxError. The comparison excludes only `wall_seconds`.
4. In fake mode, supply, sheet import and fixture qualification are injected fakes, and so are docker, the escape report and the pool views.
5. The measurements row requires S0-derived limits to equal the self-test's start limits (C7b1-1). It also fails when the memory guard needs a slot reduction, because the manifest has no field for one (C7b1-2).
6. `smoke-items` takes an exported 600-item SearchQA pool by path (C7b1-2).
7. On the real path, the kill actions use the docker CLI: `docker exec` runs a PPid-1 child finder, and the worker is stopped with `docker kill --signal=KILL`.
