## Public API

`skillopt.execskill.sandbox.client` (also importable from `skillopt.execskill.sandbox`):
- `IMAGE`, `PREFIX = "execskill-sbx-"`, `KINDS = ("cell", "episode", "detector", "generator")`, `LIMITS`,
  `CALL_FAULTS`, `DOCKER_ENV = {"PATH": "/usr/bin:/bin"}`, `REPLY_GRACE_SECONDS = 10`.
- `@dataclass(frozen=True) Limits(pids, memory_mb, cpus, address_space_mb, frame_bytes)`; `.worker() -> dict` gives the
  part the worker applies itself.
- `worker_sha256() -> str`; `docker_command(kind, limits, mounts, *, name, hashseed=0, docker="docker", image=IMAGE)
  -> list[str]`; `argv_template(kind, limits=None) -> list[str]`. The last two are for the manifest's
  `docker_argv_template_sha`.
- `class Docker(path="/usr/bin:/bin")`: `.binary`, `.spawn(argv) -> Popen` (stdin and stdout are the frame channel,
  stderr goes to DEVNULL) and `.run(argv, timeout) -> Completed(code, stdout)`. Every docker CLI process runs with
  `env = {"PATH": "/usr/bin:/bin"}` only.
- `cleanup(name, *, docker=None) -> None`: runs `docker rm --force <name>` (bounded at 10 s), then
  `docker ps -a --filter name=^/<name>$`. Raises `CleanupUnconfirmed` if the name is still listed.
- `drain_check(prefix="execskill-sbx-", *, docker=None) -> None`: the prefix-wide check, run once when the unit
  drains. Raises `CleanupUnconfirmed`.
- `class Worker(*, docker=None, limits=None, hashseed=0, live=None, per_call=None, scratch=None, image=IMAGE)`:
  - `.start(package, *, kind, inputs_dir=None) -> Worker` binds the package lazily.
  - `.call(proc_id, fn, args, *, timeout_s) -> Result`.
  - `.ping() -> dict`.
  - `.close() -> None` (idempotent).
  - After use: `dropped`, `rejected`, `names`, `unconfirmed`, `info`.

  `package` is any object with `sha256` and `procedures` whose items carry `id`, `source` and `hooks` (the entry
  points the host may call). That covers `package.Package` and a detector or generator bundle.
- `with_worker(package, *, kind, inputs_dir=None, **options)`: a context manager that closes the worker on exit.
- `Result` is either `{ok: True, value, value_sha256, cpu_ms, rss_kib}` or
  `{ok: False, fault, exc_type, message<=500, line}`. `fault` is one of `exception, memory, timeout, cpu, killed,
  no_result, output, over_cap, not_loaded, undeclared, worker`.

`skillopt.execskill.sandbox.worker`:
- `main()`, `WORKER_PROTOCOL = "execskill-worker-v1"`, `FAULTS`, `HEADER` (8-byte big-endian length).
- `canonical`, `sha256` (the `validator_pilot.api.digest` form), `strict_loads`, `frame`, `check_plain`, `execute`,
  `run_call`.
- Helpers that procedures see as globals:
  - `public_workbook()` returns `{"sheets": [{"name", "cells": {coordinate: {"value", "formula"}}}]}`, read from
    `/input/input.xlsx` with openpyxl. Dates are returned as ISO text.
  - `safe_sympify(text)` parses with `parse_expression(text)`, a whitelisted grammar (numbers, names, + - * / ^ **,
    unary signs, parentheses, sqrt/exp/log/sin/cos/tan/asin/acos/atan/Abs, pi/E/I; at most 1,000 characters,
    depth 40, integer exponent 1,000), then builds the result with sympy constructors. There is no
    sympify/parse_expr/eval anywhere. sympy is imported only inside the call; if it is missing, the helper raises
    RuntimeError.

Wire protocol:
- `ping`: returns `worker, worker_sha256, policy_sha256, hashseed, python, numpy, openpyxl, pandas, sympy, vsz_kib,
  rss_kib`.
- `load`: sends `{package_sha256, policy_sha256, limits{address_space_mb, frame_bytes}, procedures[{id, source,
  hooks}]}` and returns `{package_sha256, loaded, rejected[{id, reason}]}`.
- `call`: sends `{proc, fn, args, timeout_s}`. The reply echoes `seq, proc, fn, args_sha256`.
- A request the worker refuses gets `{seq, ok: false, error}`, which the client raises as `ConfigurationError`.

Usage notes for callers:
- A6 (ALFWorld card arm): starts are lazy, so an empty package starts no container by itself. Call `worker.ping()`
  so that the card arm takes the same slot path as the other arms (REG §6.2).
- Pass `timeout_s` from `protocol.SANDBOX_TIMEOUTS` (predicate 2, hook 5, detector 5, generator 60).
- Use one Worker per thread. The live slot is taken before the per-call slot, which follows `slots.LOCK_ORDER`.

## Deviations from the plan, with reasons

1. **`call` carries `timeout_s` and `load` carries `limits`.** The worker enforces the per-call wall timeout and the
   S0-registered RLIMIT_AS and frame cap; the plan's op schemas omit them. The worker fixes FSIZE 0, NOFILE 32,
   nesting 32 and oom_score_adj 1000 itself.
2. **Extra keys.** Results add `rss_kib` (the child's peak RSS from `wait4`). Ping adds `worker`, `policy_sha256`,
   `vsz_kib` and `rss_kib`. Both are S0 measurement inputs for `measured{vsz, rss}`.
3. **Extra parameters.** `docker_command` takes `name`, `hashseed`, `docker` and `image` keywords beyond
   `(kind, limits, mounts)`. The `Worker` constructor carries the docker CLI, limits, hash seed, slot pools and the
   scratch directory. `start` binds lazily; the container starts at the first `call` or `ping`.
4. **Library preload.** The worker parent imports numpy, openpyxl, pandas and sympy (when present) before serving.
   Importing them in each call's child would use up much of the 2 s predicate budget. Children are forked from the
   untouched parent, so no library state crosses calls; the fresh-namespace test checks this with a module attribute.
5. **Entry points.** The worker calls any function named in an entry's declared `hooks`, not only the six HOOKS, so
   detector and generator bundles can use the same worker. Undeclared names return the fault `undeclared`.
6. **Restart rule.** Each worker-level loss (death, end of file, corrupt frame, seq or echo mismatch, late reply)
   records fault `worker` for the in-flight call, removes the container and drops that procedure. The next call
   restarts the container once. A failed restart raises `SandboxUnavailable`. There is no other cap: each restart
   drops one procedure, so restarts are bounded by the package size.
7. **Policy inside the worker.** It is checked with `bench=None` (all static bans), the same default as package
   validation.
8. **tmpfs.** The plan's argv template is followed exactly, so the frozen `mode=1777` is absent. S0 should confirm
   the tmpfs mode inside the real container.
9. **Unconfirmed cleanup keeps the slot.** After `CleanupUnconfirmed` the container stays in `Worker.unconfirmed`, so
   its live slot stays held. Without that reference, garbage collection of the slot's context manager released the
   slot; a test caught this.
10. **Sandbox constants live in `sandbox/client.py`** (image, prefix, start limits). See ticket A5-1. `RLIMIT_AS` has
    no registered start value; 2048 MiB is a placeholder until S0 measures it.
11. **T-SBX-13 is included.** The plan's A5 row lists T-SBX-1..13; the task text said 1..12.
