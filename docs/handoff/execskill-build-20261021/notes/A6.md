## Deviations (with reasons)
1. `solve` takes three keywords beyond the plan: `native` (the slot pool, held only around container runs),
   `nominal_tokens` (chain D's §4.1 margin rule, A7-1 item 5), `precheck_report` (replay of the stored report, §2.5).
2. The caller passes an unstarted Worker; `solve` starts it (cell/episode, SpreadsheetBench `/input/input.xlsx`),
   pings it on ALFWorld, and always closes it (one lifecycle per cell, as A5's lazy start expects).
3. Repair request key `repair_instruction` (not `instruction`): the sheet view already has `instruction` (the task);
   the first draft overwrote it and T-SOLVER-4 caught it. Repair user = first user + `previous_program`,
   `repair_instruction` (REPAIR_FRAME), `run_report{status, exc_type, message}`, `repair_notes` (when any).
4. A pre-check container whose removal is unconfirmed raises `CleanupUnconfirmed` (frozen `_native` returns
   unknown `container_cleanup_unconfirmed`): the pre-check report never reaches the frozen decision table, so an
   unknown would hide it.
5. ALFWorld: every stop is re-raised before the catch-all; if `env.close()` then fails, `CleanupUnconfirmed` is
   raised from the stop (the frozen `return` in `finally` would swallow it). Without a stop the frozen
   `alfworld_cleanup_unconfirmed` unknown is kept.
6. T_F arm: `before_call`/`bindings` hooks still run in the sandbox as shadows to decide "has output" (nothing they
   return is shown; registration §8.1 says T_F executes no procedure code -- removing the shadow needs F's per-item
   outputs passed in, not implemented); `sheet_feedback` runs no code (description + the shell's error message, repair
   when the program fails on the public input, status `exception` or `missing_output`, and the procedure declares a
   second call); ALFWorld: the description every step, no hook, no state.
7. Placebo arm takes plain data (ticket A6-1); the repair trigger shadow runs inside `solve`.
8. A withholding twin is the FULL package plus `withhold=` ids (the predicate must still run: `shadow_fired`), not
   `package.withhold(...)` (which removes the procedure). A restoration twin is `package.restore(...)`'s package plus
   `restore=` ids (marked in the log).
9. Faults beyond the plan list: a repeated binding name across procedures (the later procedure's bindings note is not
   shown), an undeclared repair request, a hook value of the wrong shape (`output_shape`), a note over its declared
   cap; all P1 (procedure dropped for the rest of the cell/episode).
10. Margin rule: unclosed `<answer>`, `<action>` or `<calc>` (case-insensitive count) or an odd number of fences.
11. The frozen fences extraction takes an unfenced reply whole, so a repair reply counts as a program whenever it is
    delivered; the fallback to the first program happens only for undelivered/truncated repairs.
12. Router: `plan` requires donors when A* is non-empty and the decision is `run`; ALFWorld requires `rooms`.
