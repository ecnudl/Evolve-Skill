## Public API (smoke)

- `run_stage(spec, manifest_path, stage, *, fake=False, env_path=None, roles_repo=None)`: `spec` a record or a path;
  `stage` in `BUILT_STAGES` = ("S2", "SN1"); any other stage is refused ("not run by run_stage"). Returns the stage
  record (written once through `record`), or, when a unit stopped, `{"stage", "complete": False, "stopped", "reason",
  "unit"}` with nothing recorded (the stopped attempt stays on disk, like S1 in `run_probe`).
- Constants: `BUILT_STAGES`, `UNITS_DIR` = "units" (`<root>/units/<stage>/<set>`: one copied unit per stage and item
  set), `CONFIRM_ARM` = "C_confirm", `DUP_ARM` = "C_dup", `TWIN_SETS`.
- Helpers used by tests: `_slice(stage, set, items)` (SearchQA 0-20 / 20-220 / 220-280 for S2 / S-N1 / S4 in stage
  order from `protocol.SMOKE_REAL_ITEMS`, ALFWorld 0-6 / 6-12, fixtures all 20 for S2), `_rehearsal_reply`.

## What run_stage does

1. Real mode refuses unless BOTH `env_path` and `roles_repo` are given, before anything else; they must equal the
   smoke manifest's `clients.solver.D.env_path` / `clients.solver.G.env_path`; then `manifest.verify_unit` (code map,
   interpreter, image) and `manifest.setting_of(m, "smoke", path=, docker=)`: ledger `<root>/shared/ledger`,
   `smoke_caps()` (solver 14M, GLM 2M), chain D's model through the elucid client. Fake mode refuses credentials.
2. Per item set (`ITEM_SETS` order, those in `PLAN[stage]`): `units.run_unit` (attempt dirs, the unit drain
   `units.drainer(setting, "smoke", unit)`, `units.for_unit` tag), endpoint `budgets.endpoint` on
   (`overall`, `smoke:solver`) with B = `protocol.ledger_bound(model, bench, branch, longest)`.
3. The first unit this process runs dispatches ONE production cell (`C_confirm`, the card arm on its first item) alone
   (`workers=1`); unless its first receipt is ok and echoes a registered response model id, the unit pauses
   `first_call_not_confirmed` before any concurrent round (plan §10 step 4).
4. One `rounds.run_round` per unit (seeded interleaved order, §6.2). S2: arms C (`empty` card), X
   (`fixtures.fixture_package()`), P (`placebo_i`: `fixtures.fixture_placebo` content, `placebo.arm` with
   `discourage_tag(unit, cell)`), runs per `PLAN`; withholding twins on the four non-ALFWorld sets. S-N1: C and C_dup.
5. Per cell the unit result keeps counts only: format violation, v2 token, `classed_sends` entries stamped at
   dispatch (body registered, M = the client's nominal M, B), procedure faults, hook kinds that ran without a fault
   (trajectory `shell.procedure_calls` + `route.enabled`), ALFWorld step forms, sandbox restarts and cleanup seconds
   (`cell["sandbox"]`, C5-4), reported tokens.
6. S2 judge = `s2_solver` (format floor/margin, receipt classes incl. the complete S1 probe attempt's entries, hooks,
   ledger, leftovers) plus rows `faults` (procedure faults only fx-crash on `FX_CRASH_SUBSET`, no cell stop) and
   `native_lock` (no model call while the calling thread holds a spreadsheet-native slot: a watched client checks
   `slots.Holdings.held()`); reported: hooks fired, procedure faults, ALFWorld wrapper share (`how` starting `tag`)
   and level-1 share (`how` ending `_level1`, canonical.py:45-59), restarts, max cleanup seconds, tokens per
   bench/arm. S-N1 judge = `sn1_noise` on (C, C_dup) v2 pass indicators per item.
