# coevo5 第一批代码 Codex 审查（第 1 轮，2026-10-17 17:2x）

> 模型 gpt-6-astra（推理档位 ultra），只读沙盒。审查对象：skillopt/coevo5 第一批（data、budget、calls、cells、qualify、evaluation 与 outcomes 的 spent 参数）。原文如下，未改动。

1. **MAJOR — Assumption-breaking settlement can lose the receipt and leave a permanent reservation.** [calls.py:104](../../skillopt/coevo5/calls.py#L104), [budget.py:156](../../skillopt/coevo5/budget.py#L156). A seven-byte request with `max_tokens=100` reserves 2,476 tokens. Three unknown-cost attempts followed by reported usage `(520, 100)` charges 2,477. Reproduced: settlement raises before recording the receipt or setting `broken`; the reservation stays open, and the cell becomes a generic exception. Other workers can wait indefinitely on its still-live owner. **Fix:** persist the receipt and assumption violation before settlement, provide explicit overrun accounting, and prohibit further dispatch. Add this four-attempt boundary test (§13.2–13.4).

2. **MAJOR — A reservation-bound breach does not immediately stop calls.** [calls.py:107](../../skillopt/coevo5/calls.py#L107), [cells.py:136](../../skillopt/coevo5/cells.py#L136). When excessive usage still fits the total reservation, the wrapper merely sets `broken`. ALFWorld continues until the episode finishes; an undelivered receipt can also trigger resends. A reproduction through the frozen backend made three calls despite the first breaching the bound. **Fix:** record and propagate the assumption stop immediately, preventing subsequent calls, resends, or native execution. Test an early-episode violation (§13.2).

3. **MAJOR — Training rendering checks parse test content without `TestAccess`.** [data.py:227](../../skillopt/coevo5/data.py#L227), [data.py:250](../../skillopt/coevo5/data.py#L250), [data.py:283](../../skillopt/coevo5/data.py#L283). Both renderers load entire upstream sources before selecting requested IDs. Consequently, `rendering_check()` parses held-out questions and answers during its supposedly training-only operation. Parser traces reproduced this for both benchmarks. **Fix:** use training-only sources for non-evaluation checks and require `TestAccess` for readers of mixed/test sources. Test parsing access, not just returned IDs (§0).

4. **MAJOR — One completed chain can unlock another active chain’s scores.** [evaluation.py:165](../../skillopt/coevo5/evaluation.py#L165). `unseal()` checks the supplied completion marker but never verifies that requested units belong to that chain. Reproduced: finished chain A’s marker authorized reading running chain B’s test score. **Fix:** validate every requested unit’s chain ownership before reading scores; handle explicitly authorized shared/reused source records separately. Add a mixed-chain rejection test (§0).

5. **MAJOR — Native scoring precedes mandatory stop and workbook checks.** [cells.py:133](../../skillopt/coevo5/cells.py#L133). A SpreadsheetBench prediction containing an earlier delivered workbook and a later cleanup failure still launches scoring before classification raises `Pause`. Structurally invalid workbooks likewise reach the native scorer before the registered 9b check. **Fix:** preflight known wrapper/generation stops and workbook structure before native scoring, retaining ordered classification afterward. Tests should assert zero native scorer calls for these conditions (§5.4 rows 1–3 and 9b).

6. **MAJOR — Ledger state and audit events can diverge after a crash.** [budget.py:69](../../skillopt/coevo5/budget.py#L69). `state.json` is replaced before events are appended and synchronized. Interruption between those operations leaves a committed reservation, settlement, or cap raise without its event. Settlement receipts are also still only in memory at that point. The replacement state itself is not synchronized before dispatch. **Fix:** use a durable transactional journal with replay/recovery and persist settlement evidence. Add fault injection around state replacement, event append, and synchronization (§13.2–13.4).

7. **MAJOR — Shared test qualification is neither concurrency-safe nor restart-safe.** [evaluation.py:59](../../skillopt/coevo5/evaluation.py#L59), [qualify.py:87](../../skillopt/coevo5/qualify.py#L87), [qualify.py:95](../../skillopt/coevo5/qualify.py#L95). Concurrent first evaluations can enter the same qualification and deterministic scorer directories. The frozen scorer then encounters competing writers. Following interruption, retry uses those same directories: completed results are replayed, while incomplete `started.json` files prevent execution. **Fix:** serialize shared qualification, give each authorized attempt a fresh root, and atomically register its completed result. Test simultaneous first use and interrupted recovery (§2.1, §13.4).

8. **MAJOR — Write-once publication does not prevent duplicate execution.** [evaluation.py:91](../../skillopt/coevo5/evaluation.py#L91), [cells.py:105](../../skillopt/coevo5/cells.py#L105). Two processes can pass the absence checks before either publishes. Distinct evaluation attempt directories allow both to issue all paid calls, after which one loses the immutable unit-record race. Individual cells have the same check-then-execute window. **Fix:** acquire exclusive ownership before checking and executing, and retain it through publication. Add cross-process tests verifying that the losing contender makes no calls (§13.4).

9. **MAJOR — Unexpected worker failures do not reliably halt queued work.** [cells.py:183](../../skillopt/coevo5/cells.py#L183). `run_parallel()` sets its halt flag only for `Pause`. An `OSError` publishing a cell record, or another exception outside `run_cell()`’s protected block, leaves dispatch enabled. A queued-worker reproduction started all five jobs after the first raised `ValueError`. **Fix:** latch the halt on every escaping exception before propagating it; preserve interruption evidence where storage permits. Test publication failure with queued jobs (§13.4).

10. **MAJOR — Legal SpreadsheetBench records can exceed the reader’s size limit.** [cells.py:131](../../skillopt/coevo5/cells.py#L131), [evaluation.py:173](../../skillopt/coevo5/evaluation.py#L173). Each rescore duplicates the complete base64 prediction in the cell record. Three valid 6.29 MB workbooks and two permitted rescores produced a 75,527,622-byte record in memory. Publication accepts it, but the frozen `read_json()` rejects anything over 64,000,000 bytes, making unseal fail. **Fix:** store workbook/prediction artifacts once and reference their hashes from attempts. Add a maximum-size, multi-case remedy test.

11. **MAJOR — Evaluation reuse checks only the Skill hash.** [evaluation.py:99](../../skillopt/coevo5/evaluation.py#L99). An incorrect `previous` path silently substitutes another benchmark or solver’s results. Reproduced: E-ds/SearchQA’s 400-cell unit was reused as E-glm/OfficeQA without evaluation. **Fix:** validate benchmark, solver/configuration, chain, and immediate predecessor stage before reuse; represent authorized shared stage-zero evaluations explicitly. Add wrong-source rejection tests (§10).

12. **MAJOR — OfficeQA silently excludes registered test items.** [data.py:235](../../skillopt/coevo5/data.py#L235), [data.py:309](../../skillopt/coevo5/data.py#L309). Missing parsed-page context drops an item, while validation accepts `tasks + dropped == 172`. One missing source therefore changes the denominator to 171 without pausing. Registration §2 fixes 172 OfficeQA items; only SpreadsheetBench has a registered eligibility exclusion. **Fix:** pause on missing required sources while preserving the roster, or amend the registration before evaluation. The existing dropout test currently enshrines this deviation (§2, §10).

13. **MAJOR — LiveMath rendering can consume unpinned files.** [data.py:249](../../skillopt/coevo5/data.py#L249), [data.py:259](../../skillopt/coevo5/data.py#L259). Verification hashes the layout’s declared files, but rendering independently globs every matching file and silently overwrites duplicate `month:no` IDs. An undeclared file can therefore replace test content while every pinned hash still matches. **Fix:** render from exactly the pinned file roster and reject duplicate IDs. Add an undeclared-file substitution test (§0).

14. **MINOR — Unreaped exited processes are treated as live reservation owners.** [budget.py:105](../../skillopt/coevo5/budget.py#L105). A zombie still passes `kill(pid, 0)` and retains its process start time, so admissions can wait indefinitely instead of settling its orphan reservation. This was reproduced with an exited, unreaped child. **Fix:** recognize Linux `Z`/`X` process states as ended and add a real-process orphan test (§13.2).
