# V12：跨域配对反馈驱动的 Skill 内容修订

日期：2026-09-15。此文件在首次正式模型调用前冻结。本轮是原创合成原生任务上的机制学习实验，不是三个公开 benchmark 复现，也不是原版 SkillOpt 的正式公平胜出比较。

## 研究问题与对照

同样的 Coding + Spreadsheet 开发数据、同样的模型/工具/求解修订机会下，显式配对 No-Skill/current 的执行反例反馈，是否比逐份处理相同证据更能修订出有用且少干扰的 Skill？第三域 RuleReasoning 的任务、反馈和规范研究不进入学习。验证器固定；本轮不声称检验 Research 验证器协同升级。

两个学习臂为 independent（逐份执行证据）和 contrastive（同一证据投影方式加宿主计算的配对差异、跨域义务对比指导）。首轮父Skill均空，两臂实际证据相同；之后父Skill分叉，current轨迹和失败优先反馈也可能不同。因此比较的是同任务、同执行机会预算的两条进化路径，而不是每轮始终完全相同证据的prompt对照。两臂均为一次调用的文本修订器，并非完整 reflect/merge/rank 的 stock SkillOpt。对照并不隔离抽象的“对比思想”单因素，它同时包含证据组织和修订指令。模型均为 PJLAB glm-5.3，temperature=0、reasoning_effort=low、流式、4 workers、每 HTTP attempt 最少间隔10秒、429冷却30秒、最多三次传输尝试，不因语义失败补抽。

## 数据与学习

正式设计3条学习历史、3轮、每轮4个训练任务和4个独立实例选择任务（各2 Coding、2 Spreadsheet）。训练/选择属于相同开发结构族，不冒充未见家族；选择反馈不得进入修订器。每个历史每轮每臂恰好一次 Skill 提案。输出格式无效或API不可用则保留原文，并计为失败提案，禁止不断抽到合法。

末轮候选始终作为下一轮开发父版本，即使小型选择片未选中，也只在实验开发/反事实臂使用。另行维护 selected 诊断版本：候选在当前选择片的领域等权成功率严格高于旧selected时替换，否则保留；不是作用域批准或安全证明。原始末轮候选无论选择结果如何都进入最终评测，避免全fallback掩盖内容效果。

最终36题：每域4个与开发隔离的新结构家族，每家族3个固定实例。参数实例不增加独立结构家族数。任务规则按规范事先写定，不根据模型输赢挑题；离线检查参考实现、起始缺陷和控制实现。模型每题一次生成和一次依据公开执行日志的修订；最终私有评分只进报告。Coding运行在现有多文件OS沙箱；公式和规则由有界解释器执行，不运行任意宿主代码。资源、传输、无效交付和真实执行失败分层记录。

任何模型调用前的一次性任务构造修订：Coding 每族起始代码统一设为三个独立的行为/辅助输出错误，不改变参考、题目集合或评分；Spreadsheet 有多处顺序/额度/审计错误，Rule 有多个前提/替代路径错误。控制失败只说明判分能识别这些错误，不证明模型存在提升空间。真实模型即使全部通过，也不再调整难度。本批以部分更新和保留约束为主，不声称完整覆盖全替换、near-miss 与无关任务的机制析因设计。

## 冻结最终矩阵与预算

每条历史评估 no_skill、independent_raw、contrastive_raw、selected_independent、selected_contrastive。相同任务/Skill文本/阶段必须精确复用请求和结果；No-Skill跨历史共享，选中版本与raw相同则为别名，不能充作独立采样。没有基于最终得分的路由或候选挑选。主比较只用raw候选。

最坏上界：开发训练每轮每历史4题×3种文本×2调用=216，选择4题×4种文本×2调用×9=288，18次优化，最终最多13种唯一文本×36题×2调用=936，共1458次。预算固定1536逻辑调用；实际相同文本复用可更少。选择No-Skill无需另加独立臂，因为selection只比parent/candidate；预算余量不用于追逐显著结果。输出tokens上限两臂一致，实际tokens/Research额外成本不能声称相同。

smoke单独目录、1历史1轮、仅开发来源的少量任务；不得消费正式final。smoke结果仅判定接口与证据闭合，不决定正式面板难度、模型或阈值。

## 统计与解释

两项主终点：contrastive_raw−independent_raw 的三域等权平均差；未训练Rule域的差。先在任务内平均历史，再在结构族内平均实例，域内结构族等权，再跨域等权。按域分层的结构族bootstrap、簇级配对sign-flip及两项Holm；四个第三域家族无法支撑小效应强结论。本轮是固定规模探索，不是3pp功效充分或安全认证。

同时报告各历史/领域、No-Skill参照、配对改善与损失、交付/可评/语义结果、实际非空Skill覆盖、文本变化与选择事件、调用/tokens成本。selected仅诊断，不替代raw主结果。零差异可能来自别名或统计不足，不能称等效；不显著退化不是非劣。

只因安全、未闭合请求/执行、数据完整性、预算或明确用户暂停中止。可缓存继续已经闭合的阶段；未决intent不得静默重跑。不改旧实验源码/结果/凭据/代理/持久电源设置。全部源文件、任务、Skill、请求和执行证据登记hash；完成后离线重算须零模型调用、零生成代码执行。

## 结论出口

如果来源未出现收益，报告当前表示/学习方式未奏效，不通过调gate制造成功。如果两学习臂都进步，区分共同多域经验贡献与配对反馈增量。如果仅selected较好，支持选择作用而不是Skill内容改进。只有raw在未见域出现可支持收益并兼顾开发域新任务，才为跨域内容泛化提供证据。即使完全负结果也完成报告，不继续用final改候选或重抽。
