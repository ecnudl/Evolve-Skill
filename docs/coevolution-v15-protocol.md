# V15：经独立校准的验证策略与 Skill 协同进化

状态：实现后、首次模型调用前登记。历史 V1–V14 代码、协议、成绩不修改。

## 目的和结论边界

核心假设：开发行为驱动的验证策略更新，能够产生新增的可靠执行证据，通过相同的结构化反馈/Skill 更新器改善后续冻结 Skill 的跨领域收益与能力保持。外部文档研究是否有增量作用单独检验。

本版是新编写的受限 Coding／数值公式／Rule 机制实验，不是公开 benchmark、原版 SkillOpt 复现、真实 Excel 执行或安全认证。6 个最终结构家族/域与3条学习历史不足以保证发现几个百分点差异；不存在事后按效果继续扩样至显著。结构家族是设计聚类单位，不自动保证独立。

为先识别 Skill **内容**收益，本版不进行 scope promotion、Skill 候选选择、部署路由或 fallback。所有合约合法的更新均保留为 working Skill；API/格式无效时保留父 Skill。评测原始末轮候选和预先指定的早期 checkpoint。独立校准门只控制验证器更新，不等于批准 Skill 跨域使用。

## 四个条件与匹配

- No-Skill：同模型、同题目、同求解器的真实性能锚点。
- fixed：Skill 进化，验证搜索策略固定。
- adaptive：Skill 与验证搜索策略进化，无外部文档。
- adaptive_research：同 adaptive，增加有界官方文档信息。

三学习组共用结构化闭合回执、完整 Markdown Skill 更新器（4096 token 上限）、6000字符 Skill 上限、求解器、可见任务信息与每题一次探针输入搜索机会。不得同时改变局部/整体改写形式。空 Skill 或完全相同的 task/text/history/intervention 共享一次真实调用，并显式视为别名，不当独立样本。历史之间不共享真实性能抽样。

主比较为 adaptive−fixed、adaptive_research−adaptive；对 No-Skill 的结果说明绝对收益/损失，不替代方法对照。Research/策略提案/校准产生额外计算，固定组未获得同等总推理计算。因此这是匹配求解、Skill更新及开发探针机会的干预，不宣称等总成本；报告实际 token、逻辑调用、HTTP尝试、原生执行及文档获取成本。后续论文须加等总成本搜索/反思对照与真实原版 SkillOpt 基线。

## 固定正确性，进化证据搜索

任务要求、输入合法性、可信宿主 oracle、执行接口固定；模型仅输出1–4个合法输入，不能输出 expected、改测试答案或执行任意测试代码。同一输入集可以在相同候选及已知校准控制上执行。

搜索仅看公开任务、输入 schema 和当前 policy，不看 reference、mutant标签、隐藏答案或最终任务。开发的实际产物及执行反馈可以进入下一次 policy 提案，所有文本作为不可信数据处理。

结构化反馈区分要求、实际语义失败、交付失败、API/oracle unknown、通过的行为和未验证假设。引用/哈希验证只证明来源与一致性，不宣称自然语言蕴含被证明。探针未知不能变成语义失败；未检错不等于正确。

公共交付协议在 V15 明确：公式以一个 `=` 开头，内部数字相等比较使用 `==`；支持函数仅以受限DSL公开规范为准，不能假定Excel语法均支持。Rule修改包含完整原始rule ID集合及保护规则，revision 必须使用声明的action envelope。各组共享相同提示与仅交付级回滚；合法但语义变差的revision不得按隐藏成绩回滚。

## 任务划分和跨轮时序

pilot：3条完整历史、4轮 `Coding → Spreadsheet → 新 Coding 家族 → 新 Spreadsheet 家族`，每轮2题；开发共8题。3个独立校准片，每片1 Coding +1 Spreadsheet；最终18题，每域6个新结构家族。所有任务ID及结构家族的 train/calibration/final 分区互斥。Rule 不进入开发、Research或校准。

smoke：独立题族，1条历史、2轮各1题、1个两域校准片、每域1道最终联调题。只验证系统联通和交付，不产生科学结论，也不消费pilot最终题。

轮次 r 使用已批准的 V(r−1) 生成反馈并更新 S(r)。开发证据可提出 V(r)，但它必须在独立校准片 C(r) 验证，最早影响下一轮 Skill。最后一轮不生成没有下游学习机会的验证器。校准产物、指标、最终标签均不回流 Skill 更新器或后续 policy 提案；批准/拒绝以及已批准策略状态本身允许影响下一轮。

每条历史/轮次/两个自适应臂各至多一个候选；同轮两臂共享预登记校准片，但不根据另一臂成绩改提案，模型提案看不到校准数据。跨轮不重复使用旧校准片调整候选。所有协议、源码、任务、Skill和validator状态有不可变记录及源码快照。

所有历史的所有 checkpoint 冻结之后，才启动最终评分。末轮评测全18题；早期checkpoint只评测预先指定的两个开发域各前2个最终家族，作为低功效保持性诊断。相同题/Skill/history的最终调用可共享，不将多checkpoint当独立样本。最终任何组都没有进化验证器的在线辅助，只接受同一公共反馈revision。

## 验证器校准和Research

每个校准任务为旧、新policy分别生成一次输入集（同查询预算），输入集各自执行4个宿主控制：reference、equivalent、semantic mutant、preservation mutant。另用完整的固定ordinary输入分块检查真值：正确控制必须全部通过，坏控制至少有一个实际失败且所有执行可用；不能把只覆盖4个输入的canonical探针当完整真值。校准控制不能仅因输出非法而算语义缺陷。

描述性pilot批准条件：完整固定控制校准通过；policy文本实际改变；新policy新增真实缺陷检出；新policy零误拒；总体及正确控制unknown不增加；旧policy已检出的缺陷不丢失。满足才批准；无增量或证据不足保留旧policy。小样本通过不构成泛化/统计安全保证，不声称unknown下降等于语义检错改善。

另对每个校准任务/历史生成一次共同 No-Skill 自然产物，旧、新输入集都执行其上。自然产物结果只作独立检错诊断，不把未检错产物当正确标签，也不用于批准候选。必须分别报告旧未检出→新检出、反向丢失、unknown转换，以及相对普通任务检查是否新增真实错误。人工mutant与自然产物不能合并宣称真实检错率。

Research 是**有界官方文档检索**，不是已经实现的自主全网 DeepResearch：固定读取 Python comparisons 与 conditional-expressions 两个官方页面，缓存HTML与摘录的哈希；使用既有安全传输，不改代理/DNS/路由，不发送API key或任务。模型只允许引用实际可见摘录的精确URL和12–300字符原文。出处存在不代表提出的检查合理，后者仍由执行/独立校准检验。文档不能覆盖受限DSL合同。

有文档/无文档策略提案均为一次模型调用；文档不可用、输出截断、引用不匹配等记为实际无效提案，保留旧policy，不自动重采样。Research固定页面是否带来增量是待检验问题，不要求为故事强行得到正结果。

## 三层证据与分析

1. 检错：同产物、等搜索机会，人工控制与自然产物分别统计新增检错、丢失、误拒、unknown。
2. 反馈利用：第2轮若各组仍共享相同父Skill/产物，审计各分支收到的反馈、子Skill及冻结后小片表现。父Skill不同则不得宣称受控的共同父分叉。只修好当前题不算跨题迁移。
3. 冻结迁移：逐域全尝试成功率、域等权macro、相对Base的逐域变化/最差域变化、配对胜负、真实非空Skill使用。早期checkpoint诊断旧域能力保持。

统计按域内结构家族成组bootstrap，保留家族内所有历史/任务；区间条件于观察到的学习历史，不把相同题重复当更多独立家族。报告每条历史、交付/语义/API错误分解；主分母保留所有尝试。预指定两主比较，不按最终分数调阈值或重选家族。

若校准全拒绝，结论是本次没有发生有效validator干预，不能把最后的随机分差当协同收益。若新增检错但没有冻结迁移收益，应归因为反馈利用/学习瓶颈；若只改善格式，报告工程收益；若Research不优于无文档版本，报告没有观察到额外文档收益。

## 运行、预算与恢复

沿用仓库 PJLAB 凭据和 glm-5.3；凭据只由既有客户端读取，不进入日志或快照。4并发，HTTP尝试最小间隔10秒；沿用已验证传输重试，不做语义重采样。smoke逻辑调用上限192，pilot上限1536，额度不自动上调。

每次调用/原生执行先登记intent，成功/失败均保留receipt；未闭合intent停止而不是重发。支持PAUSE在当前批次排空后停止，显式resume仅复用源代码/协议一致的记录。监督器每30秒记录心跳；检测到明显wall/monotonic差异时请求暂停，标记潜在休眠/时钟影响但不自动删除成绩。该检测不能保证识别所有合盖或网络中断。

完成后禁止API、文档获取和原生执行，进行只读全流程replay与字节不变审计，再生成中文报告。报告不包含题目gold或凭据。
