## 问题与设计

协同进化分析认为，当前学习只给反思器“通过/失败”标量，失败原因不可见，可能是Skill难以针对性改进的瓶颈。本试点只改反馈内容，其余全部固定：

| | 臂A（复用，不重跑） | 臂B（新跑一次） |
|---|---|---|
| 来源 | F的SkillOpt S1（学习v7，BCB） | 同一学习清单逐字段复制 |
| 反馈 | `benchmark-public-feedback-v1`（标量） | `bcb-execution-evidence-v1`（标量＋脱敏证据） |
| 其余 | 同面板、train/selection族、空父、模型、预算、种子、host runtime、原生优化器源码 | 同左（`prepare`逐字段核对） |
| 评测 | F已有BCB单元格（800位置） | 同一派生评测源码、同面板评测B的选中Skill |

脱敏证据只附在**失败的训练执行**的反思输入上；选择集仍只做门控。每个失败测试只保留：内置异常类名（非内置一律`NonBuiltinException`）、失败位置分类（候选代码 / 候选调用的库 / 隐藏测试断言 / 隐藏测试代码 / 隐藏测试调用的库 / 未知）、以及**候选自身**的失败行。隐藏测试正文、异常消息、数值、期望值都不复制；结构不明确时fail-closed为`unparsed`，模块级`ALL`消息不计为证据；最多8例，已解析例优先保留。实现见[execution_evidence.py](../skillopt/continual_learning/execution_evidence.py)，门控只允许v7＋BCB＋SkillOpt使用此档案（[contracts.py](../skillopt/continual_learning/contracts.py)、[feedback.py](../skillopt/continual_learning/feedback.py)）。

## 门控与可复现性

入口[run_feedback_ablation_pilot.py](../scripts/run_feedback_ablation_pilot.py)（`bcb-feedback-ablation-pilot-v2`）：

- `prepare`：要求F为序列v4且S1学习完成、阶段/学习结果/Skill/评测请求互相绑定，并逐一核对臂A全部学习产物哈希；臂B清单除反馈档案外与A完全相同；学习源码仅允许4个文件变化且必须等于审查后固定哈希，`--f-source`须逐文件等于A的源码树；冻结No-Skill计划须与引用哈希一致，派生评测源码只差长度字面量。保存源码diff并封存协议。
- `run`：在与F相同的native锁内重新核对源码，**付费学习前**用冻结worker对臂A评测执行`verify-evaluation`并要求结果完全一致；已完成结果只回放并重新核验，不重采样。
- `report`：每次重核冻结源码、两臂学习与评测（含空Skill路径），输出两臂对No-Skill及B对A的配对比较（全部位置/排除学习族两视图），覆盖率只统计已登记且经臂B授权的训练执行。`--export`须为试点目录外的新目录。

审查：Codex四轮（9项→残留3项＋1新→残留2项＋3新→全部RESOLVED、无新缺陷）。测试：试点与脱敏专项37项通过；相关回归504 passed / 16 skipped。

## 零API真实数据冒烟（10/4，只读F）

Linux冻结源码`/root/feedback-pilot-20261004-source`（995文件，与F同一打包规则）；结果`/root/feedback-pilot-20261004-smoke/smoke.json`。除需F阶段记录的绑定外，`prepare`全部检查在真实数据上通过：臂A学习产物1,521项哈希全部一致；臂B清单仅反馈档案不同、仅4个审查文件变化且哈希匹配；F源码树、原生源码与派生评测源码核对通过。

在F S1的152次失败开发执行（77训练＋75选择）上运行脱敏器：151次有证据（1次仅模块级`ALL`，正确判为不可用），470个失败测试全部解析；`__test__.py`行号映射违例0（实证确认`code + "\n" + test`拼接），异常消息泄漏0。渲染长度均值341、最大938字符。保留的467例中：

| 位置 | 例数 | 占比 |
|---|---:|---:|
| 隐藏测试断言 | 219 | 46.9% |
| 候选代码 | 132 | 28.3% |
| 候选调用的库 | 62 | 13.3% |
| 隐藏测试调用的库 | 42 | 9.0% |
| 隐藏测试代码 | 12 | 2.6% |

**预期限制**：近一半失败是隐藏断言不通过，证据只说明“答案错”，不比标量多多少；带候选失败行的只有41.5%（194/467），证据主要帮助崩溃类错误。臂A自身选择分仅40/65→41/65，学习信号很弱。
