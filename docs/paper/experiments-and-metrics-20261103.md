## 2 持续学习指标的定义，以及阶段行怎样对应

R[k][t] = 第 k 步冻结的包（加 t 的卡）在 t 的测试集上的准确率，R[0][t] = C，K = 5。为与登记的配对比较一致，
R[k][t] := C_t + Δ_k(t)，Δ_k(t) 是登记的配对差 S_k − C（主分析或 S）。

| 指标 | 定义 | 本设定里的读法（以 main-v6 D 为例） |
| --- | --- | --- |
| ACC | (1/5) Σ_t R[K][t]，宏平均；另报 1,110 题的 micro 平均 | 就是 F 行 |
| dACC | ACC(F) − ACC(C)；dACC_learned 只算前 4 个学习 bench | 导入的 ALFWorld 单列，不算成"学到" |
| PG（plasticity） | (1/K) Σ_k (R[k][k] − R[k−1][k])：第 k 步对自己 bench 的即时增益 | 只有 k=3（+10.0）、k=5（+17.9）非零 |
| BWT | (1/(K−1)) Σ_{t<K} (R[K][t] − R[t][t])，负 = 遗忘 | t=1、2 用 C 行；t=3 用 k=3 的 S3；t=4 用 k=4 的 S3（与 k=3 同包） |
| FGT（forgetting） | (1/(K−1)) Σ_{t<K} [max_{t≤l<K} R[l][t] − R[K][t]] | 同上 |
| FWT | (1/(K−1)) Σ_{t≥2} (R[t−1][t] − R[0][t])；参照取 C，不取随机初始化 | 四项依次是 C@OfficeQA、C@ZebraLogic、S3@表格题、S3@ALFWorld |
| TS / TD | 只看改变了包的步 k：对 t ≠ home(k)，增量 R[k][t] − R[k−1][t]，按 t 与 home(k) 是否相似分组平均（登记读数的 q2 用 S_k − C，本数据里两者相同） | 改变包的只有 k=3、k=5，home 都没有相似 bench，TS = 0 格 |
| no-harm rate | 非对角格（k=1..5，t ≠ home(k)，共 20 格）中，S_k − C 的 95% 区间上界 < 0 记"受损"；"有信息"= 包 ≠ C 的行。登记读数另有无关 bench 合并的 −5 pp 非劣效检验，本指标是逐格的补充 | k=3、4、5 三行 × 4 = 12 个有信息的格 |
| touch / abstention | 链末包下请求与 C 不同的题所占比例（abstention = 1 − touch）；off-target = 不承载任何程序的 bench | 读格子记录里的请求哈希 |
| noise floor NF95 | 1.96·sqrt(f/n)，f = 同请求重读的翻转率，n = 面板题数 | 单次读数的差小于它就不解读 |

**结构零**：程序不触发的格子，包与 C 的请求逐字节相同，Δ 恒为 0（main-v6 起连方差也是 0）。main-v5、implant-v5、main-v6 D 的
BWT、FWT、FGT 全部由这类格子构成，等于 0 是设计的直接结果。论文里写成"互不干扰是架构性质 + 实测的触发率"，
可检验的部分只有三样：本 bench 上的增益（PG）、非目标 bench 的触发率（0/776）、在真正触发的题上是否有害。

### E1 主表：路线 B 对 No-Skill、零样本指令、SkillOpt、GEPA、memory 基线

- 目的：故事线主张"不需要验证集也能达到或超过 baseline"的直接证据；五 bench × 两种模型，同时段读取。
- 已有：B、C 在每次链末读数里都有（main-v6 D：B 54.3 / C 63.7 / F 69.3 宏平均）。SkillOpt、GEPA 只在旧 bench 组（LiveMath 代替
  ZebraLogic、只有 GLM）有：空白 58.6、指令 66.7、SkillOpt 66.0、我们的路线 A 63.7、GEPA 63.5（账本 10/19 10:52）；更早的五域
  （BCB/表格/QA/KOR/ALF，10/6）两者只在 QA 上有可信提升。memory 方向（ExpeL / AWM / Dynamic Cheatsheet / ACE 式）**没有任何数字**。
- 要跑：SkillOpt、GEPA 在当前五 bench、G 和 D 上各一条；memory 基线 1–3 种（实现与运行手册另见 baseline 清单文档）；
  可选的任务专用基线（ZebraLogic 的 PAL/PoT 式、ALFWorld 的 Reflexion 式，见 story E5）；main-v6 G 读数（已于 11/04 打开）。
- 成本：SkillOpt 5,960 万 + GEPA 1,618 万（GLM 每链，含逐步测试读取，账本 10/19）→ 两种模型约 1.5 亿（D 链成本未知，按同量级估）；
