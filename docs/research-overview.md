# 跨域安全 Skill 进化：研究索引

本分支关注多领域整体表现和负迁移，而不是逐个 benchmark 追求最高分。新增研究代码与上游 SkillOpt 训练入口并存；各版本用于检验不同假设，不应把不同任务面板的数字直接横比。

## 阅读顺序

新主线优先阅读 [Research-driven Skill Validation](skill-validation-mainline.md)：当前仅阶段一，固定产物验证回放与可见证据／隐藏审计隔离，尚无新方法效果结论。以下保留历史研究脉络。

1. [目标与指标](cross-domain-objective-and-evaluation.md)：平均表现、最差域、逐域损害与使用覆盖率。
2. [三部分实验总结](experiment-report-skill-validation-coevolution-20260916.md)：Skill 学习、可执行验证、协同进化各自已有的证据与局限。
3. [V17 科学性审计](coevolution-v17-scientific-audit-20260917.md)：为什么没有学习空间时停止，而不是不断换题直到出现正结果。
4. [V18 预注册协议](coevolution-v18-protocol.md)：相同父 Skill 与开发证据下，对比全文更新、共享核心和领域局部规则。

## 模块关系

开发任务执行产生轨迹与产物；原生检查／Coding Rubric 将观测整理为结构化反馈；Skill 更新器据此提出候选。独立确认集决定候选的使用范围，最终冻结后在保留任务上评测，并把原始内容效果与回退保护效果分开报告。

验证器进化是另一个受控环节：开发证据与限定来源的 Research 提出补充检查策略，通过独立校准后才在下一轮生效。任务真值和最终评价标准不能随验证器一起改写。最新 V18 聚焦 Skill 表示与干扰控制，本轮使用固定原生检查，不同时新增 Research 干预。

| 代码 | 作用 |
| --- | --- |
| `skillopt/cross_domain/` | 早期范围门、任务面板及多域评价 |
| `skillopt/scope_evolution_v2/` | 来源保持、路由与来源数据适配 |
| `skillopt/validator_pilot/`、`skillopt/validator_scale_*` | 产物验证、Rubric、检索与校准实验 |
| `skillopt/coevolution*/` | 冻结协议对应的版本化进化、评测与审计实现 |
| `scripts/coevolution_v18.py` | 最新实验的准备、运行、恢复、状态及报告入口 |
| `tests/test_coevolution_v18_*.py` | 无模型调用的数据隔离、门控、回执与控制流程测试 |

历史版本之间存在实际代码复用和源码哈希依赖，故一并保留。新实验应另建协议与输出目录，不直接改写已经冻结的版本。

## 复现与发布边界

- **离线代码测试**：按根 README 安装研究依赖后，可运行 V18 的合成数据／模拟接口测试，不需要模型凭据或历史输出。这些测试不等于完成真实模型实验验证。
- **CI 范围**：上游回归测试由 `configs/ci/upstream-tests.txt` 显式列出，V18 离线研究测试单独运行；不包含所有依赖本机沙箱或外部素材的历史研究测试。文档站保留上游指南，研究协议和报告直接在 GitHub 阅读。
- **真实实验配置**：本地 `.env` 使用 `.env.example` 中的 PJLAB 字段；冻结实验限定 `glm-5.3`，其他模型需要新协议。真实 Coding 执行依赖 macOS 沙箱，其他平台尚未提供等价已验证执行路径。
- **公共数据**：自行依照来源许可准备固定版本 SearchQA、MBPP-sanitized 等数据。部分旧代码含本机缓存默认路径，需按入口与协议配置匹配路径，不应直接照抄历史机器命令。
- **历史来源材料**：V18 依赖经过审计的 V9 父 Skill、运行回执及来源哈希。GitHub 不包含原始 `outputs/`，因此源码公开不等于该历史运行已可独立完整复现。复现同一实验还需另外准备经过审查且允许分享的来源材料。
- **第三方任务**：旧 validator pilot 的 SkillEvolBench 快照暂不发布，原因是未确认再分发许可。仅保留[来源清单与说明](../configs/validator_pilot/tasks/README.md)。依赖这些文件的旧实验及测试，需要自行取得有权使用的素材。
- **发布内容**：算法代码、实验脚本、单元测试、非敏感配置、冻结协议及精选分析。密钥、调用日志、数据缓存、检查点和日常运行／暂停记录不在本次发布范围内。
- **报告证据**：汇总报告不是完整原始证据包；其中提及的本机过程记录未全部公开。冻结协议保留原文，不为本次发布更改实验约定。

## 结果应如何理解

已有实验支持局部内容学习和部分结构化反馈收益，但尚不能证明协同进化稳定优于 No-Skill 或原始 SkillOpt。人工缺陷检出改善不等于自然错误检出改善；门控后不退化也不等于 Skill 本身已泛化。小样本诊断与完整公开 benchmark 结论必须区分。

发布时 V18 已写出计算结果，但完成后的离线回放审计被父实验缓存读取的拦截错误中止，尚未完成整条审计链；因此这里不发布其效果结论，也不改写冻结源码或重抽结果。离线单元测试通过不覆盖这项已知集成问题。
