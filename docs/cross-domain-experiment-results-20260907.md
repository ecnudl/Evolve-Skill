# Cross-Domain Safe Skill Evolution：实验交付记录

状态：本轮五组实验/先导工作已结束。A/C/D/E 完成预定执行，B 按预先约定的
无学习空间停止条件结束；没有继续扩大测试集或选择性补跑以追求正结果。
所有真实调用使用已有 Freerouter 的 gpt-5.5，没有更换模型、修改 `.env` 或 Clash 路由。

## 当前结论

本轮没有证明 Cross-Domain Safe Skill Evolution 优于对照。它确认了来源
EM 收益、找到了错误泛化反例，并暴露了机制归因、任务难度和验证样本量问题；
全部回退到 Base 不能算保住正迁移收益。

补充实验改为固定一个历史上已有收益的 SearchQA Skill：在新的 128 道来源
校准题上，Base 为 103/128，完整 Skill 为 112/128，11 次改善、2 次退化，
EM 增益 7.03 个百分点；抽取小节为 105/128，尚无确定正收益。
独立留出 256 题上，Base 为 199/256，完整 Skill 为 214/256：
20 次改善、5 次退化，EM 增益 5.86 个百分点，配对 bootstrap 95% 区间
为 [1.95, 9.77] 个百分点。来源 EM 收益得到复核，但还没有证明通用机制或
跨域安全进化成功。机制路由在 96.48% 来源覆盖下保留 86.67% 的净收益，
Domain 路由保留 93.33%；两者均未拦截本轮 5 个来源 EM 退化。

最值得带入下一轮的研究问题是：**先确认 Skill 实际改善了什么行为，再验证
这种行为机制是否能跨任务族迁移**。不能由章节标题或模型生成的机制标签，
直接推定已有的 benchmark 收益来自通用证据验证。

## 实验 A：从局部轨迹进化候选并验证范围

来源 train 40、dev 40；两域 validation 640（fit/confirmation 各 320）；
三域独立 test 360 题，每题两次生成。分别进化 CP、EV 两个候选，复用原
SkillOpt 的反思、合并、排序和 patch 执行。

| 测试指标 | Base | 无条件 CP | 无条件 EV | 来源门 / 所有 safe 策略 |
|---|---:|---:|---:|---:|
| 原始严格 EM | 99.58% | 95.83% | 95.69% | 99.58%，覆盖率 0% |
| 测试前固定的形状敏感性副指标 | 99.72% | 99.72% | 96.67% | 99.72%，覆盖率 0% |

- EV 在副指标下仍有 2 次改善、24 次退化；一个可核查原因是将“审计回放指定
  旧记录”的请求错误地套入“选择当前合法最新记录”的经验。
- CP 的主要下降来自题面未说清数组嵌套方式，不能把它当成机制级负迁移。
- 两个候选的来源 dev 均无增益，Current=Base，原来源门也已拒绝更新。
  因此 safe 胜过强制注入，并不等于胜过正常 SkillOpt 更新。
- 等覆盖率的机制排序没有优于 Domain；EV 在多个强制高覆盖率下反而更差。
  这种强制排名诊断与允许 abstain 的正常部署不同。
- 这是合成任务及领域表述变化，不是完整公开跨领域 agent benchmark。

详细数字、全部对照与配对区间见 [首轮完整报告](../outputs/cross_domain/scope_mvp_gpt55_20260907/findings.md)。

## 实验 C、D：成熟 Skill 的来源收益及固定路由对照

固定历史完整 Skill 的内容，不根据新数据重写它；另将 extractive 小节单独作为
内容消融。来源预留 calibration 128、holdout 256；与历史 400/200/1,400 个
划分 ID 全部不相交，也排除已知精确归一化重复问题。

D 在同一来源输入和每个 split 的 48 道合成控制题上，比较 Base、无条件使用、
Domain-only、机制路由。所有启用策略注入完全相同的完整 Skill，路由仅看原始
可见输入，先封存 masks 再调用目标模型。来源覆盖率和净收益保留目标均为 80%。

D 的来源结果复用 C 的同一次执行，不是另一份独立实验证据。机制描述是从
冻结 Skill 人工指定的，不是本轮自动进化获得；它目前只是固定路由诊断。

校准阶段，Domain 和机制路由均在 127/128 的来源覆盖下保留全部观测净收益；
48 道控制题中 Base 与完整 Skill 均满分，暂时不能识别跨域收益或伤害。
留出路由 304/304 在目标执行前成功封存；全部目标执行已完成，无 API 错误。

| 留出来源策略 | 正确数 / 256 | EM | 来源覆盖率 | 来源净增益保留 |
|---|---:|---:|---:|---:|
| Base | 199 | 77.73% | 0% | 0% |
| 完整 Skill 无条件使用 | 214 | 83.59% | 100% | 100% |
| Domain 路由 | 213 | 83.20% | 96.48% | 93.33% |
| 机制路由 | 212 | 82.81% | 96.48% | 86.67% |
| 抽取小节单独使用（C 内容消融） | 202 | 78.91% | 不适用 | 不作完整 Skill 的范围策略 |

Domain 保留了完整 Skill 的 19/20 次改善，机制路由保留 18/20；
两者都仍使用全部 5 个退化回答，拦截数为零。机制与 Domain 的直接来源差值
为 −0.39pp，95% 配对区间 [−1.17, 0.00]pp，不能声称机制更优或显著更差。
两种路由的 80% 覆盖率和净收益保留目标均在点估计上达到，但保留比例没有
置信保证，更不等于安全 Gate 通过。

留出控制仍是 Base/full 各 48/48：跨域同机制 16/16、来源外观 near-miss
8/8、跨域 near-miss 8/8、unrelated 16/16。机制路由在四组分别启用
16、5、5、0 题，Domain 分别为 0、3、0、0。没有跨域正收益，也没有本组
可减少的观测伤害；这不是“对所有不适用任务都安全”的证明。

C 中抽取小节对 Base 为 5 改善、2 退化，EM +1.17pp，区间 [−0.78, 3.12]pp；
尚无确定来源增益。完整 Skill 的 F1 从 87.01% 到 89.20%，差值 +2.19pp，
区间 [−0.11, 4.47]pp，同样需保留其不确定性。不能因 Full 的 EM 显著而
extractive 不显著，就推断二者差值显著或已完成机制归因。

C/D 共享同一来源结果；固定种子下，两个分析程序的任务排列不同，有限
bootstrap 的端点略不同，不是两次独立执行。此处来源收益区间用 C 原报告，
路由差值用 D 预先冻结的分析程序。运行及完整指标定义见
[C/D 复现说明](retention-routing-mvp.md)；全部数字及案例见
[C 来源结果](../outputs/scope_evolution_v2/source_retention_gpt55_20260908_sessionfix/findings.md)、
[C 全部差异案例](../outputs/scope_evolution_v2/source_retention_gpt55_20260908_sessionfix/holdout_effect_audit.md)、
[D 完整路由对照](../outputs/scope_evolution_v2/retention_routing_gpt55_20260908_paced/findings.md)。

事后逐题审计中，Full 的 20 个改善有 13 个是可见证据支持的同对象形式变化，
1 个是明确答题对象纠正，5 个涉及槽位/粒度/词义选择，1 个证据不足。
5 个退化中 4 个涉及形式、1 个丢失实体识别信息且题意欠明确。
这些分类没有回写评分，不是盲化人工标注或已验证的机制处理效应。

## 实验 E：固定章节删除的来源收益归因

在 C/D 留出题目打开前，固定两种删除版：删除 Evidence Selection 完整小节；
或删除 Concise clue-answering 小节及整个 SLOW_UPDATE 块。除精确删除片段外
不改写其余内容，保留最终答案标签要求。复用 C 同一批 256 道题的 Base/full
轨迹，只新增两臂、512 次目标调用；全部成功，四臂共同分母为 256。

| E 留出内容条件 | 正确数 / 256 | EM | 相对 Full 的 EM 差值及配对 95% 区间 |
|---|---:|---:|---|
| Base（借用 C） | 199 | 77.73% | 参照条件，不作章节删除 |
| Full（借用 C） | 214 | 83.59% | 0 |
| 删除 Evidence Selection 章 | 212 | 82.81% | −0.78pp [−2.73, +0.78] |
| 删除答案表达章及 SLOW_UPDATE 块 | 206 | 80.47% | −3.12pp [−6.25, 0.00] |

两种删除版对 Base 的 EM 仍有名义正向信号：分别 +5.08pp [1.17, 8.98]
和 +2.73pp [0.39, 5.08]；所有固定比较均保留，未做多重比较校正。
去掉答案表达/实例块的点估计下降更大，但两种删除版相对 Full 的区间都
包含零，不能说“确定证明某章贡献”或“另一章毫无作用”。两种删除版的
F1 差值区间也均包含零。

这是章节级消融，不是纯机制因果隔离：第二种删除还移除了实例记忆，各章节
语义有交叉，提示长度不匹配；共享 Base/full 也不是第二次独立来源复现。
因此这只是与“来源效果不能直接归给单一证据章节”相容的证据，不是
纯答案格式机制或 RCE 无效的因果证明。详见
[E 原始配对结果](../outputs/scope_evolution_v2/source_attribution_gpt55_20260908/holdout_summary.json)、
[E 完整解读与事后案例](../outputs/scope_evolution_v2/source_attribution_gpt55_20260908/findings.md)、
[E 运行与结果解读](source-attribution-mvp.md)。

## 运行可靠性和统计注意事项

- 一个新来源入口曾漏传已有 Session ID，248 个完成请求均失败且无模型结果。
  独立启动器修复导入顺序，旧失败目录保留，新来源样本重新固定。
- 一次路由尝试在 122 次成功后出现 6 个 HTTP 429，自动停止；后续采用独立
  `_paced` 目录、每 2 秒放行一个逻辑调用。只降低请求频率，没有绕过服务限制。
- API 错误不记作模型答错；真实比较使用共同成功题集并保留错误数。
- 无结构性 identity、reference 全对且零改善零退化的保护 cell，
  在当前 gate 的主阈值下至少需 46 题才能通过
  两项安全筛查，严格阈值需 96 题；这不是统计功效保证。A 的 confirmation
  每 cell 32 题不足以认证这种非空、无观测差异的使用范围，但来源无收益也是
  独立阻断。详见 [样本量审计](gate-sample-size-audit.md)。
- 新结果不能与旧测试重新调参后混称独立验证；固定模型别名、单训练种子、
  有限任务分布、合成控制和无多重比较校正均限制外推。

## 工程验收

全仓 `conda run -n skill python -m pytest -q`：1,945 项通过、6 项跳过；
新增代码 Ruff 和 `git diff --check` 通过。原始 SearchQA 结果、凭据和冻结实验

该检查不提供上游服务身份或服务器签名证明。见
[工程验收记录](../outputs/scope_evolution_v2/verification_final_20260907.json)、

进入相应命令与结果目录即可；缓存恢复不等于新的独立模型重复实验。

[下一轮研究设计](next-cross-domain-study-design.md) 根据已完成开发结果提出
可学性预筛、真正任务族 OOD、两个正交主对照与明确停止条件；它不是本轮
留出结果的事后调参，也不代表这些后续实验已经运行。

建议下一步先做一个机制的、带明确硬 oracle 的真实任务族 pilot：先分开
答案形式、对象/关系选择与实例记忆，确认来源及目标域都有可识别的机制收益，
再固定内容对比“跨域门开/关”和“同一门下机制/Domain 路由”。目前没有必要
仅为获得正结果而更换模型或继续扩充同类满分控制题。
