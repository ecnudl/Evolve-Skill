# V9-A：真实来源 Skill 学习与接受门对照（事前协议）

日期：2026-09-13。本协议在对应运行首次模型调用前封存；不是论文默认完整复现，也不是三域评测。

## 问题和条件

使用 PJLAB glm-5.3，复用原生 SearchQA 提示、6000 字符 DOC 边界上下文截断、单次回答和 EM/F1。SkillOpt 原生反思、归并、编辑排序、补丁应用与严格 EM 接受门保留；meta/slow 更新关闭，编辑预算 4，反思 minibatch 8。模型输出上限统一为 4096，原生优化器请求上限与实际封套上限分别登记；这与原生默认 16384 不同。保留原生 JSON 容错及 merge/rank fallback，不将它冒充严格 Research 格式验证。

每个历史从同一原版 initial.md 开始，实际采集训练轨迹并生成一个候选 Skill。该候选精确共享给两个门：

- SkillOpt：调用原生来源接受门，仅 candidate EM > parent EM 时提交。
- Our：除原门通过，还需 candidate EM ≥ No-Skill EM，且 candidate 对 parent 的精确单侧配对 discordant 检验 p≤0.10；至少 64 个确认问题簇。否则保留 parent。

这是接受门组件对照，不是两套独立优化器，也没有声称已把 V8 结构化 Coding 反馈应用于 QA。Our 只允许来源域 Local Commit，不批准跨域 scope；拒绝时保留初始 Skill，不将其假称 No-Skill fallback。两个门收到相同候选和确认轨迹；额外 No-Skill 确认的实际成本计入总账，原生门本身不使用该条件。该探索性门不提供安全或非劣认证。

最终条件为 No-Skill（空串）、Initial（原手写初始版本辅助）、SkillOpt 所选版本、Our 所选版本。只评正常门选择的版本，不用被拒候选冒充 SkillOpt 部署结果。

## 规模与预算

先跑独立 smoke：1 历史×1 轮，4 道训练、8 道确认、4 道 final；仅检查流程，不解释效果。Our 的 64 簇要求不为 smoke 降低。

正式 source 批次：3 个预定学习历史，各 1 轮、32 道训练、64 道独立确认；final 为所有历史共同的 128 个问题。草案的两轮是上限，本批事先固定一轮控制预算，不因结果追加轮次。每历史独立训练抽样及模型请求，不将历史差异解释为纯供应商随机种子效应。

每历史优化器最多 16 次逻辑调用。全运行使用 4 workers，每 HTTP attempt 至少间隔 10 秒，429 共享冷却 30 秒；仅保留原有最多 3 次传输 attempts，无语义补抽。最多调用数：`H*T + H*16 + H*3*C + (H+2)*F`，smoke 为 56，source 为 1360。上界包含训练、优化、No-Skill/parent/candidate 确认和最终所有可能唯一 Skill。

同题、同阶段、同 Skill 文本的请求精确共享；final 的 No-Skill/Initial 跨历史共享，相同所选候选跨政策也共享，显式记录 alias，不伪装独立随机样本。训练和不同确认分片不得相互别名。实际费用按唯一请求、HTTP attempts、返回 usage、阶段和 Skill 统计；调用上限不等于等实际 token 成本。

## 数据、冻结和恢复

训练从本地 SearchQA train Arrow；确认/final 从 validation Arrow。结果盲筛选只读身份列；排除历史已使用/预留/暂停/隔离目录中的题目 ID 和规范化问题指纹，跨全部新分区去重。所有历史来源文件和缓存哈希封存。此定义不证明没有语义近重复或预训练污染。

训练标签与真实训练回答可进入原生反思。API 不可用不伪造语义失败；训练失败记录保留，可用回答之外不生成假的 analyst 轨迹。确认金标只给宿主接受门，不交回优化器。正式数据排除 smoke 曝光；smoke 不用于调门槛、挑候选或改变正式评估规模。

final 在三个历史的候选、接受决定、部署 Skill、数据清单、模型参数、源码和分析规则封存后才由运行器物化、执行与评分。最终题目/答案不得回流候选生成。完成后 replay 为纯离线；缺少元数据、未决请求或源码漂移必须停下，不能删除原记录以补抽。所有终止失败保留为 API/响应 unknown，端到端 EM/F1 以 0 留在分母中，同时单列可用性。

反思并行完成顺序按固定 tag 排序再交原生归并，防缓存身份随调度漂移；这是确定性封套改动。模型温度 0 不等于确定性，repeat 只是请求身份。分片按历史分离，不能跨新确认片使用旧 parent 分数。

## 分析和结论边界

预声明两个主要 EM 对照：final 上 Our−SkillOpt 与 Our−No-Skill，p 值作 Holm 双重校正；前者对应门控问题，后者检查相对基础模型表现。辅助列两者相对 Initial 的 EM/F1、每历史结果、wins/losses、Base 正确而方法错误的比例及条件分母、Skill 更新与实际使用率、API 可用性和成本。按问题簇先平均学习历史，再做配对簇区间；128 题×3 历史不算 384 个独立问题。三个历史不能充分刻画学习随机性。

单轮共享候选无法证明多轮协同进化；SearchQA 一个域无法证明跨域收益。没有更新、全部保留父版本或两门选相同 Skill 均为可报告结果，不能据此称方法优越。旧 V8 Research 候选已被独立校准拒绝，本批不重调该候选或重复消耗该校准片。
